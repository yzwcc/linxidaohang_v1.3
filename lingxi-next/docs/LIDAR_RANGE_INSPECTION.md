# 原始雷达点云的距离核查

日期：2026-10-28。用户补充：往返总路程约 5 米，途中多次转向。
这是未测量的现场回忆，不是轨迹长度、端点重合或几何闭环真值。
**行走路程、雷达回波距离、地图范围及地图精度是不同的量。**
没有按 5 米缩放/裁剪地图，没有因转向就宣称验证回环。

## 完整原始点统计

本机离线读取全部 353 帧静止及 1,232 帧动态原始 PointCloud2，
共 8,999,917 / 31,270,824 点，未发现非有限坐标或全零点。
不下采样、不按 IMU 覆盖范围跳帧，不作近远距离或零回波过滤。
三维距离为点到雷达原点的欧氏距离；水平距离仅使用 XY，不是地图宽高。

附件 SDK 声明点坐标单位为米；本轮仍以原始坐标单位记数，
因为物理尺度和几何精度尚未标定。下表是有限回波统计，不是厂家额定量程、
可用测距精度或场馆真实尺寸，极远点也可能受异常回波影响。

因此数据中确有大量超出 5 个坐标单位的回波，不是只扫到了机器人所走路程。
各帧的距离 P95 再取中位数，不等于把所有点混合后的 P95；
完整证据分别标记，避免扫描点数差异导致统计误读。
本轮没有验证角度视场、遮挡、反射强度、多回波语义或距离准确性。

## 来源与复算

工具 `tools/inspect_lidar_ranges.py` 复用已经验证的点云字段/行填充解码，
按完整点数核账，在读取前后核对五个原始文件的哈希、数据库及话题数。
它不连接机器人、不启动 ROS/SLAM、不作标定或修改算法/显示参数。
公开 `lidar-range-evidence.json` 只有计数、距离分布、源码/输入摘要及边界，
没有点坐标、位姿、绝对时间戳、地址、配置或凭据。

```sh
rtk proxy python tools/inspect_lidar_ranges.py \
  --manifest docs/slam-capture-evidence.json \
  --data-root "$PRIVATE_RECORDINGS" --output "$NEW_AGGREGATE_JSON"
```

输出必须是新的、位于录制目录之外的文件。两次独立读取的聚合须逐字节相同；
单点极值不能代替可靠量程标定。本轮不需要现场再次行走。
