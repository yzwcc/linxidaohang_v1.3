# Web 现场地图显示核验

日期：2026-10-31。此轮响应用户对新扫地图效果的反馈，未启动新的采集、
定位或导航，没有修改原始地图或替换实机服务。现场地图、名称、原始坐标、
完整轨迹、点云图片和原生日志均仅保存在忽略入库的私有目录。

## 实际核对

通过已经配对的页面确认选中地图，再通过已核对主机身份的普通用户 SFTP
只读获取保存收据、完整二进制点云、最终雷达轨迹、里程计轨迹和日志。
点云与轨迹摘要分别匹配页面预览携带的摘要；收据身份和摘要也匹配。
未执行远程 shell 命令。对照分析前后完整点云摘要不变。

| 完整保存点数 | 83,911 |

## 已确认的问题

1. `web/src/LidarCanvas.tsx` 的点绘制使用 XYZ 中的 X/Y，将全部高度叠加。
   它还不是经过地面、顶面和障碍层区分的俯视地图。高度混叠会保留大量
   平面内部散点，不能只调整点的颜色或大小就当作参考效果已达成。
2. `web/src/lidar-view.ts` 的范围来自全部点的极值。此次少量远点显著扩大
   范围；完整范围与中心 1%–99% 分位范围有明显差异，主体结构被缩小。
   分位视口只应用于显示对照，未删除远点，也未认定远点都是错误测量。
3. `robot-api/src/slam-map-catalog.ts` 的预览上限为 20,000 点，按固定步长
   抽样。本次完整点云的对照图更密，但全部高度的重叠仍存在，因此不能
   将问题简单归因于预览抽样，或声称提高点数即可解决。

本轮生成四种只读对照：当前抽样与全范围、完整点与同范围、完整点与中心
分位视口、指定原始 Z 区间与同一中心视口。最后一项的结构轮廓更清楚，
但该区间只是诊断示例，不是已批准的米制高度、地面提取或导航障碍阈值。
原始地图和全部点均保留。

## 不能据此批准的项目

局部轮廓仍有多层散点；没有独立现场尺寸、回到起点的信息或外部真值，
不能将其确定归因为漂移，也不能认定只是地面/顶面叠加。
日志中的 IMU 告警提出外参或偏置的可能性，但这不是确定根因。
本轮未修改外参、时间假设、原生校验阈值或地图收据。

下一步先由现场距离和路线信息约束判断，再补充明确区分全部点、显示视口
和原始 Z 分层的点云页面。显示筛选不得改写地图或冒充几何修复。
地图尺度、方向、轮廓精度、回环、移动定位与导航验收仍未通过。
