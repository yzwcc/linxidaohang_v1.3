# GLIM 原生引擎与进程监督组合

日期：2026-10-29。本轮仅使用已保存的完整回调记录，不连接机器人，
不新建 ROS 节点，不采集传感器、不发布 TF/地图、不发送运动命令，
不切换模式或修改厂商服务。机器人当前地址变更不影响本轮离线验证。

这是独立后端的前置组合验证，不是可部署的完整建图、定位或导航服务。
现有 0.1.19 管理 API、前端及 APK 仍使用原 AIMDK 接口，未重建交付包。

## 组合边界

新增 `tools/run_glim_supervised_replay.py`，组合已有的：

- `ProcessSupervisor`：单次会话、进度时限、私有 stop 管道及自有进程组回收。
- `HealthEmitter`：标准输出只传健康 JSON，不传点云、位姿、模型密钥或运动指令。
- `SensorWorker` / `SensorStream`：原有有界队列、同步和静默检查保持不变。
- `Native`：原有 C ABI 封装和原生库保持不变，每个子进程仅初始化一次。

原生实例的创建、IMU 插入、扫描处理和关闭由同一个非主线程执行。
C/C++ 标准输出重定向到 mode-0600 私有日志，不能进入健康 IPC。
退出不仅检查 stopped 消息，还要求正常退出码、工作线程关闭、
leader 回收、管道关闭、监督线程 join 以及无可执行的自有进程组成员。
失败不会自动重启、续接旧任务或批准导航 readiness。

## 输入与来源

仅选用一份既有完整记录：197 帧点云、3,947 条 IMU，共 4,144 次回调，
约 20 秒。保留原始顺序、CDR 字节、传感器时间和扫描起始时间假设；
没有筛选更好看的片段、改偏置、外参、扫描范围或估计位姿。

冻结的 GLIM 提交为 `1a197c999e4865f5cab7c9cd25474128413ebbca`。
核对原生构建报告、适配器源码、配置、profile、诊断、完整日志 footer
与 SHA256，并核对 `/proc/self/maps` 中实际加载的七个库是否与既有
x86 验证基线一致。该检查不声称固定了所有系统级传递依赖。

在进程启动前，将源码和所需输入复制到 Linux 私有输出目录并核对
字节摘要。父子进程再次验证输入，退出后父进程还检查原始输入未变。
准备耗时不计作实时性能；重放必须明确选择 1 倍或 0.5 倍速，
不能视为真实 DDS、端到端传感器延迟或 ARM64 性能测量。

生产者 EOF 不代表处理完成。父进程观察到全部 4,144 次回调处理完成
后才及时请求停止，避免在 EOF 后继续等待而触发正常的传感器静默保护。
最终还核对接受、完成、拒绝、丢弃、扫描跳过及原生调用计数。

## 分段耗时观测

新增统计不改变原有工作线程、流式输入、C ABI、配置或 watchdog。
每个固定通道最多保存“记录数 + 1”个标量，报告只汇总计数、总和、
最小值、P50/P95 和最大值；百分位明确采用 nearest-rank。
失败/异常调用的墙钟耗时也会记录，不伪装成成功处理。
生产者读取包含首条读取及最后一次 footer/EOF 核验，共 4,145 次。

g 的主要观测如下，单位均为 ms：

| 通道 | 样本数 | P95 | 最大值 |

| 原生完整 frame 封装墙钟 | 196 | 36.747 | 55.307 |
| C++ 预处理 | 196 | 7.679 | 8.402 |
| C++ 里程计 | 196 | 19.588 | 35.551 |
| 生产者读取与记录摘要核验 | 4,145 | 0.232 | 1.842 |
| CDR 解码 | 4,144 | 0.085 | 0.341 |
| 回调入队调用 | 4,144 | 0.105 | 0.620 |

完整 frame 墙钟还包含 C ABI 内的数据准备、Python 封装和调度等待；
不能仅用预处理与里程计两项替代。各通道不是相同事件的同一阶段，
不能相加 P95 得出端到端延迟。生产者混合 IMU/点云的百分位主要由 IMU
样本占比决定；入队迟到不是队列年龄，也不是传感器至画面或可听反馈延迟。

## 使用

在已准备好固定依赖的普通 Linux 用户虚拟环境中运行；输出使用原生
Linux 磁盘上的新私有目录，不要复用失败目录或从挂载盘逐条喂入。
所有路径必须明确指定，不会自动寻找机器人、安装依赖或启用服务：

```sh
rtk proxy "$PYTHON" -B tools/run_glim_supervised_replay.py run \
  --work "$CPU_CORE" --adapter "$NATIVE_ADAPTER" \
  --bundle "$PRESERVED_BUNDLE" --reference "$PRESERVED_LIVE_OUTPUT" \
  --output "$NEW_PRIVATE_LINUX_OUTPUT" --hypothesis header_is_scan_start --rate 0.5
```

`export` 子命令核对父子报告及私有日志摘要，只输出白名单聚合字段。
不要提交私有输入、运行源码副本、原生日志、录制文件、外参或业务数据。
