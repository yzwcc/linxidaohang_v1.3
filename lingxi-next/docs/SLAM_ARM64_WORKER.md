# ARM64 有界工作线程的真实节奏回放

日期：2026-10-28。经 SSH 主机密钥比对确认机器人身份，在普通用户全新独立目录
完成四个新进程，实际执行有界输入工作线程和原有 GLIM CPU 里程计。
**这是按原始接收节奏的 bag 回放，不是实时 DDS、全局建图或导航验收。**

没有创建 ROS 节点、实时订阅/发布、切换模式或输入源，
没有改动部署服务、厂商 AIMDK、传感器配置、地图、安装包或 APK，
没有发送运动命令或要求现场人员再次走动。既有历史试验原样保留。
当前 0.1.19 产品后端没有切换到独立 SLAM。

## 执行方式

- `prepare_glim_worker_target.py` 复制已经验证的 ARM64 原生库、
  单预处理线程控制配置和既有解析依赖，只新增输入组件和本次运行器。
  不修改或重编 GLIM，不调整量程、尺度、外参或时间偏移。
- `glim_target_worker.py` 使用 Humble `SequentialReader`，
  按原始混合消息顺序逐条读取并反序列化，不创建 DDS participant。
  只预读第一条消息以打开读取器，不预载整个 IMU 流。
- 生产者按整数接收时间先相减再转为相对秒，计划以原始 1 倍节奏调用输入回调。
  实际晚到和快照耗时单独保存；不因 CPU 忙而悄悄改变记录时间或加速补偿。
- 真正的 `SensorWorker` 工作线程执行引擎创建、点云解码、IMU/帧原生入口、
  结果处理和引擎关闭。独立计数及线程检查确认生产者没有调用原生入口。
- EOF 先等待全部已接受消息处理完，再停止并 join；不通过停止丢掉尾部数据。
  超时、拒绝、失败或残留存活线程都不能生成成功报告。

目标实际环境为 AArch64、Python 3.10.12、NumPy 1.26.1。
原生库、实际进程映射、配置与源码均有摘要，配置与冻结目标基线逐文件一致。
进程使用现有普通用户、显式隔离环境和 `nice -n 10`，
每轮外层限时 300 秒，超时后最多再等 10 秒。
这不是生产守护进程安装，也不代表原生挂起场景已做过实机验证。

| 条件 | 消息 / 点云队列峰值 | 原始排队 payload 峰值 | 最长队列年龄 | 回调开始至帧结果 P95 / 最大 |

| 静止，终点 | 16 / 9 | 7,323,752 字节 | 79.26 ms | 47.54 / 81.11 ms |

| 行走，终点 | 18 / 10 | 8,162,480 字节 | 84.94 ms | 58.54 / 86.10 ms |

实际线程排队峰值包含记录开头的消息突发，不能用先前虚拟时钟回放的
“点云缓冲最多一帧”代替。流核心内部缓冲和回调队列是不同边界；
原始字节峰值也不等于整个进程 RSS。均未放宽已有诊断限额。
原生预处理/里程计两调用合计 P95 分别约 47.25、44.26、51.03、54.54 ms。
流核心的 `maximumActualCallbackScanWaitSeconds` 按实际回调入队时刻
计算 IMU 覆盖等待，不含之后的工作线程排队和计算；
表内端点耗时则由生产者/结果处理两端的真实单调时钟另行测量。

表中帧结果包括初始化期间的无位姿结果，不能当首个有效定位耗时。
开始点是回调进入时刻，终点是工作线程的帧结果处理；
不含真实雷达至 DDS 接收链路，不包含网页传输/绘制、全局建图、
语音模型或音频播放。不能据此宣称语音 P95 两秒或现场全链路实时性通过。
实际消息读取、反序列化、回调快照与计算会竞争 CPU，但不是受控语音并发试验。

## 独立复算

`export_glim_worker_evidence.py` 检查四轮完整私有轨迹、统计、投递时间、
原生日志、源码和实际加载库；重新打开原始 bag，
逐项核对计划投递的消息种类与混合接收时间，再复算分位数及基线差异。
基线使用此前目标平台同条件 repeat1 的完整已验证输出，
通过冻结公开摘要核验，未重跑或更换有利基线。

相对浮点时钟的减法比较仅允许 1 ns 数值舍入，保留原始有符号观测值，
不钳制时间、不放宽工作线程超时。跨 NumPy 复算分位数允许极小数值误差，
公开结果使用重新计算值，不照抄目标报告中的统计值。
四轮原始数据及复制的原生库/配置在执行后和导出时均保持不变。

```sh
rtk proxy python tools/export_glim_worker_evidence.py \
  --bundle "$PRIVATE_WORKER_BUNDLE" --parent-bundle "$PRIVATE_CONTROL_BUNDLE" \
  --core-bundle "$PRIVATE_CORE_BUNDLE" --baselines "$PRIVATE_TARGET_BASELINES" \
  --results "$PRIVATE_WORKER_RESULTS" --data-root "$PRIVATE_RECORDINGS" \
  --output "$NEW_PRIVATE_AGGREGATE"
```

本次目标运行使用新的 bundle-b。此前仅在本机准备的 bundle-a 因浮点边界测试
修正而保留未用，没有在目标执行或覆盖它。
全部回传、轨迹、日志、源码快照和运行目录均保持私有。
公开 `slam-arm64-worker-evidence.json` 只含白名单聚合和摘要，
不包含坐标序列、绝对采样时刻、设备地址、外参或凭据。
