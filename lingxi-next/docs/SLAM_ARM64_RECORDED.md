# ARM64 真机真实记录回放验证

日期：2026-10-28。结论：**机器人本机完成静止/行走各两种扫描时间假设，
共四轮真实点云与 IMU 的 GLIM CPU 里程计离线回放。**
不是仅在电脑上运行，也不是只加载 ARM64 库或处理合成点。
这仍不是地图几何、标定、实时建图、重定位或自主导航验收，
不批准更换现有 0.1.18/0.1.19 产品后端。

复用机器人已有的 Humble `rosbag2_py.SequentialReader`、

## 实际结果

耗时来自机器人实际进程；P95 为每帧预处理与里程计耗时之和的分位数，
不是两个 P95 相加。墙钟只覆盖本轮记录遍历和处理，
不含前后整包校验、模块初始化、上传下载或产品 UI/语音链路。

| 数据与假设 | 录制 / 处理 / 跳过 / 初始化 / 有效位姿 | 合计 P95 ms | 合计最大 ms | 处理墙钟秒 | 峰值 MiB |
|---|---|---:|---:|---:|---:|
| 静止，扫描起点 | 353 / 343 / 10 / 30 / 313 | 44.86 | 69.14 | 10.59 | 196.29 |
| 静止，扫描终点 | 353 / 342 / 11 / 31 / 311 | 41.18 | 68.87 | 10.47 | 188.14 |
| 行走，扫描起点 | 1232 / 1221 / 11 / 31 / 1190 | 43.24 | 71.68 | 42.29 | 244.69 |
| 行走，扫描终点 | 1232 / 1220 / 12 / 31 / 1189 | 46.72 | 70.86 | 45.17 | 250.42 |

跳过的是首尾缺少完整 IMU 覆盖的扫描；不补造 IMU，
初始化期间不伪造位姿。每轮均满足：
`处理 + 跳过 = 录制`，`初始化 + 有效位姿 = 处理`。
有效位姿数与此前 x86_64 诊断一致，不要求不同 CPU 上的浮点轨迹逐位相同。
私有报告中的 `recordedScansSeen` 是最后一次进度检查点，
最终计数使用 `recordedScans` 和上述完整记账字段，不误作漏帧。

行走起点/终点假设的累计位置步长约 8.1413 / 9.8487，
首末距离约 0.6790 / 0.7236，均是未批准标定的原始坐标单位；
静止首末距离约 0.02273 / 0.02210。
这些估计不是已知距离或外部真值，也不是地图误差。
两种时间假设结果仍有差别，不能因某一数值更像腿里程计就自动选定它。

本轮结果支持继续评估 GLIM CPU 路线，**不保证 10 Hz 端到端实时运行**。
这里只执行离线里程计，没有实时消息队列/丢帧统计、
全局建图、地图发布、网络显示、语音并发或长期温度/负载测试。
两线程设置也不等于给语音预留了已经验收的算力。

## 证据与故障保留

构建和试验经历按时间保留，不覆盖失败记录：

1. `-a` 包漏带传递依赖 `slam_preflight.py`，导入时退出，尚未读取 bag。
2. `-b` 已通过导入和两份原始数据校验，Humble 读取器因缺少
   `AMENT_PREFIX_PATH` 退出；详细原生日志已取回。
3. `-c` 补齐显式 Humble 插件路径后，四轮均完整处理并正常退出。

打包工具现在先检查本地 Python 导入依赖闭包，
再启动 `-I -B` 的独立解释器，只导入暂存包中的源文件，
防止单测借用工作树模块而漏检。回归测试明确移除依赖并确认失败。
协调器对非零退出也保留报告与原生日志，便于区分环境失败与算法失败。

机器人每轮前后复核两份原始 bag 的五个文件校验和、
SQLite quick_check、大小和全部 topic 消息数量，均一致。
导出时又复核本机已校验副本；原始数据没有改写。
实际配置、完整数组、轨迹、日志和失败输出均保留在忽略的
`.local/glim-target-{replay-bundle,results}-20261028-{a,b,c}/`
及机器人独立目录，不进入 Git、APK 或通用交付包。
独立回放包不是已冻结全部许可证/依赖的正式发行包。

`export_glim_target_replay_evidence.py` 重新检查包和来源哈希、
四轮报告及数组/日志哈希、完整计数、有限位姿和时间顺序，
从逐帧数组重新计算耗时与运动汇总，通过嵌套字段白名单生成
`slam-arm64-recorded-evidence.json`。未知嵌套字段不透传。
公开证据没有实际 IP、用户名、密码、profile、点坐标、地图或轨迹序列。
`toolSourcesAtExport` 表示导出时工具版本；实际目标运行器
另由上传清单和目标报告中的源码摘要共同固定。
此前合成加载、电脑里程计和电脑地图持久化证据保持原样。
