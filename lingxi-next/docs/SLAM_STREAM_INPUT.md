# 独立 SLAM 的有界流式输入

日期：2026-10-28。已新增可复用的雷达/IMU 输入组件，并以原始记录的
接收顺序完成静止/行走、扫描起点/终点假设的四组 GLIM 里程计验证。
有效 header 域、算法时间戳和逐帧计数均与冻结的单预处理线程基线相同。
**这不是实时 ROS 接入、ARM64 流式运行或导航验收。**

本轮不联系机器人、不移动或切换模式/输入源，不改现有服务、AIMDK、
传感器配置、历史试验、地图、安装包或 APK。产品后端仍是原生 AIMDK。

## 输入组件

`robot-slam/lingxi_slam/stream.py` 中的 `SensorStream` 由单个所有者线程调用，
注入已经验证的算法引擎，不包含算法替代实现、原生库加载、ROS、网络或运动接口。
实时接入时，订阅回调与算法工作线程之间还需要单独的有界队列，
不能把此模块当作已经完成 DDS 并发集成。

- 雷达与 IMU 按实际到达顺序进入，不先预读整段 IMU；
  数据时间使用整数纳秒，转为相对小数秒后才传给引擎。
- 扫描起点/终点必须显式选择，不自动把其中一个标记成正确标定。
  沿用原始逐点时间解释、范围和物理量，不增加时钟偏移或尺度拟合。
- 只有 IMU 覆盖整帧扫描，才推进里程计。
  已收到但属于未来的 IMU 暂存，不提前全部送入算法。
- 点云、逐点时间与 IMU 数组由组件持有副本，排队后不受调用方修改影响。
  点云按完整数组处理，不因网页显示范围裁剪远处点。
- 时间回退、重复或过大间隙、断流、超时、容量溢出、原生调用或结果处理失败
  均使会话锁定失败并清空缓冲；同一个失败对象不能重启或补跑旧帧。
- 调用者须周期性使用真实单调时钟调用 `tick()`，否则断流看门狗不会自行运行。
  所有原生调用须保持单所有者，不能直接从多个 ROS 回调并发调用。
- 初始化中的 `None` 位姿不伪造为定位成功。
  明确停止/EOF 时逐项记账边界扫描、释放缓冲，但不自动声称地图已保存。
  原生引擎关闭仍由调用方负责。

当前诊断边界为 IMU 最多 4,096 条、点云最多 32 帧、
完整点云缓冲最多 64 MiB；单帧最多 2,000,000 点。
启动等待最多 2 秒，常规扫描等待与传感器接收间隔最多 0.75 秒，
IMU/header 连续间隙上限分别为 50 / 500 毫秒。
这些是显式诊断限额，不是经过现场批准的生产参数或时钟标定结果。
核心还会检查有限数值、数组形状、计数整数性及输出刚体位姿。

## 原始到达顺序验证

`run_glim_stream_trial.py` 在四个新进程中逐条读取 bag 的混合接收顺序，
使用原有 CPU 核心和里程计 C ABI，不修改或重新编译 GLIM。
有效配置引用各条件冻结的 repeat1 单线程基线，完整输入、源码快照、
实际加载库、完整数组和基线摘要均核对。
没有选择更接近预期路程的条件，也没有重跑或覆盖旧的 12 组完整建图结果。
首次四轮后，审查修正了错误类型的空限额参数回退默认值的问题；
新增拒绝测试，并在全新 trial-b 目录重新执行四轮。
trial-a 的结果、源码快照及证据原样保留，当前公开聚合对应修正后的 trial-b。

| 条件 | 接收扫描 / IMU | 处理 / 初始化 / 位姿 | 开头无 IMU 覆盖 / EOF 未覆盖 | IMU 暂存峰值 | 点云暂存峰值 |

所有接收扫描均归入处理或边界跳过，无故障丢弃；四轮结束均释放全部缓冲。
完整点云暂存峰值为静止 816,960 字节、行走 828,000 字节。
四组有效 header、算法时间和预处理点数/边缘化计数序列与对应基线完全相同。
在线位置与基线的最大差异约 4.71e-11 原始单位，不是与真实场地的误差。
没有据此批准扫描时间假设、外参、地图几何、回环或重定位。

记录时间轴上的最大扫描等待分别约 1.914、0、28.589、0 毫秒。
**时间轴来自 bag 的相对接收时刻，不是当前 CPU 墙钟：**
此回放没有按真实速度等待，也没有模拟算法处理期间的回调积压。
因此零等待不表示零交互延迟，28.589 毫秒不构成在线延迟保证，
更不能据此声称语音首响两秒、并发实时性或长期温升通过。

## 复算

`export_glim_stream_evidence.py` 重新核对四轮完整数组、原始采集、
源码快照、加载库及基线，并重新计算轨迹差异及耗时分位数。
公开的 `slam-stream-input-evidence.json` 只有白名单聚合和摘要，
不含坐标、轨迹、绝对采集时刻、设备地址、外参或凭据。
导出不连接机器人、不执行原生算法，拒绝覆盖已有结果。

```sh
rtk proxy python tools/run_glim_stream_trial.py batch \
  --baselines "$PRIVATE_CONTROL_RESULTS" --work "$PRIVATE_CPU_CORE" \
  --adapter "$PRIVATE_ODOMETRY_BUILD" --data-root "$PRIVATE_RECORDINGS" \
  --output "$NEW_PRIVATE_STREAM_RESULTS"

rtk proxy python tools/export_glim_stream_evidence.py \
  --results "$PRIVATE_STREAM_RESULTS" --baselines "$PRIVATE_CONTROL_RESULTS" \
  --data-root "$PRIVATE_RECORDINGS" --output "$NEW_AGGREGATE_JSON"
```

回放输出须位于忽略的 `.local/` 内全新目录，禁止路径或符号链接越界；
原始传感器数据、完整数组、日志和试验副本不进入 Git 或通用交付包。
独立重新导出只重算证据，不再次执行 SLAM。
