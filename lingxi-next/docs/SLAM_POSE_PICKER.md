# 点云初始位姿选取

日期：2026-10-31。此轮为离线源码和界面验证，没有连接或部署机器人，
没有运行原生 SLAM 或发送运动命令。产品及已交付 APK 版本仍为 0.1.19。

## 操作约定

- 保存地图继续显示点云投影，不转成占据栅格。
- 工具栏提供平移与初始位姿模式；选点时按下位置确定 X/Y，拖拽方向确定朝向。
- 根据当前画布宽高、缩放和平移反算地图坐标，地图正 Y 朝上。
- 橙色虚线表示初值草稿；蓝色标记只表示已确认的新鲜定位状态。
- 选点只编辑 X/Y/朝向，不填写或覆盖 Z/横滚/俯仰，不调用控制 API。
- 六个字段默认留空；全部明确填写且当前地图与会话可用时，才允许手动提交。
- 胸前雷达位置仍为 `native-raw`，角度输入为度，不代表底盘坐标或米制标定。

单击、少于 12 像素的拖拽、画布外松开、取消及 Escape 不生成新草稿。
视图在拖拽中变化时不提交；同地图换定位会话也会丢弃旧画布捕获的手势。
草稿绑定 session、地图 ID、收据/点云/配置摘要及输入模式。绑定变化、
断线、状态过期或控制派发会清空字段；恢复后不自动复用旧初值。
地图预览必须匹配当前定位绑定。提交仍使用既有带代次/参考帧的 HTTPS 接口，
202 只表示请求接受，不能当成匹配成功；失败或确认不明时不自动重试。

## 后续：建图首末帧参考初值

同日新增参考位姿选择，减少现场手工查找六自由度初值的工作。
它使用经地图清单摘要验证的 `map/traj_lidar.txt`，不是 `odom_lidar.txt`、
IMU 轨迹或固定零位姿。固定 GLIM 提交
`1a197c999e4865f5cab7c9cd25474128413ebbca` 的
[原始保存实现](https://github.com/koide3/glim/blob/1a197c999e4865f5cab7c9cd25474128413ebbca/src/glim/mapping/global_mapping.cpp#L606)
确认格式为时间、XYZ、四元数 XYZW，位姿方向为最终地图到雷达。

只有包含传感器配置来源的 schema-2 地图才提供参考值；预览接口可选返回
`seedReferences`，包含来源/坐标标签、轨迹摘要、配置摘要、帧数及首末帧矩阵。
读取后再次核验轨迹摘要，完整检查所有行的帧数、有限值、严格递增时间和单位四元数。
时间按整数纳秒比较；只归一化原生六位小数输出允许的 2e-6 模长舍入差。
参考解析上限为 8 MiB、100,000 帧。缺少来源或轨迹元数据不可用时仍可看图和
手工填初值，但不提供虚构的首末帧。没有改写收据、轨迹或厂商地图文件。

界面选择“建图首帧/建图末帧”只载入三维位置和完整旋转的草稿。
旋转使用与已有提交一致的 ZYX 欧拉角，奇异角采用等价表示，角度显示保留至九位小数。
操作员必须确认“当前位置与参考位姿一致”，再单独提交；换参考值、手动编辑、
连接/绑定变化或断线会撤销确认。选择和确认本身均不发送定位或运动命令。
首帧指最终轨迹的第一个有效保存帧，不等于物理地图原点或导航返航点。
复选框只是操作员声明，不是独立的现场位置、雷达姿态或匹配精度证明。
