日期：2026-10-29。**目标端入口已编写，尚未在机器人执行。**
这是准备提交时的历史边界；后续首次真实 ARM64 监督回放的结果单独记在
`SLAM_SUPERVISED_ARM64.md`，不以新结果改写本记录中的原始验证范围。
本轮没有连接机器人、上传文件、启动 ROS、采集新数据、发送运动命令、
修改 SDK/服务或构建新部署包。现场静止、看护和急停条件仍待明确确认。

这一步准备 ARM64 生命周期验证，不是独立 SLAM 的产品后端接入。
当前管理 API、网页、APK 和 0.1.19 归档仍使用原 AIMDK 接口。

## 共用会话循环

`tools/run_glim_supervised_replay.py` 将 `recorded_child` 从电脑端绑定中分离：

- 平台绑定提供完整输入校验、原生工厂、实际库核验、CDR 解码和版本信息。
- 会话循环仍使用原 `SensorWorker`、`SensorStream`、健康 IPC 和私有 stop 管道。
- 同一非主线程创建、调用和关闭原生实例；一个子进程只初始化一次。
- 原有队列、处理、静默、进度和退出时限没有改变；失败不会自动重试。
- 只有全部回调处理完成才请求正常退出，不把生产者 EOF 当作完成。
- stdout 仍只传健康状态；原生输出进入 mode-0600 私有日志。

电脑端继续使用固定 rosbags 解码器，没有改成 ROS 依赖。
`tools/glim_supervised_target.py` 为目标端提供已安装 Humble 的解码绑定；
它不调用 `rclpy.init`、创建节点或订阅 DDS。类型支持在工作线程启动前检查。
本地测试使用明确标记的合成解码器，不能证明实际机器人已安装的模块通过。

此前原生 C ABI、算法库、配置、工作线程、录制及历史诊断运行器保持不变。
新的共用循环是本轮实际回归对象，不能用旧版本成功记录替代检查。

## ARM64 入口约束

父入口 `run` 需要 `--operator-confirmed`；没有明确确认，输入加载和进程创建
均不会发生。该标志只是本地运行前置条件，不等同于现场人员实际确认，
也不是对网页、模型或远程用户开放的控制接口。

路径全部由可信本地组合指定：

- `--root`：原有、完整、未变更的 matched-input 私有 bundle。
- `--core-root`：原有独立 ARM64 core，不覆盖厂商 AIMDK。
- `--reference`：同一 bundle、同一时间假设的完整 live 参考记录。
- `--output`：新的私有忽略目录，不能与以上输入目录重合、包含或嵌套。
- `--hypothesis` 与 `--rate`：必须明确选择；不自动选择更有利的假设或降速重试。

仅支持普通用户的 Linux aarch64 / Python 3.10。显式子环境限定已安装
Humble Python 路径和本次核验的库路径，不继承凭据、ROS_DOMAIN_ID、
ROS_DISTRO、RMW 配置或 LD_PRELOAD。目标端 OpenMP/OpenBLAS 均为 2，
与原 ARM64 离线验证环境一致，不把电脑端线程设置直接套用到机器人。
NumPy 版本必须与 live 参考记录一致。

启动前检查原 bundle/core 清单、原始配置/profile、工作线程源码和参考记录。
参考的日志、结果数组、完整 CDR journal 均核对摘要，journal 再核验 footer。
只处理了前缀、存在停止丢弃、拒收、排队残留或非正常退出的参考会被拒绝。
不会将历史带尾部丢弃的采集静默当作完整输入。

源码及参考按字节摘要暂存到新的私有运行目录；旧 bundle、core、
原始参考和厂商地图原位保留。子进程用新源码、原库/配置及暂存参考，
父子重复校验，退出后再检查原输入。低优先级只作用于本次自有子进程；
没有更改系统调度配置或厂商进程。

**这些路径和环境约束已做本地检查，目标端完整执行仍未验证。**
当前没有目标端成功证据或自动部署/SSH 协调器；不能据此发布可用安装包。

## 电脑端真实回归

新的共用循环已在新的 x86 子进程 h 中按原速重放同一份既有完整 journal：

- 4,144 次回调全部完成，197 帧点云、3,947 条 IMU，无拒收或丢弃。
- 196 个原生扫描，31 个初始化结果、165 个位姿，1 个首 IMU 前扫描单独记账。
- 原生创建/关闭各一次，工作线程、管道、自有进程组和监督线程正常回收。
- 最大已观测队列年龄约 71.676 ms；工作段墙钟约 19.969 s。
- 原生完整 frame 墙钟 P95 约 37.136 ms、最大约 73.431 ms。

脱敏聚合为 `slam-supervised-portable-evidence.json`。h 是本轮共用循环的
电脑端证据，不是 ARM64 证据，不证明实时 DDS、几何精度或产品性能。
此前 g 的 `slam-supervised-native-evidence.json` 保留其原源码摘要及结果，
不改写历史证据使其看似来自新代码。

完整工具套件：Linux 558 项全部通过、无跳过；
Windows 253 项通过、305 项明确跳过。新增 12 项目标端合成检查覆盖

父进程失败清理、机器/会话/速率匹配及 Humble 解码绑定。
Python 编译和 Git 空白检查通过。没有用合成测试宣称硬件验证通过。
