# 单预处理线程的完整建图对照

日期：2026-10-28。**电脑端 12 个独立进程均完成完整建图、保存和新进程重载；
同条件的子图划分与点数重复一致，在线轨迹数值差异很小，但完整点云并非逐位相同。**
这不是地图几何、扫描时间标定、回环、重定位、实机实时性或导航验收。
机器人 ARM64 的完整建图单线程对照仍未执行，不能用此前 ARM64 预处理结果代替。

本轮仅离线读取已采集记录，不连接机器人、不启动 ROS 或实时订阅，
不发送运动命令，不更改模式、输入源、厂商系统、已有地图、产品后端或 APK。

## 对照设计

此前的 `SLAM_PREPROCESS_REPEATABILITY.md` 和 `SLAM_ARM64_PREPROCESS.md`
已经比较完整预处理点及邻居，但没有覆盖完整 SLAM。
本轮复用原有里程计、建图 C ABI 和固定的 CPU 核心；
没有修改现有 C++、编译库、历史运行器或历史试验结果。

新增 `run_glim_controlled_mapping.py` 通过原有原生工厂和回调接入完整建图：

- 保留原样生成的 `config/`，另建 `control-config/`；
  唯一算法参数变化为 `preprocess.num_threads: 2 → 1`。
  这里是单个预处理线程，不是整个 SLAM 全部变成单线程。
- 使用固定 JSON5 解析器处理上游含注释的配置，更新实际配置文件哈希和清单。
  注释、缩进可以不同；其他传感器、距离、里程计和建图参数不变。
  外参、IMU 噪声、同步及扫描时间假设仍未获标定批准。
- 静止/行走、header 为扫描起点/终点，各三个新进程，共 12 轮。
  不根据点数、轨迹长度或图片选择有利条件。
- 原始记录、配置、实际加载库、源码快照和完整结果均按内容摘要核对。
  所有有效帧只送入建图一次；独立进程重载全部地图并比较完整点序。

环境为隔离 x86_64 Linux / Python 3.12.3，NumPy 2.5.4、
rosbags 0.11.9、JSON5 0.12.1；绘图使用 matplotlib 3.10.7。
新环境位于独立缓存，未修改旧环境或安装系统软件。
GTSAM、gtsam_points、GLIM 的固定提交及原生库来源见聚合证据，
沿用 `SLAM_CPU_BUILD.md`，不是重新选取最新上游版本。

## 重复性结论

每个条件的三轮全部两两比较，共 12 对，不挑选最接近的一对：

- 完整整数 header、算法时间和有效域一致，没有插值或强行关联不同帧。
- 子图划分、逐扫描预处理点数和边缘化计数序列一致。
  完整建图轮次没有保存每帧预处理点，点数一致不证明预处理内容一致。
- 在线位姿不是逐位相同。静止最大位置差异约 2.57e-12，
  行走起点/终点假设分别约 3.41e-11 / 2.82e-11 原始单位。
- 保存文本中保留六位小数的全局位置差异为零；
  文本舍入后的相同不代表底层所有浮点结果相同。
- 所有比较的完整地图点数一致，但有序坐标位模式和保留重复点的
  完整坐标多重集均不相同。因此不能声称完整地图逐位稳定，
  也不能把不同文件哈希仅归因于点序。

本轮尚未测量重复地图的最近邻几何差异，也未建立可靠的一一对应点关系。
轨迹数值接近、点数一致或缩略图相似，都不能代替完整地图几何验收。
结果支持继续验证此诊断配置，但不是单线程生产参数的批准，
也不能证明历史电脑/机器人地图分歧的唯一原因。

## 时间假设仍未解决

另比较起点三轮与终点三轮的全部九种组合，每种数据各九对，共 18 对。
共同 header 为静止 311 帧、行走 1,189 帧；
同一个 header 在两种假设下指向不同扫描时刻，最大约相差 0.095181 秒。
这些不是相同时刻的精度比较。

行走两种假设间的在线最大位置差异约 0.26150 原始单位；
保存文本的全局位置最大差异约 0.16567，
只移除首个共同位姿刚性偏移后约 0.16614。
没有尺度拟合、最优轨迹配准或外部真值。
两种假设产生 7 / 10 个子图和明显不同的点数，不能按“点更多”选定正确时间基准。

行走估计三维累计步长约 8.2189 / 9.8083，XY 累计约 7.8452 / 9.4587；
末端距起点约 0.66594 / 0.74616，均为未校准的算法原始单位。
不把这些数值强行缩放到用户约 5 米的回忆。
雷达回波范围的独立核查见 `LIDAR_RANGE_INSPECTION.md`，
行走路程不是雷达扫描距离或地图尺寸。

## 复算

`export_glim_controlled_mapping.py` 重新核对全部 12 轮、完整数组、
保存文件清单、逐点重载差异及原始采集，导出
`slam-controlled-mapping-evidence.json`。
公开文件只有聚合、来源摘要和未通过的验收边界，不含点坐标、
轨迹、绝对采集时刻、设备地址、实际外参或凭据。

```sh
rtk proxy python tools/export_glim_controlled_mapping.py \
  --results "$PRIVATE_CONTROL_RESULTS" --work "$PRIVATE_CPU_CORE" \
  --adapter "$PRIVATE_ODOMETRY_BUILD" --mapping-adapter "$PRIVATE_MAPPING_BUILD" \
  --data-root "$PRIVATE_RECORDINGS" --output "$NEW_AGGREGATE_JSON"
```

参数必须显式指定，输出必须是新文件，不覆盖任何历史结果。
独立重新导出后进行逐字节比较；这只重算证据，不重跑 SLAM。
合成测试与真实 12 轮记录分开统计。
