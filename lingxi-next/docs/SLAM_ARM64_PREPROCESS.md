# ARM64 原生点云预处理重复性与耗时

日期：2026-10-28。本轮使用机器人普通用户的隔离目录回放已有记录，
不运行实时建图、里程计、ROS 节点、实时订阅或运动接口。
全部 12 轮及完整输出已核对；以下为最终聚合，不是完整 SLAM 或导航验收。

## 来源与执行边界

复用 `SLAM_PREPROCESS_REPEATABILITY.md` 中未改动的 C++ 适配层，
调用真实固定版本的 `glim::CloudPreprocessor`，没有重新实现采样算法。
同一批原始静止/行走记录、同一份配置文件和既有 ARM64 CPU 核心保持不变。
配置内容摘要必须与电脑端重复性证据相同，全部原生源码摘要也逐一匹配。
新的交叉编译库为 ELF64/AArch64，SHA-256：
`8fc5dd7d1aafc92c3460b46e7e4b13f30828a09ea0a3eeef5da7daa8af2f1707`。

预声明静止/行走、原双线程/单线程诊断对照各三轮，共 12 个新进程。
只在参数对象中指定 2 或 1 个预处理线程；不改写配置文件，
不据此选定生产配置。两组的 OpenMP/OpenBLAS 环境均保持 2 线程，
以 nice 10 执行，每子进程 300 秒外层上限，10 秒退出宽限。
这些限制不等于系统级 CPU 硬配额或生产资源保障。

保留原先未批准的扫描终点时间假设，用 IMU 时间覆盖范围筛选扫描，
不把 IMU 姿态、加速度或角速度送入预处理器。
目录内独立保存所有 x/y/z/逐点时间 float64、邻居 int32 索引、
完整整数 header、输入字节摘要以及逐帧调用耗时。
每轮前后核对全部五个原始采集文件的 SHA、SQLite 检查及 topic 计数。
原始数据和完整结果只保留在机器人新试验目录及本机忽略的私有缓存。

目标端核对 `/proc/self/maps` 中实际加载的库路径及内容摘要，
必须来自新适配目录或已验证的核心目录。版本化 SONAME 只接受核心清单中
已声明、已校验的别名，不接受来自其他目录的同名库。
SSH 保留已知机器人身份校验，密码仅交互输入内存，不写入源文件或报告。
不安装系统包，不更改 AIMDK、步态、安全链路、服务、输入源或既有地图。

第一轮 trial-a 在处理扫描前因库来源校验退出：代码错误地只接受无版本号
`libgtsam_points.so`，而 ELF 实际依赖 `libgtsam_points.so.1`。
失败目录、报告和日志完整保留；新增版本化名称及外部目录拒绝测试后，
以新的 trial-b 目录执行全部预声明条件，不把失败试验计入有效三轮。
原生 C++ 与编译出的适配库内容没有改变。

## 完整点输出比较

比较所有有效帧，不选择有利的共同子段。原始输入坐标/时间字节摘要、
整数 header、算法时间和原始点数必须先全部相同。
比较全部 xyzt 的精确 float64 位模式；顺序不同时，比较保留重复点的
完整多重集，不使用最近邻、坐标容差或抽样。邻居只在有序点完全相同时比较。

每轮静止读取 353 帧，处理 342 帧、跳过 11 帧；行走读取 1,232 帧，
处理 1,220 帧、跳过 12 帧。所有有效帧的采样分支均激活。
机器人同条件三对比较的差异帧数如下：

| 数据/预处理线程 | 点数差异 | 实际 xyzt 多重集差异 |
|---|---|---|
| 静止/2 | 0 / 0 / 0 | 145 / 153 / 157 |
| 静止/1 | 0 / 0 / 0 | 0 / 0 / 0 |
| 行走/2 | 8 / 9 / 11 | 395 / 412 / 525 |
| 行走/1 | 0 / 0 / 0 | 0 / 0 / 0 |

每个数据/线程条件再比较电脑三轮与机器人三轮的全部九种组合，
共 36 对，不选择最接近的一对。单线程的 18 对全序列点、逐点时间、
顺序和邻居索引逐位相同；不是只验证点数或点多重集。
双线程静止九对多重集差异为 199–223 帧，点数全部相同；
行走九对多重集差异为 759–828 帧，点数差异为 10–15 帧。
本轮所有 48 对比较均没有“仅顺序不同”的帧；
有序点完全相同的帧，其邻居索引也完全相同。

这证明相同预处理源码可在本轮单线程对照中跨架构产生相同输出，
同时原双线程在机器人本身也存在重复差异。没有逐块调度/RNG 轨迹，
不能将源码机制推断写成完整运行原因证明。
历史建图报告、轨迹和完整地图结果保持原样，不用新预处理输出替代旧输入。
跨架构的完整点一致性仍不等于完整 SLAM、地图几何或定位精度一致性。

## 耗时定义

`private-metrics.npz` 保存每个有效帧的单调时钟调用墙钟纳秒和进程 CPU 纳秒，
不是只保存平均值。导出工具核对长度、整数类型和有效范围，
重算 P50/P95/P99、最大值与全序列总和。

调用边界包括 Python/ctypes 输出缓冲分配、原生输入复制、真实预处理和输出复制，
不把它称为纯采样内核耗时。该边界不含 bag 读取、消息解码、输入摘要、
私有输出写盘、网络回传、里程计或全局建图。
处理循环墙钟/CPU 另行记录，包含点云读取、解码、摘要和完整输出写盘，
不含先行的 IMU 时间读取及前后采集完整性核对。
总墙钟记录到采集后验核对结束，不包含最终结果文件摘要和网络回传。
峰值常驻内存是单个回放进程的观察值，不是整机预算。

三轮实际范围如下，单位分别为毫秒、秒、MiB：

| 数据/线程 | 调用墙钟 P95 | 调用最大墙钟 | 处理循环墙钟 | 峰值常驻 |
|---|---:|---:|---:|---:|
| 静止/2 | 8.83–9.23 | 11.36–13.13 | 4.47–4.49 | 98.12–101.16 |
| 静止/1 | 12.18–12.24 | 12.92–13.14 | 5.84–5.90 | 97.25–98.00 |
| 行走/2 | 9.24–9.42 | 14.06–16.24 | 15.91–16.11 | 98.34–101.73 |
| 行走/1 | 12.89–13.05 | 16.84–17.12 | 20.89–21.01 | 96.04–99.77 |

单线程行走全序列调用 CPU 合计 14.35–14.41 秒，
双线程为 15.23–15.24 秒；CPU 时间不是墙钟时间或整机 CPU 利用率。
静止/行走有效 header 跨度为 34.096599 / 121.900235 秒，
header 间隔中位数约 100 ms。输出回传约数分钟/轮的网络时间不算算法耗时。

不把离线回放与录制时长之比当作实时保证。原生实时输入排队、完整建图、
地图保存、语音/模型并发、长期运行、热限制及失效恢复仍须独立测量。

## 复算与检查

`build_glim_target_preprocess.py` 交叉构建及打包实际固定适配层；
`run_glim_target_preprocess.py` 执行预声明轮次并下载、校验完整结果；
`export_glim_target_preprocess_evidence.py` 重算全部数组比较及每轮资源统计，
白名单导出 `slam-arm64-preprocess-evidence.json`。
私有输入、输出、实际外参配置和凭据不入库。公开证据只有聚合及摘要。

所有参数显式指定，在已有隔离 Linux NumPy 环境复算：

```sh
rtk proxy python tools/export_glim_target_preprocess_evidence.py \
  --bundle "$PRIVATE_PREPROCESS_BUNDLE" --results "$PRIVATE_PREPROCESS_RESULTS" \
  --core-bundle "$PRIVATE_CORE_BUNDLE" --adapter-build "$PRIVATE_ADAPTER_BUILD" \
  --host-core "$PRIVATE_HOST_CORE" --host-adapter "$PRIVATE_HOST_ADAPTER" \
  --host-results "$PRIVATE_HOST_RESULTS" --data-root "$PRIVATE_RECORDINGS" \
  --output "$NEW_AGGREGATE_JSON"
```

输出必须是新文件；不覆盖已有记录。公开证据由第二次独立全量导出生成，
与先前私有导出逐字节比对；原始录制和全部结果在导出前后再次核对。
合成测试覆盖线程条件、来源/SONAME、完整数组和计时、篡改/不完整结果拒绝、
无实时订阅/运动边界、完整公开组合及隐私。
两次导出逐字节相同，SHA-256：
`62724ae9616273d4e17318101ffdc1860e6894d9c5380b9bfa5443fcb73d506f`。
本轮全部工具测试：Linux 273 项通过、无跳过；
Windows 154 项通过、119 项 Linux/NumPy 专用测试明确跳过。
真实上游配置检查通过固定 Linux 检出执行；前端、Java、Android 未改动或重建。
