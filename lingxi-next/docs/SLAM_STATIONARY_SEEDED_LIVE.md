日期：2026-10-31。用户在本轮明确确认测试期间机器人保持原地、胸部姿态不变。
本轮在普通用户独立目录运行，不更改厂商服务、安装指针或生产配置，不发送行走、

## 本轮结果

新增 `tools/check_stationary_seeded_live.py`，以配对 HTTPS 接口完成：

1. 被动接收实时雷达/IMU，建图、保存并独立进程重载。
2. 读取本轮新地图的已校验末帧雷达参考位姿；检查地图、点云、收据、传感器配置、
   轨迹摘要和当前帧绑定，只提交一次初值。不复用旧地图位置，不自动重试。
3. 至少三次匹配确认后观察诊断跟踪，检查同会话/代次、递增帧和未开放的导航就绪标志。
4. 暂停立即撤销位姿；旧初值请求返回 409；停止后连续十次查询不恢复位姿。
5. 显式关闭定位及父管理进程，核验子进程正常退出、原生所有权和最终清理。

| 实际 ARM64 观察 | 结果 |
| --- | --- |
| 新地图 | 90 帧、1 个子图、2,779 点，保存/新进程重载成功 |
| 初值来源 | 新静止地图的最终优化雷达轨迹末帧；一次显式请求 |
| 首次诊断 tracking | 初值提交后约 0.327 秒 |
| 持续观察 | 约 10.085 秒，HTTPS 轮询观测到 91 个不同帧，帧号 4 到 105 |
| 相对首个观测的最大平移变化 | 0.0116702 原始单位 |
| 相对首个观测的最大旋转变化 | 约 0.178719 度 |
| 定位原生输入 | 144 次扫描、113 个里程计位姿、2,896 次 IMU 插入 |
| 原生创建/关闭 | 各一次，正常清理 |
| 暂停/停止/旧请求拒绝 | 全部通过，停止后十次查询均不复活 |
| 独立最终观察 | 零遗留测试进程，测试端口关闭，原管理端口仍监听 |

91 是不同的轮询观测帧数，不是每个处理帧均已外部采样的证明。平移变化是未经独立
尺度标定的原始单位，不能换写为厘米定位误差；旋转变化也是估计抖动，不是对真实
方向的测量误差。0.327 秒是定位初值提交到首次轮询观测的时间，不是语音首响延迟。

机器人位姿不变的关联来自操作员确认，不是测量装置提供的独立真值。地图和定位
采用先后两个实时会话，定位输入不是重复播放建图记录，但场景与雷达姿态相同。
这个小范围静止检查不证明移动中的定位、重复场景拒绝、全局重定位、长时稳定性、
局部避障或完整地图精度。测试通过后 `localizationReady` 和 `navigationReady` 仍为 false。

按时刻机身 TF 输入在本轮有 143 次有效查询，无无效时间/变换或查询错误；
`metresPerMapUnit=1.0` 仍只是诊断配置，不是物理尺度或外参验收。
