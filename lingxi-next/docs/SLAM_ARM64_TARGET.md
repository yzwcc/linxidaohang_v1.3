# ARM64 真机隔离加载与合成执行

日期：2026-10-28。结论：**机器人实际加载四个 GLIM CPU 模块，
并运行 ARM64 合成时间检查程序成功。不是 SLAM、实时性或导航验收。**
前一阶段的交叉构建边界与来源见 `SLAM_ARM64_BUILD.md`。
本文保留合成阶段记录；后续真机真实记录回放结果见
`SLAM_ARM64_RECORDED.md`，不把后续结论回填到此前合成报告。

## 实际执行

使用此前固定源码、Jammy ARM64 交叉构建目录中的库及合成可执行文件，
不重新编译上游、不改变其参数，也不将 x86_64 的离线结果冒充实机性能。
本机工具将库别名物化为独立普通文件，因此试验目录的体积包含重复别名，
不是最终交付包体积。32 个有效载荷文件共 52,191,936 字节，
加上传清单一共 33 个文件。

只向机器人普通用户的新目录
`~/lingxi-next-validation-arm64-20261028-a/` 复制验证文件。
同名目录或本地结果存在即拒绝复用，不删除旧结果。
目录 700、普通文件 600、合成可执行文件 700。
不执行 APT 安装、sudo、ldconfig、模式切换、输入源切换或服务管理命令。
不覆盖 AIMDK、步态、安全链路、系统库或现有 0.1.18/0.1.19 软件。

连接使用严格 SSH 主机密钥核对，新的 IP 必须与显式指定的已知机器人身份一致；
即使该 IP 已在 known_hosts 中，也再次核对实际连接的服务器密钥。
密码通过 getpass 仅存在于进程内存，不进入命令参数、文件或 Git。

探针用清空继承环境后的独立进程运行，
显式设置唯一的试验 `LD_LIBRARY_PATH` 和 2 线程上限，
不继承 ROS、PYTHONPATH 或 LD_PRELOAD。
外层执行上限 120 秒并有 5 秒终止宽限，
合成子程序独立设置 30 秒上限。
本轮正常退出 0，不依靠超时终止来宣称通过。

## 结果

目标观测为 AArch64、Python 3.10.12、glibc 2.35。
在目标 Python 进程中使用 `RTLD_NOW | RTLD_LOCAL` 实际加载：

- `libodometry_estimation_cpu.so`
- `libsub_mapping_passthrough.so`
- `libglobal_mapping_pose_graph.so`
- `libglobal_mapping.so`

读取该进程的 `/proc/self/maps`，观察到 9 个试验库，包括 GLIM、
GTSAM、GTSAM points、metis、cephes 和上述四个模块；
它们均来自独立上传目录，内容 SHA-256 与已核对清单一致。
没有拿其他已安装的同名试验库替代验证。
系统 libc、libstdc++、OpenMP、Boost 等仍由机器人原有系统提供，
没有私自替换，实际加载成功是比版本号推测更直接的证据。

随后实际运行之前交叉链接的 ARM64 `lingxi_glim_time_smoke`，
程序自行动态加载前三个模块，再进行合成时间转换检查。
结果为基准 1000 秒、首点 0.000332 秒、末点 0.095181 秒，
模块计数 3、退出码 0，合成分类与未标定/未导航标记均正确。
探针及该子进程已退出，SSH 客户端已关闭，没有新增 ROS 或常驻进程。

约 0.226 秒只包含这次模块加载和极小合成检查，
**不是点云处理帧率、建图速度、内存压力或语音并发性能**。
没有在机器人上处理真实点云/IMU，未运行 Humble 包或真实建图节点，
没有改变已有地图/点位，也没有调用导航或运动接口。
本机真实地图保存/重载证据仍单独见 `SLAM_GLIM_MAPPING.md`。

## 复现与证据

工具分为三个执行边界：

1. `prepare_slam_target_bundle.py`：本机复核交叉构建及产物 SHA、ELF 架构、
   合成配置来源，再物化新试验目录；不连接机器人。
2. `run_slam_target_trial.py`：显式指定主机、普通用户、已知身份、新目录，
   SFTP 上传已校验文件，以固定有界命令运行探针；不接受任意远程命令。
3. `slam_target_probe.py`：机器人标准库探针，核对全部清单内容，
   真实加载并核对进程映射，运行合成可执行文件；没有 ROS/网络/运动 API。

`export_slam_target_evidence.py` 重新核对本地 bundle、原始交叉产物、
目标返回内容的摘要、目标实际库哈希、合成转换结果及目标探针源文件哈希，
输出 `slam-arm64-target-evidence.json`。它没有实际 IP、用户名、密码、
主机名、设备序列号、环境文件或业务数据。
公开的 `toolSourcesAtExport` 明确表示本机工具在导出时的版本；
不是补写一个未在旧运行报告中记录的运行器来源字段。

完整上传清单与本地原始报告保留在忽略的
`.local/slam-target-bundle-20261028-a/`、
`.local/slam-target-report-20261028-a.json`，
不进入 Git、APK 或通用交付包。合成 bundle 不是许可证/依赖已完整冻结的
发布包；所有依赖的发布核查仍是最终交付前置条件。
历史交叉构建报告保持原样，不把其未执行标记改成真机通过。

本轮工具测试：隔离 Linux 167 项通过，无跳过；
Windows 128 项通过，39 项 Linux/NumPy 专用测试明确跳过。
覆盖包内容核对、仅合成配置、同名结果保护、显式普通用户目录、
固定有界命令、主机身份核对、库实际来源和合成转换结果检查。
