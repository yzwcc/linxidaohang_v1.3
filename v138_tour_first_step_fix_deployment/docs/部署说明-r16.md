# V1.3.8 r16 讲解首点修复部署说明

版本：`1.0.0-20261022`，r16 专用。

## 1. 适用范围

用于 `lingxi-v1.3.8-complete-20261019-r16-deployment` 完整包，
当前 release 必须是 `1.0.19-20261019-r16`，无需升级至 r20。

本包从 r16 实际运行文件适配，只更新讲解调度代码，不替换成 r20 全部代码。
安装器校验 bridge、navigation_client、启动脚本及运行清单，拒绝覆盖未知修改。
只修改 Java 的其他增量不影响此检查；改过 bridge/client 的增量需核对基线。

## 2. 修复及保留

1. 并发启动只允许一个请求占用讲解任务，避免网页和语音重复请求覆盖首点状态。
2. 任务、步骤和导航尝试绑定独立代次，旧任务回调不能推进当前任务。
3. 导航请求尚未受理就被拒绝时，重试当前点，重试用尽暂停在当前点，可在网页继续。
4. 首个启用步骤缺少点位或引用无效点位时，拒绝启动并报告配置问题，不会静默过滤首点。
5. 增加首点、任务代次和导航会话日志，便于排查偶发问题。

真正已受理后发生的导航超时或不可达，仍按 r16 原有策略继续后续步骤。
禁用的步骤仍跳过。这两种情况与本次“请求尚未受理却跳到第二点”不同。

不重装 AIMDK，不更新 Java、TTS、语音配置、地图、点位、任务数据、密钥或知识库。
保留 r16 原有播报行为；本包不额外包含 r20 的底层播报抑制或 TTS 确认改动。
本次未连接、部署或驱动现场机器人，需要部署后验收实际顺序。

## 3. 部署

将以下两个文件上传到机器人 `/home/run/`：

- `sparkrobot-lingxi-v1.3.8-tour-first-step-fix-r16-1.0.0-20261022.tar.gz`
- `sparkrobot-lingxi-v1.3.8-tour-first-step-fix-r16-1.0.0-20261022.tar.gz.sha256`

先在网页停止讲解任务和导航，确保机器人静止。安装期间不要发起新任务。
无需停掉 Java/灵心服务，执行：

```bash
cd /home/run &&
sha256sum -c sparkrobot-lingxi-v1.3.8-tour-first-step-fix-r16-1.0.0-20261022.tar.gz.sha256 &&
tar -xzf sparkrobot-lingxi-v1.3.8-tour-first-step-fix-r16-1.0.0-20261022.tar.gz &&
cd /home/run/sparkrobot-lingxi-v1.3.8-tour-first-step-fix-r16-1.0.0-20261022 &&
sudo bash ./install.sh --check &&
sudo bash ./install.sh
```

检查不通过会停止执行；不要编辑安装器绕过检查。
安装器先备份，保留文件权限，并恢复安装前的导航服务运行/停止状态。
如果安装前服务全部停止，安装后仍停止，可在网页一键启动。
部分服务运行、活动导航或讲解任务会阻止安装。
启动失败会尝试恢复备份；恢复失败会明确报错并保留备份路径。
重复安装同一补丁不会重复重启。所有校验文件及 Shell 脚本均使用 LF 换行。

## 4. 检查与验收

```bash
sudo -u agi /opt/sparkrobot/lingxi-nav/current/scripts/navigation_control.sh status
sudo sparkrobot-lingxi-internal doctor
curl -fsS http://127.0.0.1:18082/nav/status | python3 -m json.tool
sudo python3 - <<'PY'
import json
from pathlib import Path
p = Path("/opt/sparkrobot/lingxi-nav/current/payload-manifest.json")
print("tour_first_step_fix=" + str(json.loads(p.read_text()).get("tour_first_step_fix")))
PY
```

补丁标记应为 `tour_first_step_fix=1.0.0-20261022`。
如果安装前服务已停止，请启动后再进行在线检查。

在网页确认第一点启用、点位有效，保存任务。机器人从离首点明显较远的位置开始，
应先去第一启用点，完成讲解和等待后再到第二点。分别用网页与语音多次验收。
停止后重新开始应从首点执行；暂停后继续应继续当前点。

实时看日志：

```bash
sudo tail -n 120 -F /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
```

第一条 `Tour task step starting` 应为 `step=1/总数`。
`Ignoring stale tour navigation callback` 表示过期回调被拦截；
`retrying same step` 表示仍在重试当前点。
已受理后的真实失败仍记录在 `failed_steps`。

## 5. 回滚

安装器输出事务备份路径，形如：
`/var/lib/sparkrobot/lingxi-tour-first-step-fix/backups/时间-随机后缀`。
停止网页讲解任务与导航后，在本增量包目录执行，替换为实际路径：

```bash
sudo bash ./install.sh --rollback /var/lib/sparkrobot/lingxi-tour-first-step-fix/backups/实际备份目录
```

回滚恢复原文件、清单和权限，保持回滚前运行/停止状态。
若安装后又有其他文件更新，回滚不会覆盖后续修改，应按后装先退处理。
