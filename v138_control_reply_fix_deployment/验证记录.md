# V1.3.8 控制响应修复 1.0.3 验证记录

日期：2026-10-18。分支：`codex/lingxi-v1.3.8-special`。

## 现场问题与测试方法

新增 `FieldVoiceReplayTest`，使用实际 AgentSDK 1.4.0 的 `Asr2Llm`、`Asr2Tts` 回调和序列化，连接本机模拟模型/导航/动作 HTTP 服务。测试同时覆盖 `tts.mode=lingxi` 与 `tts.mode=robot`，检查 SDK 消息、HTTP 请求次数和实际提交的 TTS 文本，而不只检查内部方法返回值。

首轮现场回放共 352 条断言，直接加载已交付 1.0.2 归档内旧 JAR 时有 200 条未通过，修改后全部通过。这些是不同回调/语音路径/异常组合，不是 200 个独立缺陷。随后补充真实 HTTP 503、动作拒绝/确认未知及多种完整身份提问；最终测试数量和结果记录在交付 `release.json` 及外部 `交付验证结果.json`。

回放覆盖：

- 带我去软着陆、保存的讲解命令、比心：只提交一次 HTTP 控制，使用无提示语的 SDK `chat` 响应，不再返回空 `action`，不采用模型“做不到”作为成功确认。
- 打个招呼、打个招呼呗、跟大家打个招呼、请你打一下招呼：分别注入非法 `greet` 意图、`greeting` 动作别名、错误 chat、正确 wave。明确请求均进入一次挥手，不产生问答不可用或拒绝模型回复。
- 唱首歌、跳个舞及礼貌变体：正确意图和无效 JSON 下均不追加本地娱乐 HTTP、SDK 技能或动作中断，不产生功能关闭/空间/问答故障播报。
- 实际 HTTP 503：验证确实注入并进行了既有的一次有界模型重试；明确打招呼可提交一次本地动作，歌舞不追加本地表演，不播错误的问答故障。
- 打招呼的真实拒绝和确认未知：保持静默，不伪称接受，不为了确认重发动作。
- “那你是”“你是”“那你”“我想”“那个”：不请求模型，不唤醒讲解，不产生自我介绍。
- 显示名编码异常时，与问题无关的“我是……现场服务和互动机器人”仍被清理；“你是谁”“你是什么机器人”“介绍下自己”保留正常回答。
- 唱歌能力/含义问题及模型答案里的舞蹈建议不会被当成实际表演指令，普通问题可以继续回答。
- 否定、转述、假设及能力询问不会进入打招呼的本地动作补偿。

测试场景彼此隔离去重表和 TTS 播放状态，避免上一场景的模拟播放影响下一场景；同时保留独立的真实去重/并发/唤醒回归。SDK 事件 ID 不含注入的模型回复正文，避免把事件标识中的测试文本误当成真实播报。

## 原有回归

运行全部 12 个 Java 回归入口：

1. `VoiceGateTest`：1419 条音频质量元数据门控断言。
2. `WakeSessionGateTest`：28 条唤醒/会话边界断言。
3. `Soc2WakeEvidenceProviderTest`：8 条 SOC2 证据断言。
4. `AgentSdkInterruptWireTest`：51 条实际协议断言，现明确验证本地控制使用 `chat`、空提示语及事件信息不变。
5. `VoiceRegression`：47 条语音回归，以及实际 Agent 门控回归（增加原生唱跳保留用例）。
6. `ModelRecoveryTest`：文本输入、暂态重试、认证错误、无效意图、桥接故障及下一次请求恢复。
7. `FunctionalControlTest`：42 条灵活意图、明确点位补偿、未知点位拒绝、动作确认及自定义任务断言。
8. `AgentConnectionStateTest`：早到回调、认证失败、离线、重启与原子状态写入。
9. `ControlReplyRegressionTest`：566 条控制响应断言，覆盖两个回调模式、两个播报路径、重复/并发请求、SDK 完成传输异常和真实拒绝。
10. `ControlOwnershipFaultTest`：524 条迟到回调/控制回执断言。普通舞蹈改为检查不调用有故障的本地娱乐接口，其他本地控制保留 HTTP 断开、503、损坏 JSON、null、空回执、有界暂态重试及急停验证。
11. `LoggedModelTimeoutTest`：两个真实的 15 秒 HTTP 超时，验证精确点位补偿、普通问答可用性及不重发控制。
12. `FieldVoiceReplayTest`：本次现场问题、原生表演保留和模型异常覆盖。

本次未修改 Python、网页、AIMDK、运动控制、地图、任务或现场配置。此前对基线导航/讲解/存储 133 项、网页服务 74 项及运行场景的验证保留为历史证据，不冒充此次新执行的测试；本次执行清单以交付结果为准。

从最终交付压缩包中提取并运行 Linux 安装事务测试，覆盖安装、重复安装、升级旧补丁、运行/停止状态保持、原字节回滚、启动失败恢复、未知基线拒装、损坏/CRLF 拒绝、后续现场改动保护、实际服务用户及祖先目录权限、错误 release 备份拒绝、systemd 和实际进程 classpath 检查。

## 验证边界

没有连接或部署机器人，没有在真实灵心云端、麦克风阵列或实际运动环境中验收。原生歌舞由机器人既有系统处理，模拟测试只能证明本应用不打断、不重复提交、不追加矛盾播报，不能证明固件服务一定在线或动作物理完成。

导航前置失败在所给 Java TTS 中没有对应文本。`action` 响应缺少 SDK 技能指令是代码确认的问题，已修正；当前日志不足以证明平台独立分支是否还有其他原因。请按部署说明核对现场听感和日志。

真实网络/模型故障仍可能影响普通问答，动作底层拒绝仍保留诊断；本包没有关闭安全限制、虚构成功或用静默证明执行成功。
