# V1.3.8 控制回复修复 1.0.5 验证记录

日期：2026-10-19。分支：`codex/lingxi-v1.3.8-special`。

## 参考包与旧增量对照

`ReferenceControlChannelTest` 使用实际 AgentSDK 序列化消息，记录本地 HTTP 控制、SDK 消息和本机 TTS 的统一顺序。测试分别加载用户提供的 V1.3.1 r7 最终知识库 JAR、上一版 1.0.4 交付 JAR、新 JAR，不用新版本测试辅助函数替代旧版本逻辑。

V1.3.1 为 204/204 通过，1.0.4 有 70/204 项不同，新版本 204/204 通过。构建器限定旧包不同项只能属于 SDK 中断、双文本通道和回复顺序，不能把 HTTP 控制未执行、测试配置错误等当成成功复现。

覆盖导航、讲解开始/暂停/继续/结束、停止导航，`Asr2Llm`、`Asr2Tts` 和两个兼容音频完成入口。参考 JAR 指纹与逐项结论见 `日志核验说明.md`。

## 累计语音回归

完整构建运行以下 14 个 Java 测试入口：

1. `VoiceGateTest`：音频质量元数据门控。
2. `WakeSessionGateTest`：唤醒与会话边界。
3. `Soc2WakeEvidenceProviderTest`：SOC2 唤醒证据读取。
4. `AgentSdkInterruptWireTest`：导航/讲解不发送 SDK 中断，普通动作保留中断策略及去重。
5. `VoiceRegression`：语音规则、真实 Agent 门控、急停、灵创保护和播放回声。
6. `ModelRecoveryTest`：暂态重试、认证错误、无效意图、桥接故障及后续恢复。
7. `FunctionalControlTest`：灵活意图、点位补偿、未知点位、普通动作与自定义任务。
8. `AgentConnectionStateTest`：早到回调、认证失败、离线、重启及原子状态写入。
9. `ControlReplyRegressionTest`：重复/并发回调、完成消息传输异常、动作真实拒绝。
10. `ControlOwnershipFaultTest`：迟到回调、HTTP 断开/503、损坏/空/未知回执、有界重试与急停。
11. `LoggedModelTimeoutTest`：两个真实 15 秒模型 HTTP 超时。
12. `FieldVoiceReplayTest`：打招呼、唱歌/舞蹈、残句和自我介绍等既有现场问题。
13. `ControlReplyTextWireTest`：按实际播报配置分配回复通道，四个完成入口、两种 TTS 路线、TTS 接受/503、默认/自定义任务、重复回调和未知回执。
14. `ReferenceControlChannelTest`：同一协议契约对照实际参考包、旧包与新包。

未修改控制提交和回执算法；对未知、损坏或网络异常回执仍不重试物理命令、不虚报成功。普通问答在本机 TTS 失败时仍可回传 SDK 文本；本机控制回复已经完成 SDK 时不再重新打开文本通道。

实际断言数量与结果以最终归档内 `release.json`、交付目录 `交付验证结果.json` 为准。

## 安装和交付

从最终压缩包提取并运行 10 项 Linux 安装事务测试，覆盖安装、重复安装、升级旧补丁、运行/停止状态保持、原字节回滚、启动失败恢复、未知基线拒装、损坏/CRLF 拒绝、后续修改保护、实际服务用户权限和启动 classpath 校验。

检查外部 SHA-256、内部 SHA256SUMS、所有文本 LF、Python 语法、Java 17 class 版本、Bash 脚本与部署说明中的 Bash 代码块。构建使用空编译目录，并检查构建前后源码快照。

相对完整包基线，仅允许 `LingxiNavAgentApp`、`PresetMotionCatalog`、`DoubaoArkClient` 及其内部类不同；后两项为累计修复。本次相对 1.0.4 的生产变化只允许 `LingxiNavAgentApp` 及其内部类。其他依赖逐字节保留。

安装只更新应用 JAR 和清单，保留属主、组、权限与服务原状态。地图、任务、密钥、AIMDK、回调配置及底层安全限制不改。

复现命令：

```text
python v138_control_reply_fix_deployment/compare_reference.py
python v138_control_reply_fix_deployment/build.py --check-previous
python v138_control_reply_fix_deployment/verify_delivery.py
```

## 验证边界

这些测试验证应用层控制提交、真实 SDK 消息序列和安装事务，不代表已经完成真实云端、SOC2 固件、环境声学和机器人运动验收。本次未远程部署。DOA/AEC/RNNoise 的硬件效果不在本次变更和验收范围内。

参考包实测推翻了上一版“必须返回非空 SDK 控制文本”的假设；新包恢复参考通道，但不会把本地回放通过表述成所有独立原生播报均已现场消失。
