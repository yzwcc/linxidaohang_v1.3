# V1.3.8 控制回复修复 1.0.4 验证记录

日期：2026-10-18。分支：`codex/lingxi-v1.3.8-special`。

## 本次新增验证

`ControlReplyTextWireTest` 使用实际 AgentSDK 1.4.0 的序列化消息，对比已交付 1.0.3 与修复版本。重点不是只看没有失败关键词，而是检查 SDK 实际收到的 `agentsdk.llm_response.item.delta` 中 `text` 字段准确且非空。

覆盖以下组合：

- `Asr2Llm`、`Asr2Tts` 和两个兼容音频完成入口。
- `tts.mode=robot/lingxi`，均开启 `tts.suppressLingxiText=true`。
- 本机 TTS 接受与 HTTP 503 拒绝。
- 导航、默认/自定义讲解、暂停、恢复、结束、停止导航。
- 普通问答：本机 TTS 成功继续屏蔽；失败仍回传文本。
- 同事件的另一个 ASR 回调：普通控制不重复执行、不重复回复；急停仍允许提交。
- 讲解明确拒绝、确认未知、缺少布尔回执：保持静默，不重复控制，不虚报成功。

四个入口统一验证控制只提交一次，最多一次本机 TTS 请求，SDK 只返回一份正确确认语，保留完成消息，不追加 SDK 技能或错误。兼容音频测试使用合成数据和本地模型，不启用现场音频直传。

历史聊天修改与当前现场事件的逐项对照见 `日志核验说明.md`。同一套 712 条断言直接加载真实 1.0.3 JAR 时有 28 条失败，全部属于本机 TTS 成功后 SDK 缺少控制文本；修复版本 712 条全部通过。构建器还检查旧包失败内容，避免把测试配置错误误当作缺陷复现。最终结果记录在包内 `release.json` 和交付目录的 `交付验证结果.json`。

## 累计回归

此次运行全部 13 个 Java 入口：

1. `VoiceGateTest`：音频质量元数据门控。
2. `WakeSessionGateTest`：唤醒与会话边界。
3. `Soc2WakeEvidenceProviderTest`：SOC2 唤醒证据。
4. `AgentSdkInterruptWireTest`：实际中断协议、去重和空提示语。
5. `VoiceRegression`：语音策略与实际 Agent 门控回归。
6. `ModelRecoveryTest`：文本输入、暂态重试、认证错误、无效意图、桥接故障及请求恢复。
7. `FunctionalControlTest`：灵活意图、点位补偿、未知点位、动作与自定义任务。
8. `AgentConnectionStateTest`：早到回调、认证失败、离线、重启及原子状态写入。
9. `ControlReplyRegressionTest`：重复/并发回调、SDK 完成传输异常与动作真实拒绝。
10. `ControlOwnershipFaultTest`：迟到回调、HTTP 断开/503、损坏/空/未知回执、有界重试与急停。
11. `LoggedModelTimeoutTest`：两个真实 15 秒模型 HTTP 超时，检查点位补偿、问答与不重发控制。
12. `FieldVoiceReplayTest`：唱歌关闭、重复舞蹈准备语、残句自我介绍、打招呼错误落入问答故障等旧问题。
13. `ControlReplyTextWireTest`：本次恢复历史控制回复的实际协议验证。

测试数量以最终构建输出为准。没有把之前执行的 Python 导航、网页和声学元数据检查算作本次新执行。

## 安装与交付验证

从最终交付压缩包提取并运行 Linux 安装事务测试，共 10 项，覆盖安装、重复安装、升级旧补丁、运行/停止状态保持、原字节回滚、启动失败恢复、未知基线拒装、损坏/CRLF 拒绝、现场后续修改保护、实际服务用户权限、备份 release 和 systemd/进程 classpath 验证。

检查外部 SHA-256、内部 SHA256SUMS、全部文本 LF、Python 语法、Java 17 class 版本、全部 Bash 脚本和部署说明中的 Bash 代码块。编译输出使用空目录，检查构建前后源码快照，防止残留内部类或构建期间变化进入交付。

相对基线只允许 `LingxiNavAgentApp`、`PresetMotionCatalog`、`DoubaoArkClient` 及内部类不同；后两项是 1.0.3 的累计修复。本次新增生产改动只在 `LingxiNavAgentApp`。其他类和依赖与基线逐字节检查。

运行文件只变化应用 JAR，安装时同步更新清单。安装保留原文件属主、组与权限，只重启原先运行的 Java Agent；地图、任务、密钥、AIMDK、回调和原生技能配置不改。

复现构建命令：

```text
python v138_control_reply_fix_deployment/build.py --check-previous
python v138_control_reply_fix_deployment/verify_delivery.py
```

旧包对比输出保留在构建工作目录 `work/previous-audit.log`。最终验证结果以归档指纹绑定，见 `交付验证结果.json`。

## 验证边界

本次未连接机器人部署，未完成真实灵心云端和物理声学验收。模拟测试证明应用发送正确控制文本、没有重复物理请求及错误文案，不能证明原生固件所有独立音频分支均已消失。

恢复历史文本例外是由当前源码和现场“成功后文本被屏蔽”日志确认的修复；不把中断类型猜测当成根因，也不以关闭安全限制或伪造成功处理真实故障。
