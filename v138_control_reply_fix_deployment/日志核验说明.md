## 4. 修改范围和结论边界

1.0.5 恢复导航/讲解的参考回复通道和顺序，保留 V1.3.8 控制去重、真实回执、模型恢复、动作与原生唱歌跳舞修复。SDK 完成传输异常单独处理，不重发控制或上报相矛盾的 SDK 错误。

这证实新包与用户指定参考包在上述协议上对齐，不等同于模拟出了云端原生错误声音。现场安装后需同时确认“控制正常执行”和“未出现额外抱歉/失败播报”。此前把非空 SDK 控制文本当作必要条件的结论已由本次实际参考包结果纠正。
