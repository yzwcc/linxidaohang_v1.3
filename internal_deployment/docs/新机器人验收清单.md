# 新机器人部署验收清单

机器人编号：____________  IP：____________  部署版本：____________

部署人：____________  日期：____________  地图：____________

## A. 安装前

- [ ] 机器人电量充足，急停可用，移动测试有现场看护。
- [ ] `uname -m` 为 `aarch64` 或 `arm64`。
- [ ] `agi`、`run` SSH 登录正常。
- [ ] ROS 2 Humble 和地图目录存在。
- [ ] 机器人可访问灵心和豆包网络。
- [ ] 灵心 APP ID、AppKey、AppSecret 属于同一个导航项目。
- [ ] 未修改直播项目的代码或语音配置。

## B. 安装

- [ ] TAR.GZ 的 `sha256sum -c` 通过。
- [ ] `configure.sh` 已生成临时 `secrets.env`。
- [ ] `sudo ./install.sh --secrets ./secrets.env --setup-soc2` 成功。
- [ ] 临时 `secrets.env` 已删除。
- [ ] `sudo sparkrobot-lingxi-internal verify` 通过。
- [ ] `sudo sparkrobot-lingxi-internal doctor` 通过。

## C. 网页与地图

- [ ] 手机与机器人连接同一局域网。
- [ ] `http://机器人IP:3000` 可打开并适配手机屏幕。
- [ ] 网页一键开启全部服务成功。
- [ ] 当前地图、地图列表和地图图片显示正确。
- [ ] 新建地图在刷新后可选择。
- [ ] 点位新增、编辑、删除和起点设置正常。
- [ ] 全局路径安全参数在 `3000` 点位配置页与 `task_type` 同页显示，保存后运行值回读一致。
- [ ] 点位和地图配置操作只使用 `3000` 网页；未要求用户访问 `8002` 或 `18082`。
- [ ] 地图切换后，网页地图与底层当前地图一致。
- [ ] 自动重定位成功，实际位置和朝向正确。

## D. 语音

- [ ] 灵心平台显示机器人连接。
- [ ] 现实中唤醒机器人能回答普通问题。
- [ ] 普通问题不会误回复“机器人导航服务未连接”。
- [ ] “前往某点”回复“收到，正在前往某点”。
- [ ] 导航命令不触发“暂时没学会这个动作”。
- [ ] 断网恢复后执行完整重启，语音可恢复。

## E. 导航

- [ ] 网站选择点位可开始导航。
- [ ] 停止导航立即生效。
- [ ] 到点首次进入 0.20m 严格范围。
- [ ] 刹车后 0.35m 滞回规则生效，不误判远距离到达。
- [ ] 最终方向误差不超过 10 度。
- [ ] 导航途中唤醒问答不会终止导航。

## F. 讲解任务

- [ ] 可保存多个讲解任务并选择当前任务。
- [ ] 语音“开始讲解”能启动选中任务。
- [ ] “暂停讲解”“继续讲解”“停止讲解”均生效。
- [ ] 暂停后恢复当前点不会错误超时。
- [ ] 每个点按顺序执行讲解文本、动作和表情。
- [ ] 讲解结束后对应动作停止，不阻塞下一点。
- [ ] 灵创舞蹈可选；未选择时直接进入下一点。
- [ ] 最后一个点完成后任务正常结束。
- [ ] 30 秒无交互返航策略符合现场配置。

## G. 留档

- [ ] 记录部署版本和归档 SHA-256。
- [ ] 记录机器人当前 IP、SOC2 地址和地图名称。
- [ ] 备份 `/etc/sparkrobot/lingxi-nav` 与 `/var/lib/sparkrobot/lingxi-nav`。
- [ ] 确认客户只需同网手机和网页，不需要电脑常驻。
