# 灵犀导航内部部署与命令手册

## 1. 适用范围

## AIMDK 激光建图（R18）

在手机或电脑连接机器人同一局域网后打开 `http://机器人IP:3000`，进入“建图”。先检查接口；只有雷达、IMU、SLAM 里程计和 AIMDK `GetStoredMapByName` 服务均已发现时才允许启动。启动后用外置遥控器移动机器人完成环境扫描，网页不发送底盘或 PNC 移动命令。填写地图名称并选择“停止并保存地图”后，控制台会调用 AIMDK v1.1.0 保存接口，将栅格转换为导航服务可发现的数字 ID 地图目录；完成后到“地图”页刷新列表。

建图只应在安全、受控区域由熟悉设备的人员操作。若停止后保存接口失败，可用相同地图名称重试；地图 ID 目录已存在时会拒绝覆盖。带旋转原点或格式不匹配的栅格会拒绝转换，避免生成坐标错误地图。网页健康状态是接口发现结果，最终仍须在目标机器人上验收一次建图、地图浏览与导航地图加载。

本安装包用于内部人员把灵犀导航整套功能部署到新的智元 X2 机器人。安装后每台机器人独立运行网页、导航、地图、语音兼容网关和 Java 灵心 Agent，不依赖电脑或公网服务器常驻。

- 客户手机与机器人连接同一局域网。
- 客户访问 `http://机器人IP:3000`。
- 一台机器人安装一套，网页只控制本机，不需要在网页中填写目标机器人 IP。
- 包内代码未加密、未混淆、未绑定设备、无许可证限制，并附带 Python、Java、TypeScript 全部源码。
- 运行目标：Ubuntu 22.04 ARM64、Python 3.10、ROS 2 Humble、JRE 17。

## 2. 安装内容

| 功能 | 本机端口 | 说明 |
| --- | ---: | --- |
| 客户网页 | 3000 | 手机控制台和机器人运维入口 |
| 地图服务 | 8002 | 内部地图数据 API；用户不要直接访问此端口配置 |
| 机器人语音 bridge | 18080 | 机器人语音控制接口 |
| 导航 bridge | 18082 | 导航、讲解任务、重定位和状态接口 |
| 语音兼容网关 | 18083 | Java Agent 只连接 `127.0.0.1:18083` |

用户进行的地图、点位、任务和全局路径安全配置统一通过机器人 `3000` 网页控制台完成。`8002` 和 `18082` 仅供本机服务之间通信，不是配置页面。

持久数据位于 `/var/lib/sparkrobot/lingxi-nav`，版本程序位于 `/opt/sparkrobot/lingxi-nav/releases`，配置位于 `/etc/sparkrobot/lingxi-nav`，日志位于 `/var/log/sparkrobot/lingxi-nav`。

## 3. 部署前检查

机器人开机并完成配网后，在电脑上执行：

```powershell
ping 机器人IP
ssh agi@机器人IP
ssh run@机器人IP
```

登录机器人后执行：

```bash
uname -m
lsb_release -ds
python3 --version
test -r /opt/ros/humble/setup.bash && echo "ROS 2 正常"
test -d /agibot/data/var/MapManagerModule && echo "地图目录正常"
getent passwd agi
getent passwd run
```

`uname -m` 必须为 `aarch64` 或 `arm64`。机器人应同时具备 `agi`、`run` 用户，并能访问互联网的灵心平台和豆包接口。建议安装前充足电，并在真实移动验收时保留实体急停和现场看护。

## 4. 上传与解压

优先使用 TAR.GZ，Linux 可执行权限保存最可靠。Windows 电脑执行：

```powershell
scp .\sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz agi@机器人IP:/home/agi/
scp .\sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz.sha256 agi@机器人IP:/home/agi/
ssh agi@机器人IP
```

机器人中执行：

```bash
cd /home/agi
sha256sum -c sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz.sha256
tar -xzf sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz
cd sparkrobot-lingxi-nav-internal-1.0.3-20260828
```

如果通过 U 盘复制，仍需先执行 `sha256sum -c`。ZIP 主要用于内部传输和查看源码，不建议作为机器人首选安装格式。

## 5. 填写配置

### 最简单方式

解压并进入目录后只需运行：

```bash
./quick_install.sh
```

该向导会连续完成配置填写、安装、SOC2 授权、全部服务启动和自检，并自动删除临时密钥文件。需要分步部署或排障时，继续按下文操作。

### 分步方式

运行交互式配置向导：

```bash
./configure.sh ./secrets.env
```

依次填写：

1. 灵心导航项目的 APP ID。
2. 与该 APP ID 配套的 AppKey 和 AppSecret。
3. 豆包 Ark API Key 和模型名称。
4. 机器人显示名。
5. SOC2 地址，X2 默认通常为 `10.0.1.42`。

也可以编辑模板：

```bash
cp templates/secrets.env.example ./secrets.env
nano ./secrets.env
chmod 600 ./secrets.env
```

灵心三项配置必须属于同一个导航项目。不要直接复用或修改直播项目目录和配置。

## 6. 一键安装

首次安装执行：

```bash
sudo ./install.sh --secrets ./secrets.env --setup-soc2
```

`--setup-soc2` 会完成语音底层服务的受限 SSH 授权。按照提示输入 SOC2 `run` 用户登录密码和 sudo 密码。安装器只授权重启和查询 `agibot_software.service`，不开放任意 root 命令。

安装成功后删除临时配置：

```bash
rm -f ./secrets.env
```

如首次安装时暂时无法配置 SOC2，可先执行：

```bash
sudo ./install.sh --secrets ./secrets.env
sudo /opt/sparkrobot/lingxi-nav/current/scripts/setup_soc2_access.sh
```

## 7. 启动与访问

安装器会启动网页。首次完整启动所有模块执行：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal doctor
```

查看机器人当前 IP：

```bash
hostname -I
```

客户手机和机器人连接同一 Wi-Fi 后，浏览器打开：

```text
http://机器人IP:3000
```

如果机器人启用了 UFW：

```bash
sudo ufw allow from 局域网网段 to any port 3000 proto tcp
```

例如局域网为 `192.168.0.0/24` 时，使用该网段，不要把 3000 端口无条件开放到公网。

## 8. 网页使用顺序

1. 打开网页，确认显示本机机器人和当前地图。
2. 点击“一键开启全部服务”，等待导航、地图、语音和灵心状态全部正常。
3. 在地图页刷新地图列表并切换到机器人当前实际地图。
4. 机器人放在该地图的真实位置后执行“自动重定位”。
5. 查看当前定位，确认位置和朝向正确。
6. 先进行点位导航，再进行讲解任务测试。
7. 在任务编排中配置各点的讲解文本、动作、表情和可选灵创舞蹈。

当前到点规则为：首次到达必须进入 `0.20m` 严格范围，进入后允许 `0.35m` 刹车滞回范围，最终朝向误差不超过 10 度。不要通过放大误差范围掩盖地图或定位问题。

## 9. 功能验收

### 9.1 静态验收

```bash
sudo sparkrobot-lingxi-internal verify
sudo sparkrobot-lingxi-internal doctor
curl -fsS http://127.0.0.1:3000/health
curl -fsS http://127.0.0.1:3000/api/robots/default/status
ss -ltn | grep -E ':(3000|8002|18080|18082|18083) '
```

### 9.2 语音验收

1. 灵心平台应显示机器人已连接。
2. 唤醒机器人并询问“今天星期几”，机器人应正常播报，不应误报导航未连接。
3. 说“前往某点”，应回复“收到，正在前往某点”，且不触发“暂时没学会这个动作”。
4. 临时断网恢复后如果不回答，必须重建 Java 进程，见第 13 节。

### 9.3 导航与讲解验收

1. 先选空旷短距离点位，确认地图、定位和方向一致。
2. 验证网站点位导航、停止导航、地图切换和自动重定位。
3. 说“开始讲解”，验证选中的任务能够启动。
4. 验证“暂停讲解”“继续讲解”“停止讲解”。
5. 导航途中唤醒可正常问答，讲解暂停后说“继续讲解”可恢复当前点。
6. 到达每个点后验证讲解文本、动作、表情；讲解结束后到点动作应停止。
7. 配置灵创舞蹈时只验证任务编排和资源可选性；除非现场明确批准，不自动执行真实舞蹈。

## 10. 日常运维命令

```bash
# 查看汇总状态
sudo sparkrobot-lingxi-internal status

# 自动检查关键配置、服务和端口
sudo sparkrobot-lingxi-internal doctor

# 启动、停止、完整重启
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal stop
sudo sparkrobot-lingxi-internal restart

# 校验安装文件是否被破坏
sudo sparkrobot-lingxi-internal verify

# 查看日志
sudo sparkrobot-lingxi-internal logs all
sudo sparkrobot-lingxi-internal logs console
sudo sparkrobot-lingxi-internal logs voice
sudo sparkrobot-lingxi-internal logs navigation
```

网页是开机自启的。机器人重启后，客户在网页点击“一键开启全部服务”即可重启导航和语音模块。

## 11. 升级

先上传和校验新 TAR.GZ，解压后进入新目录。正常升级不传 `--secrets`，会保留灵心配置、地图、点位、任务和客户调速参数：

```bash
sudo ./install.sh
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal doctor
```

需要更换灵心或豆包配置时：

```bash
./configure.sh ./secrets.env
sudo ./install.sh --secrets ./secrets.env
rm -f ./secrets.env
```

同版本修复安装：

```bash
sudo ./install.sh --reinstall
```

安装器会将被替换的同版本程序移入 `/opt/sparkrobot/lingxi-nav/reinstall-backups`。

## 12. 回滚与卸载

查看版本：

```bash
readlink -f /opt/sparkrobot/lingxi-nav/current
ls -1 /opt/sparkrobot/lingxi-nav/releases
```

回滚到上一个版本或指定版本：

```bash
sudo sparkrobot-lingxi-internal rollback
sudo sparkrobot-lingxi-internal rollback 旧版本号
sudo sparkrobot-lingxi-internal start
```

卸载服务但保留程序、配置和客户数据：

```bash
sudo sparkrobot-lingxi-internal uninstall sparkrobot-lingxi-nav-internal
```

只有确认不再需要任何地图、任务和密钥后，内部人员才可手工清理保留目录：

```bash
sudo rm -rf /opt/sparkrobot/lingxi-nav
sudo rm -rf /etc/sparkrobot/lingxi-nav
sudo rm -rf /var/lib/sparkrobot/lingxi-nav
sudo rm -rf /var/log/sparkrobot/lingxi-nav
sudo rm -f /etc/sudoers.d/sparkrobot-lingxi-internal
```

## 13. 常见故障

### 网站打不开

```bash
sudo systemctl status lingxi-nav-console.service --no-pager
sudo journalctl -u lingxi-nav-console.service -n 200 --no-pager
sudo systemctl restart lingxi-nav-console.service
curl -v http://127.0.0.1:3000/health
```

本机健康但手机打不开时，确认手机和机器人位于同一网段，关闭手机蜂窝网络代理/VPN，并检查路由器 AP 隔离和防火墙。

如果日志出现 `console/public/index.html`，说明运行的是旧包或旧网页入口。本包正确路径为 `/opt/sparkrobot/lingxi-nav/current/console/dist/public/index.html`。请确认 `readlink -f /opt/sparkrobot/lingxi-nav/current` 指向本次版本，并重新执行本包的 `sudo ./install.sh --reinstall`，不要手工执行旧的 `start_lingxi_nav.sh`。

### 灵心平台未连接或机器人不回答

```bash
sudo systemctl stop lingxi-java-agent-robot.service
sleep 2
sudo systemctl start lingxi-java-agent-robot.service
sudo sparkrobot-lingxi-internal logs voice
```

断网期间旧 Java 进程可能持续保留失败连接，仅调用“启动”不足以恢复，必须先停止再启动。`sudo sparkrobot-lingxi-internal restart` 和网页的完整重启流程都会重建 Java 进程。

### 显示 SOC2 运维通道未配置

```bash
sudo /opt/sparkrobot/lingxi-nav/current/scripts/setup_soc2_access.sh
sudo /opt/sparkrobot/lingxi-nav/current/scripts/restart_robot_voice_stack.sh
```

如 SOC2 地址不是默认值，编辑 `/etc/sparkrobot/lingxi-nav/runtime.env` 后重新运行。

### 导航服务未连接

```bash
sudo -u agi /opt/sparkrobot/lingxi-nav/current/scripts/navigation_control.sh restart
tail -n 200 /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
tail -n 200 /var/log/sparkrobot/lingxi-nav/voice_nav_gateway.log
```

### 地图列表没有新地图

```bash
ls -la /agibot/data/var/MapManagerModule/
curl -fsS http://127.0.0.1:8002/api/discover_maps
```

在网页刷新地图列表。确认地图由机器人本机地图管理模块完整保存，然后再切换和重定位。

### 自动重定位超时或没有 `/slam/lidar_odom`

```bash
source /opt/ros/humble/setup.bash
ros2 topic info /slam/lidar_odom
ros2 topic hz /slam/lidar_odom
sudo journalctl -u agibot_software.service -n 200 --no-pager
```

先确认机器人退出建图状态、当前地图与底层地图一致、SLAM 定位模式已启动。不要反复发送重定位命令掩盖底层没有定位输出的问题。

## 14. 配置备份

升级前可额外执行：

```bash
sudo tar -czf /home/agi/lingxi-nav-data-$(date +%Y%m%d-%H%M%S).tar.gz \
  /etc/sparkrobot/lingxi-nav \
  /var/lib/sparkrobot/lingxi-nav
```

备份包含灵心和豆包密钥，只能交给内部授权人员保管。

## 15. 源码与二次构建

归档内 `source/navigation`、`source/java`、`source/server` 分别为 Python 导航、Java Agent、TypeScript 网页后端源码。运行包中的 JAR 是现场验收通过的普通未加密 JAR；如修改 Java 源码，必须重新构建、完成实体机器人语音和讲解回归，再替换内部包构建输入。
