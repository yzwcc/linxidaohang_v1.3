# 验证范围

本包构建时先将新增的导航/讲解路由测试原样运行在实际交付的 1.0.5 JAR 上，要求复现路由失败；再用相同测试验证新 JAR。测试使用官方 AgentSDK 的 ASR2LLM、ASR2TTS 回调对象，以及本机 HTTP 服务，记录真实发出的导航、任务、动作和 TTS 请求。

覆盖：模型误判为聊天、握手、错误目的地；当前地图精确点位校验；讲解启动的多种表达及自定义任务 ID；双回调去重；否定/转述/说明问题；未知与歧义点位；真实服务拒绝不冒充成功。

同时执行原有 14 组 Java 回归：唤醒和语音门控、SDK 中断协议、问答恢复、导航/任务/动作控制、连接状态、回复所有权、模型真实超时、历史语音回放、文本回复和 V1.3.1 参考控制通道。与 1.0.5 相比，只允许修改主应用与点位校验类；其余前序累计类、依赖和 SDK 保持原字节。

交付核验另外检查最终归档的内外 SHA256、LF 换行、Java 17 字节码、源码重新编译一致性、Bash 命令语法，以及在 Linux 临时根目录中的事务安装、重复安装、回滚、权限、r16 升级和失败恢复场景。

精确测试结果与实际旧版失败数量以包内 `release.json` 和外部 `交付验证结果.json` 为准。模拟通过不等同于机器人实机或独立原生语音链路验证，本次没有连接或部署机器人。
