# 灵犀 V1.3.8 r16：已编译 AIMDK 新机完整部署

这是独立首次安装教程，不需要先安装 r10/r11/r12/r13/r14 或任何增量包。适用 ARM64 SOC1、Ubuntu 22.04、ROS Humble，厂家底层软件已安装，AIMDK 已编译至 `/home/agi/aimdk/install`。产品版本 V1.3.8，运行版本 `1.0.19-20261019-r16`。

包含 r15 基线和其后控制回复修复 1.0.0～1.0.5 的累计功能，不需要先安装 r15，也不需要再叠加旧增量。合并列表和 JAR 指纹见 `merged-increments.json`。

此流程复用当前 AIMDK；不要执行 `prepare` 或 `01-replace-aimdk.sh`。包内包含 ARM64 Java、Node、导航/地图网页、语音接入、普通动作与灵创接入代码、知识库组件。厂家地图、音频、底盘服务和实际灵创资源应由机器人本身提供。

## 1. 上传与账号检查

上传完整包及同名 `.sha256` 到 `/home/run`，以 run 账号执行：

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -r /home/agi/aimdk/install/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

当前用户应为 run，架构应为 aarch64/arm64，时间应正确。准备配套的灵心 APP ID、AppKey、AppSecret、豆包 Ark API Key、模型标识、知识库智能体 `AI_AGENT_...`、SOC2 地址和 SOC2 的 run 密码。run 无 sudo 权限时由设备管理员配置安装权限。

必要工具缺失时安装，已有工具可跳过：

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl openssh-client python3 iproute2 util-linux nano
command -v python3 curl ssh ssh-keygen ssh-copy-id tar ss flock sudo
```

## 2. 校验和解压

```bash
cd /home/run &&
sha256sum -c lingxi-v1.3.8-complete-20261019-r16-deployment.tar.gz.sha256 &&
tar -xzf lingxi-v1.3.8-complete-20261019-r16-deployment.tar.gz &&
```

必须全部显示 OK。包内清单和脚本采用 LF 换行。校验失败重新传输原包，不编辑脚本或重算清单绕过校验。

## 4. 首次安装完整业务

先检查端口归属，已有其他程序占用时核实后处理，不直接 kill：

```bash
sudo ss -ltnp | grep -E ':(3000|8002|18080|18082|18083|18084) ' || true
cd /home/run/lingxi-v1.3.8-complete-20261019-r16-deployment
read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

按提示填写灵心配套配置、豆包密钥/模型、机器人名、SOC2 地址。默认模型 `doubao-seed-2-0-mini-260428` 必须在该 Ark 账号可用，默认 SOC2 地址 `10.0.1.42` 以实际设备为准。

按提示输入 SOC2 run 密码，分别配置 SSH 公钥和受限语音重启权限。首次安装不加 `--skip-soc2-setup`。本命令安装全部业务，不使用旧的 `install-navigation`、`install-addons` 或增量脚本。

安装成功输出“灵犀 V1.3.8 完整产品已安装”。安装器不发送走路、动作或重定位指令。

## 5. 启动和检查

```bash
bash ./install_all.sh preflight
hostname -I
```

同局域网访问 `http://机器人IP:3000/console/`，点击“一键启动全部服务”，等待最终检查。重复点击共享同次启动。语音桥已健康运行时会保留会话；补启动地图服务不会因为缓存列表而跳过。

命令行启动可用：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal status
bash ./scripts/03-verify-after-web-start.sh
bash ./install_all.sh doctor
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
sudo systemctl show lingxi-java-agent-robot.service \
  -p User -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
sudo ss -ltnp | grep -E ':(3000|8002|18080|18082|18083|18084) ' || true
```

current 应为 `/opt/sparkrobot/lingxi-nav/releases/1.0.19-20261019-r16`。Java 应为 running=true、lingxi_connected=true、robot_online=true，NRestarts 不持续增加。systemd active 只表示进程存在，仍需确认灵心认证和机器人回调。

## 6. 功能验收

1. 选择实际地图并现场重定位，确认定位持续更新，再执行导航。
2. 新建讲解任务，修改讲解文字、等待秒数、动作与开始命令词，保存并刷新，核对值保留。
3. 唤醒后分别进行普通问答、知识库问答，确认针对问题回答，不无限复读。
4. 说“带我去已保存的点名”，核对目标，测试停止和连续导航。
5. 在稳定站立时说“能不能跟我握一下手”“给我比个心”；确认只发送一次，不误报动作失败。“不要握手”不应执行。
6. 验证开始/暂停/继续/结束讲解，等待步骤按无人交流时间继续，打断交流结束后按既有规则恢复；灵创保护期间不接受干扰，结束后语音恢复。

动作“已接受”不代表肢体完成。底层拒绝和确认超时保留在日志及状态中，不再直接播报低层失败话术；先观察状态，不连续重发。模型不可用时，本地只补偿明确动作和精确匹配已保存点名的带路命令，问答仍需要模型恢复。

导航/讲解控制默认先完成 SDK 回复，再调用本机播报；SDK 不重复返回同一句控制文本。日志应记录 `Local control reply completed` 和同一事件的 `sdkTextSuppressed=true`、`sdkCompleted=true`、`localTtsAccepted=true`。测试导航和开始讲解时同时听实际声音，确认不追加“抱歉……”或任务失败。接口接受不能代替实机声音验收。未知点名、未配置任务等真实业务提示仍保留。

降噪拒识沿用已有门控、会话窗口、方向/质量元数据及语义策略；本包不新增硬件 DOA、AEC 或 RNNoise 链路。真实声学与运动效果需现场验收。

## 7. 修改配置、日志和回滚

```bash
sudo cp -a /etc/sparkrobot/lingxi-nav/lingxi-nav.properties \
  /etc/sparkrobot/lingxi-nav/lingxi-nav.properties.bak.$(date +%Y%m%d-%H%M%S)
sudo nano /etc/sparkrobot/lingxi-nav/lingxi-nav.properties
sudo systemctl restart lingxi-java-agent-robot.service
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
```

修改 `lingxi.appId`、配套 `lingxi.appKey`/`lingxi.appSecret`、`doubao.apiKey`/`doubao.model`，保留当前有效 `lingxi.callbacks` 配置。

```bash
sudo tail -F \
  /var/log/sparkrobot/lingxi-nav/java-agent.log \
  /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log \
  /var/log/sparkrobot/lingxi-nav/map_label_server_v3.log \
  /var/log/sparkrobot/lingxi-nav/robot_lingxi_bridge.log
```

Ctrl+C 退出。发日志前检查客户隐私和凭据。首次新机安装没有旧版本可回滚；从旧版更新的回滚说明见另一份《完整部署说明》第 8 节。
