# 灵创舞蹈与动作独立更新包部署教程

## 一、更新范围

本包只更新下面 5 个导航 Python 文件：

```text
lingxi_nav_bridge.py
sdk_motion_controller.py
linkcraft_resources.py
tour_step_actions.py
tour_interaction_policy.py
```

安装位置默认为：

```text
/opt/sparkrobot/lingxi-nav/current/navigation/robot_local_navigation_v3
```

不会修改地图、点位、任务数据、AIMDK、Java Agent、灵犀密钥、知识库和直播项目。安装时会先备份旧文件，默认只重启导航 bridge。

## 二、在开发电脑构建

在仓库根目录打开 PowerShell：

```powershell
python linkcraft_deployment\build_package.py
python linkcraft_deployment\audit_package.py
```

构建后确认以下文件存在：

```text
linkcraft_deployment\dist\sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz
linkcraft_deployment\dist\sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz.sha256
```

## 三、复制到机器人

将 ROBOT_IP 替换为本次机器人的真实 IP。在 PowerShell 执行：

```powershell
scp linkcraft_deployment\dist\sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz run@ROBOT_IP:/home/run/
scp linkcraft_deployment\dist\sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz.sha256 run@ROBOT_IP:/home/run/
```

SSH 登录机器人：

```powershell
ssh run@ROBOT_IP
```

## 四、校验、解包和安装

在机器人 SSH 终端逐行执行：

```bash
cd /home/run
sha256sum -c sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz.sha256
tar -xzf sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902.tar.gz
cd sparkrobot-lingxi-linkcraft-addon-1.0.3-20260902
chmod +x install.sh control.sh
sudo ./install.sh
```

安装脚本成功时会显示备份目录，例如：

```text
/var/lib/sparkrobot/lingxi-linkcraft/backups/20260902T120000Z
```

请保存这个目录，回滚时需要使用。

如果只想先替换文件、不重启服务：

```bash
sudo ./install.sh --no-restart
```

## 五、安装后检查

仍在包目录执行：

```bash
sudo ./control.sh status
sudo ./control.sh doctor
sudo ./control.sh resources
```

其中 resources 只扫描资源，不会启动舞蹈。正常时会返回 resource_count 和资源列表。资源名称通常需要以 linkcraft_resource_ 开头，并且有当前版本。资源扫描默认切换到机器人用户 run，因为部分 NFS 挂载禁止 root 读取。

如果机器上的资源配置路径不是默认路径：

```bash
sudo LINKCRAFT_RESOURCE_CONFIG=/实际路径/resource_config.yaml ./control.sh resources
```

如果当前机器人使用的资源用户不是 run：

```bash
sudo LINKCRAFT_RESOURCE_USER=agi ./control.sh resources
```

查看导航日志：

```bash
sudo ./control.sh logs
```

## 六、任务配置和验收

在网页任务编排中，到达点位后按顺序配置讲解文本、普通动作/表情和可选灵创资源。灵创资源选择的是资源快照，资源 key 必须是机器人当前可用的 linkcraft_resource_*，资源版本必须存在。

推荐先做一个只包含一个点位的任务，配置一段短讲解和一个灵创资源。先在网页确认任务保存成功，再由现场人员确认机器人周围安全后启动任务。安装包不会自动执行真实舞蹈，真实验收必须由现场人员明确授权并准备急停。

日志中应能看到类似信息：

```text
讲解任务进入灵创阶段
灵创资源已提交
灵创资源已接受
灵创资源阶段完成
```

如果没有配置灵创资源，任务应直接进入下一个点位；最后一个点位完成后结束任务。

## 七、回滚

使用安装时生成的备份目录：

```bash
sudo ./control.sh rollback /var/lib/sparkrobot/lingxi-linkcraft/backups/时间戳目录
```

回滚只恢复这 5 个文件，然后只重启导航 bridge，不会恢复或修改语音配置。

## 八、常见问题

### 1. 找不到导航目录

先检查：

```bash
ls -ld /opt/sparkrobot/lingxi-nav/current/navigation/robot_local_navigation_v3
```

如果正式导航目录不同，可显式指定：

```bash
sudo LINKCRAFT_NAV_DIR=/实际导航目录 ./install.sh
```

### 2. 找不到 navigation_control.sh

这说明导航主包脚本没有按正式版本安装，或者当前软链接失效。附加包不会自行创建导航主包脚本。修复主包目录后重新执行：

```bash
sudo ./install.sh
```

如果系统只有旧版 sparkrobot-lingxi-internal 控制命令，脚本会给出兼容提示并调用它；该兼容方式可能同时重启语音服务。

### 3. 资源列表为空

先确认资源配置文件和资源目录：

```bash
sudo ./control.sh resources
ls -l /agibot/nfs/soc0/var/robot_proxy/resources/resource_config.yaml
```

资源列表为空通常代表机器人尚未下载灵创资源，或者资源配置路径与当前固件不同。本包不下载舞蹈资源，也不会伪造资源 key。

### 4. 动作提交失败

检查：

```bash
sudo ./control.sh logs
```

重点确认 ROS2/AIMDK 已正常启动，以及 /aimdk_5Fmsgs/srv/ExecuteActionResource 服务存在。服务不可用时任务会记录失败并继续任务，不会无限卡住。
