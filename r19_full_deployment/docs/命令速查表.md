# 灵犀导航命令速查表

## 最短部署

```bash
./quick_install.sh
```

分步执行：

```bash
sha256sum -c sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz.sha256
tar -xzf sparkrobot-lingxi-nav-internal-1.0.3-20260828.tar.gz
cd sparkrobot-lingxi-nav-internal-1.0.3-20260828
./configure.sh ./secrets.env
sudo ./install.sh --secrets ./secrets.env --setup-soc2
rm -f ./secrets.env
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal doctor
```

## 服务控制

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal stop
sudo sparkrobot-lingxi-internal restart
sudo sparkrobot-lingxi-internal status
sudo sparkrobot-lingxi-internal doctor
sudo sparkrobot-lingxi-internal verify
```

## 分模块控制

```bash
sudo systemctl restart lingxi-nav-console.service
sudo -u agi /opt/sparkrobot/lingxi-nav/current/scripts/navigation_control.sh restart
sudo -u agi /opt/sparkrobot/lingxi-nav/current/scripts/robot_local_navigation_v3.sh up
sudo systemctl stop lingxi-java-agent-robot.service
sudo systemctl start lingxi-java-agent-robot.service
sudo /opt/sparkrobot/lingxi-nav/current/scripts/robot_voice_bridge_control.sh restart
sudo /opt/sparkrobot/lingxi-nav/current/scripts/restart_robot_voice_stack.sh
```


## 升级和回滚

```bash
# 新版本升级，保留原配置和客户数据
sudo ./install.sh

# 同版本修复安装
sudo ./install.sh --reinstall

# 回滚
sudo sparkrobot-lingxi-internal rollback
sudo sparkrobot-lingxi-internal rollback 旧版本号
sudo sparkrobot-lingxi-internal start
```
