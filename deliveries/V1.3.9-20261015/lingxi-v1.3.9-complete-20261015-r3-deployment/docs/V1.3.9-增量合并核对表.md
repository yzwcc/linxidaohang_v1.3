## 避免的覆盖回归

受阻提醒包中的 bridge/client 来自较早代码，直接覆盖会退回旧任务状态机。新包保留 V1.3.9 循环、等待、暂停恢复、到点锁存、密集人流和失败跳点，在此基础上添加 detector/event/TTS。

循环保存增量之后，源码还增加了地图页机器人位置显示，本次一并保留。密集人流增量包含配置写入效果，本次并入内部安装器；没有仅复制 Python 文件却漏掉启用字段。

旧知识库组件内的 Java 接入不再覆盖导航主包的已验证 Java JAR。Java 从现有源码重新编译通过，所有 `.class` 与原 V1.3.9 验证 JAR 相同；交付继续固定原 JAR SHA-256，避免无功能变化的归档时间戳影响基线。

## 客户操作结果

新机只执行本完整包的环境、AIMDK、应用安装步骤。已有 V1.3.9 执行一次本完整包的保留配置升级步骤。安装后从网页启动服务并验收，不再追加上述旧增量包。

A2 PNC 不兼容时明确拒绝自动改参数；使用 `--skip-pnc-policy` 会记录策略跳过，不能宣称该机器已启用窄通道策略。地图、灵创资源和平台凭据仍属于各台机器的现场数据。
