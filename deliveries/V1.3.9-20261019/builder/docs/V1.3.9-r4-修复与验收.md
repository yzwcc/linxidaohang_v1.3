# V1.3.9 r4 修复与验收

日期：2026-10-19。完整包 `1.3.9-complete-20261019-r4`，导航 `1.0.22-20261019`，基线为 2026-10-15 r3。

## 修复

1. 任务跳过未到达的点位后，不再把下一次同点步骤判定为已经到达。仅真实完成的到达可以复用。
2. Java 控制入口仅接受明确的布尔回执。不明确、矛盾、格式错误、HTTP 错误时静默结束，避免虚报成功和重复动作；明确拒绝时不复述肯定答复。确认成功后保留状态，防止后续 SDK 失败回调误报。
3. 本地任务规则和模型控制出口均检查否定、条件及引用说明，保留原有明确停止指令。该规则不能代替任意自然语言的实机验收。
4. 固件修改前校验技能 JSON 和两份 PNC YAML；机型检测只读取实际启用的主配置，避免注释中的 A2 路径误通过。
5. 完整恢复在停服前检查备份哈希、目标版本、路径、符号链接和归档成员；恢复前另外保存当前状态。
6. doctor 严格核对版本、JAR 哈希、完整策略字段、systemd 启动参数、实际进程命令行及工作目录。
