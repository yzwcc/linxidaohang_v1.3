# 灵犀 V1.3.8 完整部署说明

交付版：`1.3.8-complete-20261012-r10`。导航运行组件：`1.0.19-20260921`。

本包基于 V1.3.8-r9 完整组件重新整理，修正外层安装器仍引用 `1.0.18`、运维版本号不一致、普通用户无法读取 `current` 链接和已安装目录判断失效的问题。导航运行组件、Java Agent、知识库和 AIMDK 保留原有组件。

## 包内内容

- AIMDK ARM64：`aimdk-aarch64-1bde262f-artifacts.7z`。
- 导航、地图、网页控制台及语音网关。
- 灵心 ASR 转文本接入大模型、知识库检索和预设动作接口。
- 灵创动作、表情、舞蹈接口及执行期间的语音保护。
- 讲解任务自定义开始词、逐点等待、语音打断及安静后恢复能力。
- 连续导航及到点判定修复、Java 运行权限和语音 bridge 权限修复。

灵创资源、地图和账户权限取决于目标机器人；安装包不会生成机器人原本没有的动作资源。语音方向过滤及降噪效果取决于设备实际提供的 SDK 数据，不能把兼容回退模式理解为完整 DOA、AEC 或 RNNoise 已开启。

## 一、安装前提

机器人应为 ARM64，已安装 ROS 2 Humble，并有 `run`、`agi` 用户。使用 `run` 登录，确保 `run` 能执行安装所需的 sudo 命令。

准备灵心 App ID、AppKey、AppSecret、豆包 API Key、模型名和知识库 `AI_AGENT_...` Code。机器人需要能访问这些服务及系统软件源。密钥只在安装提示中输入。

将以下两个文件上传到机器人 `/home/run`：

```text
lingxi-v1.3.8-complete-20261012-r10-deployment.tar.gz
lingxi-v1.3.8-complete-20261012-r10-deployment.tar.gz.sha256
```

## 二、校验和解压

以 `run` 用户执行：

```bash
cd /home/run
sha256sum -c lingxi-v1.3.8-complete-20261012-r10-deployment.tar.gz.sha256
tar -xzf lingxi-v1.3.8-complete-20261012-r10-deployment.tar.gz
cd /home/run/lingxi-v1.3.8-complete-20261012-r10-deployment
```

校验必须显示 `OK`。校验文件和包内 shell 脚本使用 Linux LF 换行，传输时保留二进制内容。

## 三、新机器准备环境和 AIMDK

仍以 `run` 用户执行：

```bash
bash ./install_all.sh prepare
```

按提示登录同一台机器的 `agi` 用户：

```bash
su - agi
bash /home/agi/01-replace-aimdk.sh
exit
```

`su` 要求的是 `agi` 登录密码。也可以另开 SSH 终端，以 `agi` 登录后运行同一编译命令，完成后回到 `run` 终端。

AIMDK 脚本会编译新目录，并在编译及导入检查成功后替换 `/home/agi/aimdk`。该阶段适用于新机器；已部署机器不要为升级网页或 Java 组件而反复替换 AIMDK。

## 四、安装完整产品

以 `run` 用户执行：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261012-r10-deployment
bash ./install_all.sh install --agent-code AI_AGENT_xxxxxxxx
```

将 `AI_AGENT_xxxxxxxx` 换为实际知识库 Agent Code。按提示输入灵心、豆包、机器人名称和 SOC2 地址。首次配置 SOC2 通道时，输入对应登录密码及 sudo 密码。

安装器会安装导航主包和知识库服务，将 `current` 指向：

```text
/opt/sparkrobot/lingxi-nav/releases/1.0.19-20260921
```

安装器会检查已存在的目标 release 并执行重装。已有地图和配置应在更新前另外备份；本包不包含客户地图或实际密钥。不要再叠加旧增量包中的 JAR 或同名 Python 文件。

## 五、已有 V1.3.8 的更新

若原来的 AIMDK 和系统依赖可正常使用，可跳过第三节，先校验解压，再停止业务并执行完整安装：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261012-r10-deployment
sudo sparkrobot-lingxi-internal stop
bash ./install_all.sh install --agent-code AI_AGENT_xxxxxxxx
```

此过程需要重新输入部署配置。安装器会先检查现有 AIMDK，检查失败时终止并提示原因；不要直接跳过检查。只有已确认同一台机器的 SOC2 SSH 运维通道有效时，才追加 `--skip-soc2-setup`。

## 六、启动和检查

手机与机器人处于同一局域网，访问：

```text
http://机器人IP:3000/console/
```

点击“一键开启全部服务”。也可以执行：

```bash
sudo sparkrobot-lingxi-complete start
```

随后检查：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261012-r10-deployment
bash ./install_all.sh preflight
bash ./install_all.sh doctor
sudo sparkrobot-lingxi-complete status
```

这些检查不触发机器人移动。确认服务状态和端口 `3000`、`8002`、`18080`、`18082`、`18083`、`18084` 正常，再进行功能验收。

## 七、现场功能验收

1. 打开网页，选择实际地图，确认点位可读、任务可保存，刷新后仍保留。
2. 确认定位数据正常，在现场准备急停后测试两个连续导航点。
3. 测试知识库提问，确认识别到的是用户文本且回答对应问题。
4. 在安全姿态下测试预设动作和目标机器人已有的灵创资源。
5. 测试讲解任务逐点播报、等待无人沟通后继续、打断后安静约 5 秒恢复；手动暂停应保持暂停。
6. 测试灵创期间的语音保护和执行结束后的恢复。

本次在本地检查安装版本一致性、归档及组件完整性、Linux 换行和脚本语法。未在目标机器人执行本次安装或实机行走、动作、声学验收；服务检查通过不能替代这些验收。

## 八、故障检查

```bash
sudo sparkrobot-lingxi-complete logs all
sudo systemctl show lingxi-java-agent-robot.service \
  -p User -p SupplementaryGroups -p ActiveState -p SubState -p ExecMainStatus
sudo journalctl -u lingxi-nav-console.service -n 100 --no-pager
sudo tail -n 100 /var/log/sparkrobot/lingxi-nav/java-agent.log
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
```

如出现 JAR、PID、日志或 SSH known_hosts 权限错误：

```bash
sudo sparkrobot-lingxi-complete repair-permissions
sudo sparkrobot-lingxi-complete restart
sudo sparkrobot-lingxi-complete doctor
```

不要手工删除 release、修改校验清单或直接用旧增量包覆盖运行文件。若安装失败，保留输出、日志和安装器生成的备份，先定位失败环节。
