# 灵犀 V1.3.8 语音验收

## 验收前

机器人静止、处于稳定站立状态，服务已通过网页启动和 `doctor` 检查。准备现场急停，不在验收脚本中自动发送动作。

## 唤醒与拒识

1. 不说唤醒词，直接问“今天星期几”：机器人不应回答。
2. 播放一段背景声音或从机器人后方说话：不应触发回答。
3. 说真实唤醒词，再问一个普通问题：应有一次回答。
4. 说“灵犀灵犀”但没有 SDK KWS/SOC2 证据：不应仅凭文本放行。

## 本地动作

在确认站立后逐项测试“握手”“比个心”“举手”。预期日志包含本地动作命中，且不需要等待豆包意图解析。说“你会握手吗”只应回答能力问题，不应自动伸手。

## 讲解保护

讲解任务到点后：

1. 讲解文本能够播放。
2. 配置的动作或表情能够执行。
3. 灵创动作执行期间，普通语音不会打断动作。
4. 灵创完成后语音恢复。
5. 用户交互结束后按照网页设置的等待秒数继续下一点位。
