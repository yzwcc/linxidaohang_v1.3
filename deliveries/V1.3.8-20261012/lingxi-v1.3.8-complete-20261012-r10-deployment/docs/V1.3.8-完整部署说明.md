# 灵犀 V1.3.8 完整部署说明

版本：`1.3.8-complete-20260921-r8`

导航主包：`1.0.18-20260921`

适用对象：内部部署人员。本文档不包含灵心 AppSecret、豆包 API Key、SSH 密码或任何客户密钥。

## 一、部署内容

完整包包含以下组件：

- AIMDK ARM64 原始压缩包及替换脚本。
- 导航、地图标点、语音兼容网关和本机网页控制台。
- Java 灵犀 Agent 及唤醒、降噪/拒识、动作意图门控。
- 灵心知识库检索服务。
- 灵创动作、表情和舞蹈资源接口，以及灵创执行期间的语音保护。
- 连续导航、到点讲解、用户交互后等待、下一点位恢复、PNC 回验和到达方向稳定判定。
- 事务备份、版本回滚、权限修复和只读诊断脚本。

## 二、安装前提

1. 机器人为 ARM64，系统已安装 ROS 2 Humble。
2. 机器人存在 `run` 和 `agi` 用户；安装人员使用 `run` 登录。
3. 机器人可以访问灵心服务、豆包服务和必要的软件源。
4. 已取得本机对应的灵心配置、豆包配置和知识库 Agent Code。配置只在安装提示中输入，不要写进仓库或安装包。
5. 第一次部署建议连接显示器或准备串口/SSH 回退通道，便于确认 AIMDK 编译和底层服务状态。

## 三、上传与校验

在电脑上把完整包和同名校验文件上传到机器人：

```bash
scp lingxi-v1.3.8-complete-20260921-r8-deployment.tar.gz run@机器人IP:/home/run/
scp lingxi-v1.3.8-complete-20260921-r8-deployment.tar.gz.sha256 run@机器人IP:/home/run/
```

在机器人上执行：

```bash
cd /home/run
sha256sum -c lingxi-v1.3.8-complete-20260921-r8-deployment.tar.gz.sha256
rm -rf lingxi-v1.3.8-complete-20260921-r8-deployment
tar -xzf lingxi-v1.3.8-complete-20260921-r8-deployment.tar.gz
cd /home/run/lingxi-v1.3.8-complete-20260921-r8-deployment
chmod +x install_all.sh control_all.sh
```

校验必须显示 `OK`。如果出现文件名后带 `^M` 或 `$'\\r'`，说明校验文件被转换成了 Windows 换行，请重新以二进制方式上传两个文件。

## 四、安装顺序

### 4.1 准备环境和 AIMDK

以下命令由 `run` 用户执行：

```bash
bash ./install_all.sh prepare
```

准备阶段会把 AIMDK 压缩包和检查脚本放到 `/home/agi`，并安装缺失的系统依赖。然后切换到 `agi` 用户编译和替换 AIMDK：

```bash
su - agi
bash /home/agi/01-replace-aimdk.sh
exit
```

编译完成后必须确认：

```bash
source /opt/ros/humble/setup.bash
source /home/agi/aimdk/install/setup.bash
python3 -c "import rclpy; import aimdk_msgs.msg; print('AIMDK Python 接口正常')"
```

如果 ROS 的 `setup.bash` 在 `set -u` 下报告 `AMENT_TRACE_SETUP_FILES` 未定义，使用包内脚本，不要手工拼接带 `set -u` 的 source 命令；脚本已对 ROS 环境做 nounset 兼容处理。

### 4.2 安装导航、语音、知识库和灵创能力

回到 `run` 用户，并填写真实配置：

```bash
cd /home/run/lingxi-v1.3.8-complete-20260921-r8-deployment
bash ./install_all.sh install --agent-code AI_AGENT_xxxxxxxx
```

安装过程中依次填写：

- 灵心 App ID、AppKey、AppSecret。
- 豆包 Ark API Key 和模型名。
- 机器人显示名。
- SOC2 地址。只有确实使用外置 SOC2 时才配置对应地址。

安装器会创建当前版本链接：

```text
/opt/sparkrobot/lingxi-nav/current -> /opt/sparkrobot/lingxi-nav/releases/1.0.18-20260921
```

安装失败时不要手动删除 `releases` 或 `current`。安装器会保留事务备份，可先执行：

```bash
bash ./install_all.sh repair-permissions
```

再查看控制台、Java Agent 和知识库日志后重试。

## 五、启动与网页验收

安装完成后，手机和机器人连接同一个局域网，在浏览器打开：

```text
http://机器人IP:3000/console/
```

网页中的“一键开启全部服务”会启动控制台、导航/地图/语音兼容网关、Java Agent 和知识库服务。它不会自动开始导航、重定位、讲解、动作或舞蹈。

也可以使用命令行回退启动：

```bash
sudo sparkrobot-lingxi-complete start
```

基础验收：

```bash
bash ./install_all.sh preflight
bash ./install_all.sh doctor
sudo sparkrobot-lingxi-complete status
```

`doctor` 只做端口、进程、配置、接口和文件完整性检查，不会让机器人移动，也不会执行真实动作。

## 六、功能验收顺序

1. 在网页选择当前地图，确认地图和点位列表一致。
2. 先确认 `/slam/lidar_odom` 有实时数据，再进行重定位；重定位使用机器人实际位置，不设置虚构参考点。
3. 网页点击“去这里”，确认语音回复为“收到，正在前往某某点”，不应出现模型兜底句。
4. 机器人静止且处于稳定站立状态时，再说“握手”“比个心”“举手”等动作指令；明确动作会先走本地高置信识别，不等待豆包意图解析。
5. 开始讲解任务，验证到点讲解、到点动作/表情、灵创舞蹈选择、用户交互、等待结束后继续下一个点位。
6. 灵创动作或舞蹈执行期间，普通语音和唤醒会被保护；安全停止和任务停止仍然保留。
7. 最后一个点位完成后，任务结束，不会重复导航到同一点。

## 七、日志和故障定位

统一查看：

```bash
sudo sparkrobot-lingxi-complete logs all
```

分类查看：

```bash
sudo sparkrobot-lingxi-complete logs navigation
sudo sparkrobot-lingxi-complete logs voice
sudo sparkrobot-lingxi-complete logs console
sudo sparkrobot-lingxi-complete logs knowledge
```

主要日志：

```text
/var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
/var/log/sparkrobot/lingxi-nav/map_label_server_v3.log
/var/log/sparkrobot/lingxi-nav/voice_nav_gateway.log
/var/log/sparkrobot/lingxi-nav/robot_lingxi_bridge.log
/var/log/sparkrobot/lingxi-nav/java-agent.log
journalctl -u sparkrobot-lingxi-kb.service
```

动作链路重点检索：

```bash
sudo grep -E "Local preset motion|motion=|STAND_DEFAULT|motion request acknowledged|motion rejected|input source|任务执行失败" \
  /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log \
  /var/log/sparkrobot/lingxi-nav/java-agent.log | tail -n 200
```

语音门控重点检索：

```bash
sudo grep -E "Wake|wake|quality gate|拒识|低信噪|SOC2|Local tour control|/task/start|/task/stop" \
  /var/log/sparkrobot/lingxi-nav/java-agent.log | tail -n 200
```

## 八、回滚

安装器输出的事务备份位于：

```text
/var/lib/sparkrobot/lingxi-nav/reinstall-backups/
/var/lib/sparkrobot/lingxi-voice-gate/backups/
```

先停止业务，再按安装器提示的备份目录回滚；不要直接删除当前版本目录：

```bash
sudo sparkrobot-lingxi-complete stop
sudo sparkrobot-lingxi-internal rollback 目标版本号
sudo sparkrobot-lingxi-complete start
```

## 九、安全边界

- 包内不含真实密钥；`secrets.env` 只在机器人本机短暂生成，安装后删除。
- 前端不接收任意 shell 命令，网站只调用固定白名单接口。
- `doctor`、`preflight` 和日志命令不会触发移动或动作。
- 真实导航、重定位和动作验收必须由现场人员确认并准备急停。
