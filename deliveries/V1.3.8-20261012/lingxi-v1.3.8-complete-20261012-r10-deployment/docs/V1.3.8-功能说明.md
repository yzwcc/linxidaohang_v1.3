# 灵犀 V1.3.8 功能说明

版本：`1.3.8-complete-20260921-r8`

## 1. 产品定位

灵犀 V1.3.8 是面向客户现场的机器人导航与讲解控制台。客户只需要让手机和机器人接入同一局域网，在网页完成服务启动、地图选择、导航点操作和讲解任务编排，不需要使用电脑终端。

## 2. 核心能力

### 2.1 一键服务启动

网页可以启动和检查导航、地图、语音兼容网关、Java Agent、知识库检索服务。服务异常时显示中文原因，并保留命令行诊断入口。

### 2.2 地图与导航

- 切换地图并查看地图图片、点位和起点。
- 通过点位名称发起导航、停止导航和查看当前状态。
- 导航回复固定为“收到，正在前往<点位>”，明确导航意图不再被通用模型兜底语句覆盖。
- 连续点位任务使用 PNC 回验、里程计和到达稳定判定，降低到点后下一点位不启动的概率。
- 重定位读取机器人实际定位数据，不依赖虚构参考点。

### 2.3 讲解任务

每个点位可以配置：

- 讲解文本。
- 到达动作、动作区域、表情和灵创资源。
- 到店后的交互等待时间，默认可以为 0 秒，也可以设置自定义秒数。
- 用户与机器人交互结束后的静默等待时间。
- 点位执行顺序和任务名称。

执行顺序是：到达点位 -> 讲解和表情 -> 灵创动作/舞蹈（如果配置） -> 用户交互时段 -> 以最后一次有效交互为起点等待 -> 前往下一点位。最后一个点位结束后任务完成。

### 2.4 动作和表情

本版本修复了明确语音动作依赖豆包模型的问题。高置信动作在 Java Agent 本地识别：

| 语音示例 | AIMDK 动作 |
| --- | --- |
| 握手、跟我握一下手 | `SHAKE_HAND=1003` |
| 比个心、比心 | `INTERACTION_SWEATHEART=3004` |
| 举手 | `RAISE_HAND=1001` |
| 挥手 | `WAVE_HAND` |
| 空动作/停止动作 | 动作 ID 和区域均为 `0` |
| 随机讲话动作 | 动作 ID `6001`，区域 `21` 到 `48` |

“你会握手吗”这类能力询问不会误触发真实动作，会继续作为对话处理。动作请求被确认后，动作状态不会被误当成已完成；讲解流程会等待对应动作的完成或有界超时。

机器人处于 `SAFE`、启动中或动作服务报告 `NOT_READY` 时，控制器会自动调用官方 `SetMcAction`，请求 `STAND_DEFAULT`，带请求时间戳，等待恢复后再重试原动作。

### 2.5 灵创保护

灵创舞蹈或动作执行期间，普通唤醒、聊天和 TTS 会被保护，防止动作中途被打断。安全停止、任务停止和急停类指令仍可用。灵创资源完成或失败后，语音通道自动恢复。

### 2.6 语音降噪、拒识和唤醒

- 没有真实唤醒证据时不接受普通 ASR 文本。
- 支持 SDK KWS/唤醒状态；SDK 未提供完整元数据时，可用同一事件 ID 的 SOC2 日志做有限时效回验。
- 对侧后方声音、低信噪比、回声、低 VAD 概率、低 ASR 置信度和明显重复片段进行拒识。
- 安全短指令如停止、继续、是、否保留。
- 播放回声和未被唤醒的背景语音不会再次触发 Agent。

### 2.7 知识库

灵心知识库检索服务独立运行，Java Agent 通过 Agent Code 查询知识库并将检索上下文交给回答链路。知识库服务异常不会阻断导航和基础动作控制。

## 3. 典型客户流程

1. 手机打开 `http://机器人IP:3000/console/`。
2. 点击“一键开启全部服务”，等待状态均为正常。
3. 选择地图并确认重定位状态。
4. 直接点击点位或对机器人说“前往某某点”。
5. 在网页任务编排中保存多个讲解任务。
6. 说“开始讲解”，到点后机器人完成讲解、动作、表情和可选灵创资源。
7. 交互结束后等待设定秒数，自动继续下一点位。
8. 可说“暂停讲解”“继续讲解”“停止讲解”。

## 4. 不会自动执行的操作

服务启动、健康检查、版本校验和日志查看都不会让机器人移动、重定位或执行动作。真实验收必须由现场人员单独授权，并准备急停。
