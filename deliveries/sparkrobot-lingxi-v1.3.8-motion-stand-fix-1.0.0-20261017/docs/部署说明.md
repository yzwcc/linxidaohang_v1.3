# V1.3.8 预设动作稳定站立修复部署说明

## 1. 校验与安装

将以下文件放在机器人 `/home/run`：

```text
sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017.tar.gz
sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017.tar.gz.sha256
```

执行：

```bash
cd /home/run
sed -i 's/\r$//' sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017.tar.gz.sha256
sha256sum -c sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017.tar.gz.sha256
tar -xzf sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017.tar.gz
cd sparkrobot-lingxi-v1.3.8-motion-stand-fix-1.0.0-20261017
chmod +x install.sh control.sh
sudo bash ./install.sh
```

安装器会先停止 Java Agent/导航兼容服务，备份动作控制器和技能配置，完成 Python 语法检查后重新启动服务。安装失败会自动恢复本次事务备份。

## 2. 验收

确认服务：

```bash
sudo bash ./control.sh status
sudo sparkrobot-lingxi-internal doctor
```

机器人保持静止并处于站立模式，对机器人说：

```text
请和我握手
```

应看到类似日志：

```text
SDK motion rejected ... motion=1003, area=2 ...
SDK motion rejection indicates unstable stand; requesting STAND_DEFAULT before retry
机器人已请求恢复 STAND_DEFAULT，等待稳定后继续动作
SDK motion request acknowledged: motion=1003, area=2
Voice preset motion accepted ... motion=1003, area=2
```

如果第一次回执本身已经接受，不会额外请求站立恢复。不要把“动作请求已接受”当成动作完整结束，它只表示 AIMDK 接受了动作请求。

## 3. 实时日志

```bash
sudo bash ./control.sh logs
```

或：

```bash
sudo journalctl -u lingxi-java-agent-robot.service -f -o short-precise \
  | grep --line-buffered -E 'motion=1003|motion=|STAND_DEFAULT|stable|站立|拒绝|accepted|rejected'
```

## 4. 回滚

查看备份：

```bash
sudo find /var/lib/sparkrobot/lingxi-v1.3.8-motion-stand-fix/backups \
  -mindepth 1 -maxdepth 1 -type d -printf '%TY-%Tm-%Td %TH:%TM:%TS %p\n' \
  | sort -r
```

回滚最近一次：

```bash
sudo bash ./control.sh rollback
```

回滚指定目录：

```bash
sudo bash ./control.sh rollback /var/lib/sparkrobot/lingxi-v1.3.8-motion-stand-fix/backups/时间目录
```

## 5. 判断仍然失败的条件

如果日志先出现 `STAND_DEFAULT` 被接受，等待后仍出现 `motion=1003, area=2` 拒绝，说明 AIMDK/底层运动状态仍未允许握手，不能通过屏蔽播报伪造成功。此时应保留该日志，检查机器人是否正在导航、动作资源占用、急停或底层安全状态。
