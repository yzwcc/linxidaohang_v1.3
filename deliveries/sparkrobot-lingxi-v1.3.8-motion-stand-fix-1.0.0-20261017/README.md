# V1.3.8 预设动作稳定站立修复增量包

版本：`1.0.0-20261017`

本包针对 V1.3.8 现场出现的：

```text
motion=1003, area=2，机器人动作服务拒绝请求，请确认机器人已进入稳定站立模式
```

修复动作服务拒绝回执中的稳定站立场景。机器人收到此类拒绝后，会先请求官方 `SetMcAction/STAND_DEFAULT`，等待短暂稳定，再重新提交原动作。只有恢复后仍被拒绝，才向上层返回失败。

同时合并此前的动作误播修复：禁用 Agent 配置中重复的 `exhibit_commentary -> start_fixed_line_intro` 映射。

本包不重装 AIMDK，不修改地图、导航参数、知识库、灵创资源、灵心配置或豆包密钥。

安装前必须已经安装 V1.3.8 主包，并且当前动作控制器包含 `MC_ACTION_SERVICE` 与 `STAND_DEFAULT` 恢复能力。
