# 灵犀机器人本机导航控制台

当前完整交付为 **V1.3.9 r4（2026-10-19）**，入口见 [交付目录](deliveries/V1.3.9-20261019/README.md)、[完整部署说明](deliveries/V1.3.9-20261019/builder/docs/V1.3.9-完整部署说明.md)及[验证记录](deliveries/V1.3.9-20261019/验证记录.md)。该版本源码固定在对应交付目录的 `source/`，请勿混用下面历史 v1.2.0 的安装路径。

正式产品采用机器人本机部署，不再把多台机器人的导航开关放在固定公网网址上。

## 历史控制台架构（v1.2.0）

```text
客户手机或电脑（与机器人同一网络）
        |
        | http://机器人IP:3000/
        v
机器人本机控制台
  +-- 127.0.0.1:18080 语音/导航统一入口
  +-- 127.0.0.1:8002  地图、点位、任务和重定位
  +-- 本机 SSH 白名单运维
  +-- 本机 Java AgentSDK / 灵心平台连接
```

控制台、Node ARM64 运行时、生产依赖和 systemd 服务全部安装在机器人 `/opt/lingxi-nav-console`。客户设备只负责打开浏览器，不运行任何后台程序；固定公网网站、云服务器和反向 SSH 隧道均不是日常运行依赖。

## 客户使用

1. 机器人开机并连接现场网络。
2. 手机或电脑连接同一网络。
3. 浏览器访问 `http://机器人IP:3000/`。
4. 点击“一键启动全部服务”。
5. 确认语音、灵心、导航、地图在线。
6. 选择现场地图并完成重定位后，再开始点位导航或讲解任务。

机器人 IP 改变后不修改机器人配置，直接在浏览器地址栏使用新 IP。

## 讲解动作与表情

“讲解”页面支持为每个任务步骤独立设置讲解文本、预设动作、动作部位、面部表情和播放模式。任务步骤可以沿用点位效果、明确关闭效果，或使用步骤专属设置。循环表情会在进入下一点、暂停、停止或任务结束时恢复平静。

## 历史 v1.2.0 交付与安装

正式离线包位于 `交付代码包/机器人本机控制台-v1.2.0/`。解压到 ARM64 机器人后执行：

```bash
sudo bash deploy/robot-console/install_robot_console.sh
```

安装器会停用旧公网反向隧道、安装本机控制台、设置开机自启和异常自动重启，但不会覆盖 `/home/agi/robot_local_navigation_v3` 或 `/home/run/lingxi_java_agent` 中现有的导航及语音配置。

## 开发验证

```bash
cd server
npm install
npm run build
npm test
```

正式移动前必须确认 `/slam/lidar_odom` 有实时数据。没有实时定位时可以配置地图、点位和任务，但不要下发导航移动目标。
