- 保留 r18 的到点判定逻辑和 `near_goal_arrival.py`，本增量不替换该文件。

## 安装前

在机器人上确认使用 `run` 用户，且导航空闲、讲解任务已停止或暂停。不要删除旧 release、旧服务或备份。

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

架构应为 `aarch64`，系统应能读取 ROS Humble，并具有 `/home/run`、`/home/agi` 账户。若 AIMDK 已编译，另确认 `/home/agi/aimdk/install/setup.bash` 存在。

将 `.tar.gz` 和同名 `.tar.gz.sha256` 一起上传到 `/home/run`。校验文件不要经过会改写换行符的编辑器。

## 完整安装

首次安装使用以下命令。脚本会校验包、检查 AIMDK 接口、安装导航和知识库服务、配置原生讲解项；凭据通过交互提示输入，不要将密钥写进命令历史或发送到聊天窗口。

```bash
cd /home/run
sha256sum -c lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz.sha256
tar -xzf lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
sha256sum -c SHA256SUMS.txt

read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

安装时按提示输入灵心 App ID、AppKey、AppSecret、豆包 Ark API Key、模型、机器人显示名和 SOC2 地址。输入已有配置时请先确认是目标机器的配置。

如果 AIMDK 尚未安装或编译，先执行：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
bash ./install_all.sh prepare
```

然后登录同一台机器的 `agi` 账户，执行 `/home/agi/01-replace-aimdk.sh` 完成 AIMDK 安装，再回到 `run` 账户执行上面的完整安装命令。不要以 `root` 运行 `install_all.sh`。

## 从旧版升级

当前 r19 完整包的 runtime 实际为 `1.0.19-20261019-r18`。r20 支持从 r11-r18 runtime 升级；升级前确认导航空闲，并建议先通过控制台停止业务服务。不要再次运行 AIMDK 替换脚本。

```bash
cd /home/run
sha256sum -c lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz.sha256
tar -xzf lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
sha256sum -c SHA256SUMS.txt
bash ./install_all.sh preflight
bash ./install_all.sh upgrade
```

`upgrade` 会保留已有 `lingxi-nav.properties`、SOC2 运行配置、地图和讲解任务数据；不会安装 AIMDK、覆盖密钥或重装知识库配置。已编译 AIMDK 不需要重新编译。

`current` 应指向 `/opt/sparkrobot/lingxi-nav/releases/1.0.20-20261021-r20`。JAR 与 bridge 的 SHA-256 应分别与本说明开头一致。确认 Java Agent `active` 且稳定、控制台健康后，再通过网页启动服务。

现场功能回归至少验证：语音导航到一个已保存地点、语音开始讲解、讲解中暂停/继续/停止、普通问答和知识库问答。确认导航与开始讲解没有多余的成功/失败控制回执，同时检查日志中仍保留底层拒绝、超时和状态变化记录。

## 回滚

升级会保留之前的 runtime release。若原生讲解映射事务在 r20 安装时实际修改过 SOC1/SOC2，先使用状态文件中的 transaction 路径回滚该映射；该回滚必须在 current 仍指向 r20 时执行：

```bash
sudo cat /var/lib/sparkrobot/lingxi-native-tour-quiet/full-r20-status.json
```

仅当状态为 `installed` 且包含 `transaction` 时执行：

```bash
sudo python3 \
  /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment/scripts/native-tour-quiet/install.py \
  --rollback '/在此粘贴状态文件transaction字段里的完整路径'
```

之后停止业务服务，再切回 r18 并恢复对应控制脚本：

```bash
sudo sparkrobot-lingxi-internal stop
sudo sparkrobot-lingxi-internal rollback 1.0.19-20261019-r18
sudo install -m 0755 \
  /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment/scripts/control-r18.sh \
  /usr/local/sbin/sparkrobot-lingxi-complete
sudo sparkrobot-lingxi-complete start
sudo sparkrobot-lingxi-internal status
```

不要删除 r20 或 r18 目录和安装器打印的事务备份。若事务回滚本身报错，保留终端输出及 `/var/log/sparkrobot/lingxi-nav/` 日志，避免重复安装覆盖诊断现场。
