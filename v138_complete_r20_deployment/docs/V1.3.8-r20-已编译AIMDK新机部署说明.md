# 灵犀 V1.3.8 r20 已编译 AIMDK 新机部署说明

适用场景：ARM64 新机器人已安装 Ubuntu 22.04、ROS 2 Humble，且 `/home/agi/aimdk/install` 是已编译并验证过的 AIMDK。完整包为 `lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz`，内部导航 runtime 为 `1.0.20-20261021-r20`。

本完整包已合入累计增量 `sparkrobot-lingxi-v1.3.8-voice-control-silent-fix-1.0.10-20261021`，不需要单独再安装该增量包。

**AIMDK 已编译时，不要运行 `/home/agi/01-replace-aimdk.sh`。** `prepare` 只准备系统依赖和安装脚本；是否替换 AIMDK 由你显式执行该脚本决定。完整安装前仍会以 `agi` 服务用户实际加载 ROS/AIMDK 环境并导入必需接口。

## 1. 检查新机

登录 `run` 账户：

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -r /home/agi/aimdk/install/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

确认 `uname -m` 为 `aarch64`，并检查实际 AIMDK 接口：

```bash
sudo -u agi env -i \
  HOME=/home/agi USER=agi LOGNAME=agi SHELL=/bin/bash \
  PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin \
  LANG=C.UTF-8 bash --noprofile --norc <<'BASH'
set -e
set +u
source /opt/ros/humble/setup.bash
source /home/agi/aimdk/install/setup.bash
set -u
python3 - <<'PY'
import rclpy
from aimdk_msgs.msg import MessageHeader, PncTaskRequest, TtsPriorityLevel
from aimdk_msgs.msg import CommonState, McActionCommand, McCommonState
from aimdk_msgs.msg import McControlArea, McFsmState, McInputAction, McPresetMotion, RequestHeader
from aimdk_msgs.srv import PlayTts, PlayEmoji, ExecuteActionResource
from aimdk_msgs.srv import SetMcAction, SetMcInputSource, SetMcPresetMotion
print("AIMDK interfaces OK")
PY
test -x /home/agi/aimdk/install/examples/lib/examples/navigation
BASH
```

`PncTaskResponse` 是可选接口；如果 AIMDK 中没有该类型，导航到点仍使用包内的里程计判定，不需要为此重新编译 AIMDK。

## 2. 上传并校验

把完整包和 `.sha256` sidecar 同时放入 `/home/run`。直接校验原始文件，不要用文本编辑器保存或转换校验文件：

```bash
cd /home/run
sha256sum -c lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz.sha256
tar -xzf lingxi-v1.3.8-complete-20261021-r20-deployment.tar.gz
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
sha256sum -c SHA256SUMS.txt
```

所有项目都显示 `OK` 后继续。出现校验错误时停止，不要手动改写 SHA 清单。

## 3. 准备系统依赖

```bash
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
bash ./install_all.sh prepare
```

此步骤安装运行依赖、部署检查脚本，并将包内的 AIMDK 压缩组件复制到 `/home/agi`。它不会编译 AIMDK，也不会替代现有 `/home/agi/aimdk/install`。本场景不要执行 `/home/agi/01-replace-aimdk.sh`。

## 4. 安装完整产品

确认 App ID、AppKey、AppSecret、豆包 Ark API Key、模型、机器人显示名、SOC2 地址和知识库智能体 Code 已准备好。凭据只在本机交互式输入。

```bash
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

按提示逐项输入配置。SOC2 初始化需要 SSH 登录密码和 sudo 密码；安装过程不会把这些密码写进部署包。不要在命令中附加密钥，也不要把 `secrets.env` 上传或发送给他人。

完整安装包括导航和本机语音服务、网页控制台、知识库检索服务及原生讲解映射配置。不要额外解压或安装包内某个 `components` 文件，也不要另行安装 1.0.10 增量包。

## 5. 检查并启动

```bash
cd /home/run/lingxi-v1.3.8-complete-20261021-r20-deployment
bash ./install_all.sh preflight
sudo sparkrobot-lingxi-internal status
sudo sparkrobot-lingxi-internal doctor
sudo sparkrobot-lingxi-complete doctor
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
sudo systemctl show lingxi-java-agent-robot.service \
  -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
hostname -I
```

runtime 应为 `1.0.20-20261021-r20`，Java Agent 应稳定运行。浏览器访问 `http://机器人IP:3000/console/`，确认状态后再启动业务服务。

若预检失败，不要运行 AIMDK 替换脚本，也不要删除 release。保留错误输出，先检查：

```bash
sudo journalctl -u lingxi-java-agent-robot.service -u lingxi-nav-console.service \
  -n 150 --no-pager
sudo tail -n 150 \
  /var/log/sparkrobot/lingxi-nav/java-agent.log \
  /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
```

## 6. 功能验收

先在安全、空旷区域做语音导航和讲解测试，再测试知识库问答、讲解中断/恢复及网页启动/停止。确认导航或开始讲解没有额外成功/失败控制播报；同时核对服务状态和日志。

自动化测试不等同于机器人现场验收。尤其是固件或独立原生语音服务产生的播报，需要在目标机器人上实际确认。
