# 灵犀机器人客户日常使用手册

版本：v1.3.1  
适用对象：机器人日常使用人员

本手册只介绍日常操作，不需要电脑基础，不需要 SSH，也不要修改机器人系统文件。

## 1. 使用前准备

1. 打开机器人电源，等待机器人完成开机。
2. 确认手机和机器人连接同一个 Wi-Fi 或手机热点。
3. 确认机器人周围没有障碍物，急停按钮可以使用。
4. 找到机器人当前 IP。IP 通常由部署人员提供，也可能显示在机器人网络信息或现场路由器设备列表中。

机器人更换网络后 IP 可能变化。网页地址也要跟着变化，不能继续使用旧 IP。

## 2. 打开网页并启动服务

在手机浏览器地址栏输入：

~~~text
http://机器人当前IP:3000/console/
~~~

例如机器人当前 IP 是 192.168.0.203，就打开：

~~~text
http://192.168.0.203:3000/console/
~~~

进入页面后点击“一键开启全部服务”，等待页面显示导航、地图、语音和灵心连接正常。客户不需要在电脑终端执行启动命令。

如果页面提示机器人未连接：

1. 确认手机和机器人是同一个网络。
2. 确认地址中的 IP 是机器人当前 IP。
3. 刷新网页后再点击一次。
4. 仍然无法使用时联系部署人员，不要反复点击导航或修改系统设置。

## 3. 页面主要功能

- 首页：查看机器人在线状态、当前地图、导航状态和任务状态。
- 导航：选择点位后点击“去这里”，也可以点击“停止导航”。
- 地图配置：切换地图、查看地图图片、查看和维护导航点位。
- 讲解任务：选择已保存的路线任务，开始、暂停、继续或停止讲解。
- 服务状态：查看导航、语音和灵心是否在线。

所有提示均以中文显示。机器人 IP 不是固定值，当前网页连接到哪个 IP，就控制哪台机器人。

## 4. 单点导航

1. 进入“导航”页面。
2. 确认当前地图名称正确。
3. 从点位列表选择目标点。
4. 点击“去这里”。
5. 机器人会播报“收到，正在前往目标点”，并开始移动。
6. 到达后等待页面显示完成。

需要立即停止时点击“停止导航”，并确认机器人已经停止后再靠近。

第一次使用新地图或机器人位置不准确时，先完成“实际位置重定位”，再进行导航。

## 5. 根据机器人实际位置重定位

重定位不需要设置人为参考点，依据机器人此刻在真实环境中的位置和方向修正地图定位。

操作前：

1. 选择机器人当前实际使用的地图。
2. 确认地图与现场环境一致。
3. 让机器人处于开阔、可识别的位置。
4. 确认机器人没有处于建图模式。

操作步骤：

1. 打开“定位/重定位”区域。
2. 点击“获取当前定位”确认系统能收到定位数据。
3. 点击“自动重定位”。
4. 等待页面显示重定位完成，再查看位置和朝向是否与现场一致。

如果页面提示没有定位数据，不要连续重复点击。先停止导航，确认地图和服务状态，必要时联系部署人员。

## 6. 开始讲解任务

### 网页操作

1. 进入“讲解任务”。
2. 从已保存任务中选择需要执行的路线。
3. 确认当前地图和起点正确。
4. 点击“开始讲解”。

### 语音操作

在服务正常、机器人可以听到声音时，可以说：

~~~text
开始讲解
~~~

机器人确认后开始执行所选任务。任务会按保存的点位顺序前往各点，到达后播报配置内容，并按配置执行动作、表情和可选灵创舞蹈。

如果某个点没有配置灵创舞蹈，机器人会完成该点的讲解和普通动作后继续前往下一个点。

## 7. 讲解过程中的语音指令

支持以下指令：

| 说法 | 作用 |
| --- | --- |
| “暂停讲解” | 暂停当前讲解任务 |
| “继续讲解” | 从暂停位置继续 |
| “停止讲解” | 结束当前讲解任务 |
| “停止导航” | 停止当前移动 |
| 普通问题 | 行进中可正常询问机器人 |

唤醒机器人后，讲解会按策略暂停，方便用户交流。交流结束后说“继续讲解”即可恢复。灵创动作执行阶段不会被普通聊天随意抢占；需要结束任务时使用“停止讲解”或网页停止按钮。

语音服务会忽略部分无意义填充音、重复识别片段和机器人刚播放的回声。交流时先正常唤醒再提问；如果没有回应，等播报结束后重新唤醒并清楚、简短地重复一次。文本急停指令可优先处理，但不能代替实体急停按钮。

## 8. 配置和维护任务

有权限的客户可以在网页配置任务：

1. 选择地图。
2. 调整点位顺序。
3. 为每个点填写到达播报文本。
4. 选择普通动作和表情。
5. 按需要选择一个当前可用的灵创动作或舞蹈。
6. 保存任务并给任务取容易记忆的中文名称。

建议先保存一个短路线测试，再保存正式路线。动作或舞蹈选项为空时，通常表示机器人还没有下载对应灵创资源，应联系部署人员检查资源，不要自行填写不存在的资源名称。

## 9. 切换地图

1. 打开“地图配置”或页面顶部地图选择框。
2. 选择需要使用的地图。
3. 等待页面显示地图切换成功。
4. 确认点位列表属于这张地图。
5. 必要时重新执行实际位置重定位。

不同地图的点位不能混用。切换地图后如果点位列表为空，先确认这张地图是否已经录入点位。

## 10. 安全注意事项

- 机器人移动前确认前方、侧方和后方没有人或障碍物。
- 讲解任务第一次运行时必须有人全程看护。
- 机器人异常移动时立即使用实体急停，再处理网页问题。
- 不要在机器人移动时拔电、断网或强制关机。
- 不要同时在多个手机上启动不同任务。
- 不要把管理员密码、灵心密钥或网页截图发到公开群组。

## 11. 常见提示和处理

### “服务未连接”

确认手机和机器人同一网络，检查 IP 是否为最新地址，刷新网页后重新点击“一键开启全部服务”。

### “没有找到导航点”

确认已经选择正确地图，并且该地图已经录入点位。新地图尚未配置点位时这是正常提示。

### “暂未收到定位数据”

确认当前地图正确，停止重复重定位，联系部署人员检查机器人定位模式。

### 机器人不走

先点击“停止导航”，确认周围安全后联系部署人员。不要连续点击“去这里”，以免重复提交任务。

### 机器人能导航但没有语音

查看网页服务状态；刷新后重新执行“一键开启全部服务”。仍无声音时联系部署人员，不要修改任务数据。

### 讲解暂停后无法继续

说“继续讲解”，或在网页点击“继续讲解”。如果任务已经被停止，需要重新选择任务并开始。

## 12. 联系部署人员时提供的信息

请提供：

- 当前机器人 IP；
- 页面显示的中文错误提示；
- 当前地图名称和任务名称；
- 故障发生在第几个点位；
- 是否能正常急停。

不要自行删除日志、安装包或系统目录。部署人员会根据这些信息进行安全排查。
