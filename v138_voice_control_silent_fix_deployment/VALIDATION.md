# 修复范围与验证边界

## 根因

R19 运行 JAR 的 SHA-256 与旧 1.0.8 JAR 相同，为 `3140d03c2d81623ef2efb362400699c9e9dae7d4c09409a7431fff42bdb62372`。r19 完整包因而没有带上 1.0.9 对讲解启动回调时序的 Java 修复。另一方面，Python bridge 仅在请求显式携带静音标记且事件 ID 匹配时抑制导航/讲解步骤的失败 TTS；其他回调顺序或标记缺失会落回播报分支。

## 修复

- 恢复经过实际 AgentSDK 回调模拟验证的 1.0.9 累计 Java JAR，包含导航和开始讲解的控制接管、空结果收尾及失败回调抑制。
- bridge 对所有非自动返航的导航/讲解失败与超时只写日志，不再依赖 `silent_control_reply` 运行时标记决定是否播报。
- 自动返航问题提示仍保留；用户导航、讲解任务各步骤的失败和超时不发 TTS。
- 不拦截普通问答、到点讲解正文、动作执行结果、暂停/继续/结束反馈。
- 安装仅适用于 r19 的 r18 runtime，并校验目标 Java、AgentSDK、运行 manifest、bridge 和导航控制脚本。未知版本在停服务前拒绝安装。
- 保留 r18 自带的新版 `near_goal_arrival.py`，不将其降级成旧增量包中的版本。

## 自动化检查

- Java AgentSDK 回调回归沿用 1.0.9 累计测试：导航/开始讲解成功、拒绝、超时、异常 ACK、重复 ASR/Audio 回调、SDK 输出失败均验证无控制结果 TTS 或 SDK 错误帧。
- Python bridge 测试覆盖用户导航和讲解步骤失败/超时，在静音标记为真、假、字符串或缺失时均不发声；非自动返航的未识别事件同样只记日志。
- 保留自动返航问题播报和到点讲解正文的独立回归断言。
- 安装器使用临时目录模拟安装、幂等重装、服务原状态保留、事务回滚、未知基线拒绝和校验清单篡改。

未在真实机器人、SOC2 原生服务或扬声器硬件上执行部署/声学验收。若仍出现播报，需用日志区分是否来自独立 SOC2 原生语音进程；本增量仅控制灵犀 Java Agent 与本机导航 bridge 的输出。
