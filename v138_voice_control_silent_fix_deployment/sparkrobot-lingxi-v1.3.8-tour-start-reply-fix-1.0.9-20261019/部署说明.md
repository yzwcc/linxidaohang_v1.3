# V1.3.8 讲解启动语音接管修复部署说明

版本：1.0.9-20261019。适用于已核验的 V1.3.8 r15、r16，以及对应的累计增量包 1.0.0～1.0.8；安装器会在停服务前比对实际文件和启动路径。

## 本次变化

保留已由用户确认有效的语音导航静默逻辑。针对语音开始讲解，完成唤醒和讲解保护检查后，尽早发送 SDK `chat` 接管，并在查询/提交任务结果前完成中性回复流。仅允许“收到”这一输入回执，不播报启动成功、失败、拒绝、超时或“没有学会这个动作”。

“收到”只代表指令已收到，不表示任务执行成功。真实执行状态仍在网页和日志中显示。默认开始命令会在查询任务命令词前结束回复流；自定义命令词及模型识别出的讲解意图在确定意图后、提交任务前完成回复流。保留重复指令保护、灵创保护、讲解正文、普通问答、暂停、继续、结束及此前到点/TTS 修复。

本包已累计包含 1.0.8 和此前修复，可以直接覆盖已安装 1.0.8 的机器。无需重装、编译 AIMDK；地图、任务、密钥、知识库和语音配置不改动。安装过程不会下发运动指令。

## 安装

将本次 `.tar.gz` 和同名 `.tar.gz.sha256` 上传至机器人 `/home/run`。先在网页结束导航和讲解，确认机器人停稳，然后执行：

```bash
cd /home/run &&
sha256sum -c sparkrobot-lingxi-v1.3.8-tour-start-reply-fix-1.0.9-20261019.tar.gz.sha256 &&
tar -xzf sparkrobot-lingxi-v1.3.8-tour-start-reply-fix-1.0.9-20261019.tar.gz &&
cd sparkrobot-lingxi-v1.3.8-tour-start-reply-fix-1.0.9-20261019 &&
sudo bash ./install.sh --check &&
sudo bash ./install.sh
```

安装会短暂停止 Java 和导航服务组，然后恢复安装前各自的运行状态。安装前已停止的服务会继续保持停止，需要业务运行时执行：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal status
sudo sparkrobot-lingxi-internal doctor
```

不要混用以前下载的安装包或单独复制 JAR。若预检提示未知版本/自定义改动，保留输出，不要绕过校验。

## 现场验收

```bash
sudo tail -n 100 -F /var/log/sparkrobot/lingxi-nav/java-agent.log /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
```

1. 每次重新唤醒后说“开始讲解任务”“开始讲解”以及网页配置的自定义开始命令词。允许听到“收到”，不能出现成功、失败或拒绝提示；对应任务正常启动，到点讲解正文正常播放。
2. 重复开始指令不得重复启动。忙碌、无任务、无效任务及通信异常只记日志，不假报任务已成功执行。
3. “带我去门口”的导航静默效果应继续保留；普通问答、暂停/继续/结束任务正常。
4. 灵创保护阶段不得因为提前接管而被这条启动指令打断。

日志中应先出现 `Tour start input receipt completed before dispatch`，再出现对应 `/task/start request`。默认开始命令还应先于 `/task/match response` 出现该日志。停止实时查看按 `Ctrl+C`。

已完成真实 SDK 协议与本地模拟服务的离线回归，统计见 `交付验证结果.json`。本次未连接或部署机器人，未声称已完成厂商原生进程的声音验收。如果现场仍有额外提示，用上述日志区分是否为另一个独立进程发声。

## 回滚

结束任务并停稳。用安装器打印的完整备份目录替换下面的占位符：

```bash
cd /home/run/sparkrobot-lingxi-v1.3.8-tour-start-reply-fix-1.0.9-20261019
sudo bash ./install.sh --rollback /var/lib/sparkrobot/lingxi-tour-start-reply-fix/backups/实际备份目录
```

回滚恢复本次安装前的文件、权限、运行清单及服务运行状态。备份损坏或安装后又更新过其他补丁时，安装器会拒绝覆盖。
