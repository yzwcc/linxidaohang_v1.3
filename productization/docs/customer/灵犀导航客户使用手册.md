# 灵犀机器人导航控制台客户使用手册

版本日期：2026-08-26  
适用人员：展厅、展馆、学校、门店及项目现场操作人员

## 1. 日常使用只需要什么

- 已完成厂商部署的机器人。
- 一台手机、平板或电脑。
- 客户设备与机器人连接同一个 Wi-Fi 或热点。
- 机器人当前 IP 地址。

无需安装电脑软件，无需登录机器人终端，也无需使用命令行。

## 2. 打开控制台

在浏览器地址栏输入：

```text
http://机器人IP:3000/
```

例如机器人 IP 为 `192.168.0.203`：

```text
http://192.168.0.203:3000/
```

机器人切换网络后，只需要把浏览器地址改为新的机器人 IP，不需要在网页中填写旧机器人地址。

## 3. 一键启动全部服务

1. 机器人开机后等待联网和底层系统启动完成。
2. 打开控制台首页。
3. 点击“一键启动全部服务”。
4. 等待页面完成重新检查。
5. 确认语音、灵心、导航和地图服务均显示可用。

启动过程中不要连续重复点击。若某项未就绪，先点击“重新检查”；仍未恢复时使用页面对应的重启按钮或联系售后。

## 4. 地图切换

1. 进入“地图”。
2. 点击刷新地图列表。
3. 选择机器人当前实际所在场地对应的地图。
4. 点击切换并等待页面确认当前地图。
5. 核对地图预览和点位名称。

选择错误地图会导致定位和导航方向错误。机器人不在该地图的真实环境中时，不要执行重定位或导航。

## 5. 获取当前定位与重定位

### 获取当前定位

点击“获取当前定位”可以查看机器人当前坐标和朝向。保存新点位时可使用机器人实际位置，减少手工填写误差。

### 自动重定位

1. 确认机器人实际处于当前地图对应的场地。
2. 清理机器人周围障碍物。
3. 点击“自动重定位”。
4. 等待系统回验定位结果。
5. 页面显示定位有效后，再开始导航。

若页面提示没有实时定位、底层定位未输出或地图不一致，请停止操作，重新核对地图并重启相关服务；不要反复下发导航目标。

## 6. 点位管理

在地图页面可以：

- 新增点位。
- 使用机器人当前定位保存点位。
- 修改点位名称、位置和朝向。
- 设置语音别名和到达播报内容。
- 设置起点或返航点。
- 删除不再使用的点位。

点位修改后先保存，再刷新确认。首次使用新点位时，选择短距离路线并安排人员现场看护。

## 7. 前往指定点位

1. 进入“导航”。
2. 选择目标点位。
3. 确认地图和定位状态正常。
4. 点击“去这里”。
5. 需要中止时点击“停止导航”或使用实体急停。

语音服务在线后，也可以说“去前台”“带我去展厅”等指令。机器人接收有效任务后会给出前往目标点位的确认回复。

## 8. 创建多套讲解任务

1. 进入“讲解”。
2. 点击新建任务并填写任务名称。
3. 按顺序添加需要到达的点位。
4. 为每一步填写到达后的讲解内容。
5. 按需设置讲解动作、动作部位、表情和播放方式。
6. 按需选择机器人已有的灵创舞蹈或动作资源。
7. 点击保存并设为当前任务。

可以保存多套任务，并在开始前选择任意一套。任务名称建议体现场景，例如“标准参观路线”“领导接待路线”。

## 9. 讲解步骤效果

每一步可以配置：

- 讲解文本
- 普通预设动作
- 动作部位或区域
- 面部表情
- 表情播放一次或循环播放
- 可选灵创舞蹈或动作资源

“沿用点位设置”表示使用点位默认效果；“不执行”表示该步骤明确关闭对应效果。首次使用新动作或舞蹈时，必须确保机器人稳定站立并留出足够空间。

## 10. 开始、暂停、继续和停止讲解

网页按钮和语音均可控制当前任务：

- “开始讲解”
- “暂停讲解”
- “继续讲解”
- “停止讲解”

暂停或停止后，系统会停止当前任务推进，并尝试结束仍在执行的动作和循环表情。不要在机器人动作尚未安全结束时靠近。

## 11. 普通导航自动返航

普通点位导航到达后，如果连续 30 秒没有新的有效交互，机器人可按项目配置返回起点。讲解任务完成最后一个点位后直接结束，不进入该返航等待。

## 12. 常见提示

| 页面提示 | 处理方式 |
|---|---|
| 导航服务未连接 | 点击一键启动或重启导航服务，然后重新检查 |
| 灵心未连接 | 重启语音服务并等待平台连接状态刷新 |
| 当前地图不一致 | 切换到机器人实际所在场地对应地图 |
| 尚未获取有效定位 | 在正确地图现场执行自动重定位 |
| 机器人忙碌 | 等待当前任务结束，或先停止当前任务 |
| 未找到指定点位 | 检查点位名称、语音别名和当前地图 |
| 动作未执行 | 确认机器人稳定站立、动作和部位匹配 |
| 新地图未显示 | 刷新地图列表；仍无结果时联系售后检查地图保存状态 |
| 网页无法打开 | 确认手机与机器人同网、IP 正确且地址含 `:3000` |

## 13. 安全要求

1. 移动前必须确认地图与真实场地一致、定位有效。
2. 首次测试地图、点位或任务时，现场人员必须可随时使用实体急停。
3. 不在楼梯、玻璃门、狭窄通道或人员密集区域直接测试新路线。
4. 动作和舞蹈前确保机器人稳定站立，周围留有足够安全空间。
5. 网页停止按钮不能代替实体急停。
6. 不拆卸机器人、不修改系统文件、不向第三方提供机器人维护账号。

## 14. 联系售后前准备

请记录：

- 机器人当前 IP。
- 页面显示的当前地图和定位状态。
- 哪个服务显示异常。
- 操作时间和出现问题前的步骤。
- 页面错误提示截图。

不要在聊天中发送平台密钥、密码或机器人维护账号。
