## A. 发布制品

- [ ] 版本号不含 `test`、`dev` 或 `local`。
- [ ] 许可证绑定本次目标机器人设备指纹。
- [ ] 正式私钥为 AES-256 加密私钥，未进入机器人或归档。
- [ ] `deploy_robot.py --verify-only` 通过。
- [ ] `audit_release.py` 通过并保存审计 JSON。
- [ ] 归档 SHA-256 已登记：________________________________。
- [ ] 归档内不含安装器、源码、mapping、私钥、口令或 API Key。
- [ ] ARM64 临时冒烟验证通过，临时目录已清理。

## B. 安装与持久化

- [ ] `/opt/sparkrobot/lingxi-nav/current` 指向本次版本。
- [ ] `sparkrobot-lingxi-product verify` 通过。
- [ ] `lingxi-nav-console.service` 已启用且运行中。
- [ ] 控制台 `/health` 返回 `ok=true`。
- [ ] 许可证、公钥和客户密钥配置权限符合要求。
- [ ] 地图、点位、任务和配置位于持久状态目录。
- [ ] 升级场景已确认旧地图、点位、任务和客户配置未丢失。
- [ ] SOC2 专用 SSH key 已配置；未向客户提供 key 或 SSH 密码。

## C. 客户网页独立启动

先重启机器人并等待底层系统上线，不在终端手工启动导航或语音业务服务。

- [ ] 手机连接机器人同一局域网。
- [ ] `http://机器人IP:3000/` 可打开，页面中文且手机布局正常。
- [ ] 点击“一键启动全部服务”后，导航、地图、语音和灵心状态可恢复。
- [ ] 重新登录或刷新页面后状态仍正确，没有依赖部署电脑常驻。
- [ ] 网页不能执行任意 shell 命令，客户看不到密钥和内部文件路径。

## D. 地图与定位

- [ ] 地图列表包含机器人已有地图和最新创建地图。
- [ ] 地图图片可预览。
- [ ] 地图切换后网页地图与底层当前地图一致。
- [ ] 获取当前定位可返回机器人实际坐标和朝向。
- [ ] 在机器人真实处于该地图现场时，自动重定位完成并通过实时数据回验。
- [ ] `/slam/lidar_odom` 没有数据时，网页阻止移动并给出中文提示。

## E. 语音与灵心

- [ ] 灵心平台显示正确 AppId 的机器人连接在线。
- [ ] 现实中唤醒机器人后，ASR 回调和机器人扬声器播放均正常。
- [ ] 普通问答不会误报导航服务未连接。
- [ ] 导航意图接收后只播放正确的前往点位确认回复。
- [ ] 客户灵心配置与独立直播项目配置相互隔离。

## F. 导航与讲解配置

- [ ] 地图点位可新增、修改、删除和保存。
- [ ] 可保存多套讲解任务并切换当前任务。
- [ ] 每一步可保存讲解文本、动作、动作部位、表情和可选灵创资源。
- [ ] 网页与语音均可开始、暂停、继续和停止讲解。
- [ ] 讲解结束、暂停或停止后，动作与循环表情能结束或恢复。
- [ ] 普通导航 30 秒无交互返航策略与项目约定一致。

## G. 真实移动安全验收

仅在客户明确授权、机器人电量充足、现场清场且人员握有实体急停时执行。

- [ ] 使用短距离点位完成单点导航。
- [ ] 到达位置和最终朝向满足项目容差。
- [ ] 停止导航和实体急停有效。
- [ ] 使用一条短讲解路线验证到点 TTS、动作和表情。
- [ ] 新动作或灵创舞蹈已逐项完成安全验收。

若本次未获移动授权，填写：`未执行真实移动测试，待现场授权后补验`。

## H. 客户交付

- [ ] 仅交付客户使用手册 PDF、网页地址和售后联系方式。
- [ ] 未交付源码、厂商文档、部署工具、设备归档、许可证工具或密钥。
- [ ] 已向客户说明地图、定位、急停和动作安全要求。
- [ ] 客户已能独立完成开机、打开网页和一键启动。
