# 灵犀机器人导航控制台客户使用文档

本文档给现场客户日常使用，不涉及服务器部署细节。

## 1. 使用前准备

请确认：

```text
机器人已开机
机器人底层系统已启动完成
手机和机器人连接在同一个现场网络
机器人电量充足
现场网关服务已运行
```

打开网址：

```text
https://daohang.sparkrobot.top/console/
```

建议使用手机浏览器打开，也可以使用平板或电脑浏览器。

## 2. 第一次进入

进入网页后，先完成以下步骤：

```text
1. 填写机器人 IP
2. 点击保存
3. 等待连接状态刷新
4. 点击启动服务
5. 检查启动状态
6. 选择地图
7. 自动重定位
8. 开始导航或讲解
```

机器人 IP 可以在机器人网络设置、路由器后台或现场网络工具中查看。

示例：

```text
192.168.0.203
192.168.0.197
192.168.1.88
```

## 3. 日常启动流程

每天开机后按这个顺序操作：

```text
1. 机器人开机
2. 等待机器人底层系统启动完成
3. 手机打开控制台网址
4. 确认机器人 IP 正确
5. 点击启动服务
6. 等待“启动检查”全部正常
7. 选择今天要使用的地图
8. 点击自动重定位
9. 开始导航或讲解任务
```

如果 IP 没变，可以直接刷新状态并启动服务。

如果 IP 变了，只需要重新填写 IP 并保存。

## 4. 状态说明

### 4.1 语音服务

正常表示机器人可以通过灵心平台接收语音指令。

异常时，语音导航可能不能用，但网页按钮导航仍可能可用。

### 4.2 灵心平台连接

正常应显示类似：

```text
jwt auth success
```

如果不正常，请点击重启语音服务，或联系实施人员检查灵心配置。

### 4.3 机器人导航层

正常表示机器人本地导航 bridge 和地图服务在线。

异常时，网页无法正常导航或加载地图。

### 4.4 地图与点位

正常表示已经读取到当前地图和导航点。

如果地图不对，请到地图配置里切换地图。

### 4.5 现场重定位

正常表示机器人已经知道自己在地图里的位置。

如果不正常，请先自动重定位，重定位成功后再导航。

## 5. 填写或更换机器人 IP

当机器人换网络、重启、或现场有多台机器人时，IP 可能变化。

操作：

```text
1. 在控制台找到机器人 IP 输入框
2. 输入当前机器人 IP
3. 点击保存
4. 等待约 10 秒
5. 点击刷新状态
```

注意：

```text
手机和机器人必须在同一个现场网络
IP 必须填写机器人当前真实 IP
不要填写公网服务器 IP
不要填写网址域名
```

## 6. 启动服务

点击“启动服务”后，系统会检查和启动：

```text
机器人导航 bridge
地图服务
语音服务
灵心平台连接
```

如果显示“成功”，继续下一步。

如果显示失败，先点击“重启服务”，再刷新状态。

## 7. 切换地图

进入地图配置页面，可以看到地图列表。

操作：

```text
1. 选择需要使用的地图
2. 点击切换地图
3. 等待当前地图更新
4. 检查点位列表是否正确
5. 重新自动重定位
```

重要：

```text
切换地图后必须重新重定位
当前地图、点位和重定位地图必须一致
```

## 8. 自动重定位

自动重定位用于让机器人确认自己在当前地图中的位置。

操作：

```text
1. 确认机器人在地图对应的真实场地里
2. 确认当前地图正确
3. 点击自动重定位
4. 等待结果显示成功
```

重定位成功后再开始导航。

如果重定位失败：

```text
确认机器人不在建图模式
确认机器人底层定位已启动
确认机器人在当前地图对应场地内
尝试重启机器人底层导航服务
重新点击自动重定位
```

## 9. 点位导航

网页导航：

```text
1. 在点位列表中选择目标点
2. 点击“去这里”
3. 机器人开始前往该点
4. 需要取消时点击“停止导航”
```

语音导航：

```text
灵犀灵犀，带我去大门口
灵犀灵犀，去起点
灵犀灵犀，导航到永动机
```

机器人应回复：

```text
收到，正在前往大门口。
```

如果机器人能动但回复异常，请联系实施人员检查语音服务日志。

## 10. 停止导航

网页操作：

```text
点击“停止导航”
```

语音操作：

```text
灵犀灵犀，停止导航
灵犀灵犀，取消导航
灵犀灵犀，停下
```

机器人会停止当前导航任务。

## 11. 地图点位管理

在地图配置页面可以管理点位。

支持：

```text
查看点位
新增点位
编辑点位
删除点位
设置起点
设置语音别名
设置到达播报文本
```

### 11.1 新增点位

操作：

```text
1. 打开地图配置
2. 在地图上选择位置
3. 填写点位名称
4. 设置方向
5. 保存
```

建议点位名称简短清晰，例如：

```text
大门口
前台
展厅
会议室
充电点
起点
```

### 11.2 语音别名

如果客户经常用不同叫法，可以添加别名。

示例：

```text
点位名称：大门口
语音别名：门口、入口、正门
```

这样用户说“去门口”也能匹配到“大门口”。

### 11.3 到达播报文本

每个点位可以设置到达后的播报内容。

示例：

```text
欢迎来到展厅入口，这里展示的是公司的核心产品。
```

## 12. 讲解任务

讲解任务是多个点位组成的一条路线。

系统支持保存多个讲解任务。

例如：

```text
任务一：客户参观路线
任务二：展厅讲解路线
任务三：领导接待路线
```

### 12.1 新建讲解任务

操作：

```text
1. 打开地图配置
2. 进入讲解任务区域
3. 点击新建任务
4. 输入任务名称
5. 添加讲解点位
6. 调整点位顺序
7. 保存
```

### 12.2 选择当前讲解任务

如果有多个任务，必须选择一个作为当前任务。

操作：

```text
1. 在任务列表选择一个任务
2. 点击设为当前任务或保存当前选择
3. 确认当前任务名称显示正确
```

语音“开始讲解”会启动当前选中的任务。

### 12.3 启动讲解任务

网页操作：

```text
点击“开始讲解任务”
```

语音操作：

```text
灵犀灵犀，开始讲解
灵犀灵犀，开始讲解任务
```

机器人会按当前任务的点位顺序开始移动和讲解。

### 12.4 暂停和继续讲解

网页操作：

```text
点击“暂停讲解”可保留当前任务进度
点击“继续讲解”会从暂停的步骤继续
```

语音操作：

```text
灵犀灵犀，暂停讲解
灵犀灵犀，继续讲解
```

### 12.5 停止讲解任务

网页操作：

```text
点击“结束讲解任务”
```

语音操作：

```text
灵犀灵犀，结束讲解
灵犀灵犀，停止讲解任务
```

讲解停止或全部步骤完成后，如果中间没有新的用户交互，机器人等待 30 秒再返回起点。

## 13. 常见问题

### 13.1 网页打不开

检查：

```text
手机是否能上网
网址是否输入正确
域名是否可访问
```

网址：

```text
https://daohang.sparkrobot.top/console/
```

### 13.2 显示机器人离线

处理：

```text
确认机器人开机
确认机器人和手机在同一现场网络
确认机器人 IP 填写正确
点击保存 IP
等待 10 秒后刷新
点击启动服务
```

### 13.3 地图加载不出来

处理：

```text
确认机器人地图服务已启动
点击重启服务
刷新页面
重新选择地图
```

### 13.4 自动重定位失败

处理：

```text
确认机器人在当前地图对应的真实场地里
确认当前地图选择正确
确认机器人没有处于建图状态
重启机器人底层导航服务
重新自动重定位
```

### 13.5 机器人说“没学会这个动作”

如果导航没有执行：

```text
确认点位名称存在
确认语音别名配置正确
确认语音服务正常
```

如果导航已经执行但回复异常：

```text
联系实施人员检查灵心语音服务
```

新版系统正常回复应为：

```text
收到，正在前往<点位>。
```

### 13.6 机器人走错地图

处理：

```text
立即停止导航
检查当前地图
切换到正确地图
重新自动重定位
再开始导航
```

### 13.7 换机器人后怎么操作

如果只是换机器人 IP：

```text
网页填写新机器人 IP
点击保存
等待 10 秒
刷新状态
启动服务
选择地图并重定位
```

如果换了现场网关设备：

```text
联系实施人员重新安装现场网关脚本
```

## 14. 安全注意事项

```text
导航前确认现场通道安全
机器人低电量时不要执行长距离任务
重定位失败时不要强行导航
切换地图后必须重新重定位
现场有人值守时再做首次验证
紧急情况使用机器人急停或网页停止导航
```

## 15. 推荐日常操作口诀

```text
先开机
填 IP
启服务
选地图
重定位
再导航
```
