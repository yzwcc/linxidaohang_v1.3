# V1.3.8 语音导航与讲解启动静默回执增量包

版本：1.0.8-20261019。

## 适用版本与效果

适用于已核验的 V1.3.8 r15（内部版本 `1.0.19-20261017-r15`）、r16（`1.0.19-20261019-r16`），以及它们已安装的累计控制回复补丁 1.0.0～1.0.7。安装器逐项比对 JAR、SDK、Python 文件、运行清单和启动路径；其他版本或自定义改动会在停止服务前被拒绝。

本包包含 1.0.7 的到点判定与 TTS 异步确认修复，以及此前累计控制回复修复，不需要先装旧增量包。

按本次确认的口径：“收到”这类中性回应可以接受，“执行成功”“执行失败”“抱歉，暂时没有学会这个动作”等结果或拒绝播报均不允许。本包默认将这两类启动回执全部静默，不额外插入“收到”，避免与任务开始后的讲解正文抢占语音。

- 语音导航、语音开始讲解（含网页配置的自定义开始命令词）不再由应用播报启动成功、拒绝、失败或回执异常。
- 在本地执行前，通过 SDK 发送 `chat` 接管信号，提示词为 `null`；不下发重复技能、不返回成功或失败文本、不因回执丢失而重新执行。
- 由 Java 提交的导航/讲解会话携带静默标识；该会话后续的本地导航失败、超时语音同样只记日志。任务状态及失败原因仍正常返回网页、写入日志。
- 点位配置的到点播报、讲解正文、普通问答、暂停/继续/结束反馈、手动网页导航和自动返航自己的提示规则保留。
- 当前地图唯一明确的“带我去门口”等指令直接进入对应导航业务，避免再次等待模型误分类；其他自然语言仍通过模型解析意图。

边界：这不是机器人扬声器全局静音，也没有修改厂商原生二进制或 SOC2 技能配置。已验证的是应用输出、SDK 发出的协议及本地 bridge 的会话静默。若另一个原生进程独立产生提示语，它是否响应本次接管信号仍需实机验证，不能把协议测试当作厂商全链路声音验收。

## 安装

先把 `.tar.gz` 和同名 `.tar.gz.sha256` 两个文件上传到机器人 `/home/run`。本电脑文件不会自动出现在机器人上。

在网页结束导航、讲解和自动返航，确认机器人停稳后执行：

```bash
cd /home/run
sha256sum -c sparkrobot-lingxi-v1.3.8-silent-control-fix-1.0.8-20261019.tar.gz.sha256
tar -xzf sparkrobot-lingxi-v1.3.8-silent-control-fix-1.0.8-20261019.tar.gz
cd sparkrobot-lingxi-v1.3.8-silent-control-fix-1.0.8-20261019
sudo bash ./install.sh --check
```

只有预检通过后，执行：

```bash
sudo bash ./install.sh
sudo sparkrobot-lingxi-internal status
sudo sparkrobot-lingxi-internal doctor
```

安装会短暂停止 Java 和导航服务组，然后恢复各自安装前的启动/停止状态。原来停止的服务不会被强行启动；需要正常业务运行时执行：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal doctor
```

无需重装或编译 AIMDK。地图、任务、APPID、密钥、知识库、`lingxi.callbacks` 和灵创资源不改动。不会在安装时下发机器人运动命令。

安装器沿用经过验证的事务引擎，终端还会显示“到达判定与 TTS 确认累计修复”及版本 `1.0.8-20261019`，这是本包继承的累计安装步骤。

## 验收

```bash
sudo tail -n 100 -F /var/log/sparkrobot/lingxi-nav/java-agent.log /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log
```

依次验证，每次使用新的唤醒轮次：

1. “带我去门口”：实际开始导航，不播报启动成功或失败；日志出现接管及 `/nav/start` 请求。不存在的点位不应假装导航成功。
2. 结束当前导航，再说“开始讲解任务”或配置的命令词：实际启动对应任务，不播报启动成功或失败；到点仍正常讲解正文。
3. 任务运行时再发重复开始指令：不得重复启动，拒绝原因只记日志。
4. 测试普通问答、暂停/继续/结束讲解、握手，以及原生唱歌/舞蹈，确认其他功能没有被静音。

Java 关键日志为 `Local control response claimed`、`Voice start result is log-only`、`Voice start acknowledgement TTS suppressed`。bridge 静默失败日志为 `Voice control navigation result is log-only`。这些日志证明本地处理路径，不等于证明原生独立进程没有发声。

停止实时查看日志按 `Ctrl+C`。

## 回滚

安装器会打印本次实际备份目录，例如 `/var/lib/sparkrobot/lingxi-silent-control-fix/backups/...`。结束当前任务并停稳后，用终端打印的完整路径替换下方占位符：

```bash
cd /home/run/sparkrobot-lingxi-v1.3.8-silent-control-fix-1.0.8-20261019
sudo bash ./install.sh --rollback /var/lib/sparkrobot/lingxi-silent-control-fix/backups/实际备份目录
```

回滚恢复安装前文件、清单、属主和权限。若安装后又装了其他补丁或备份损坏，回滚会拒绝覆盖，避免破坏新版本。
