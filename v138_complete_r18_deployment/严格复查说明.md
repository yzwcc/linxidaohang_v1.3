# V1.3.8 r18 严格复查说明

日期：2026-10-19。复查对象为已经交付的 r17 完整压缩包，先校验其 SHA-256 后检查实际包内代码。

## 本轮复现并修复的问题

1. **新机 SOC2 主机指纹路径不一致。**旧配置脚本使用 root 默认 known_hosts，而原生讲解配置检查和网页语音重启使用共享文件。首次安装可能卡在严格 SSH 验证。现统一密钥和主机指纹路径，并按实际 run 账户验证。已有主机指纹变化时仍中止，不删除或绕过校验。
2. **关闭朝向检查时近目标判定一直不完成。**`yaw_tolerance_rad=null` 是配置支持的选项，但旧近目标分支对有意省略的 yaw_error 调用 float，导致一直返回未到达。现支持该配置；朝向检查开启时仍要求有效角度，其余距离、速度、漂移、定位新鲜度和连续稳定五秒要求保持。

新增测试先在 r17 运行，分别复现 SSH 场景四项失败、朝向场景两项失败，再检查 r18 修复。原脚本仅缺少运行账户验证时不应宣告通道成功，该故障也覆盖在测试中。SSH 边界使用隔离替身，指纹检索使用实际 OpenSSH ssh-keygen；不宣称已连接厂家硬件。
