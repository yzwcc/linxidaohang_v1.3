# V1.3.1 参考包与 V1.3.8 r18 对比核验

核验日期：2026-10-20。对象为用户此次提供的 `linxiV1.3.1.zip` 和已交付的 r18 完整压缩包，均直接校验并读取实际归档。

## 结论

本次没有发现旧包中另有遗漏、可以直接补入 r18 的厂家错误播报关闭逻辑，不据此改变产品运行代码，也不另发功能相同的安装包。

两版的开始控制路径**并非完全相同**。r18 为满足后来“开始导航、开始讲解不播成功或失败”的要求，有意增加 SDK 聊天通道接管并取消本地结果播报。不能把旧版运行代码整体覆盖回来，否则会恢复旧版的本地开始确认播报，并丢失后续控制去重、真实确认和模型故障恢复等改动。

这项比较不能证明实机厂家播报已经消失。尤其“抱歉，任务执行失败……”仍保留现场验收状态；本次没有连接或部署客户机器人，没有实测扬声器或客户云端。

## 比较的是实际生效程序

V1.3.1 的 `install_all.sh` 会在安装知识库之后执行 `install_voice_agent.sh`，后者用知识库组件中的 `robot-local-navigation-java-all-kb.jar` 替换主 Java 程序。仅看导航组件初始 JAR 会得出错误结论。

此次提取出的有效知识库 JAR，与此前参考过的 JAR 哈希相同；SDK JAR 也与 r18 字节一致。

| 核验项 | V1.3.1 实际有效行为 | r18 最终归档实际行为 |
| --- | --- | --- |
| 导航开始、讲解开始 | 不发送 SDK interrupt；通过本地 TTS 请求一次确认 | SDK chat 接管一次；不发送 SDK 文本结果，不请求本地结果 TTS |
| 暂停、继续、结束讲解、停止导航 | SDK LLM 流结束后再请求本地 TTS | 同样的流程，16 个回调场景通信序列一致 |
| 控制请求 | 每个测试事件下发一次 | 每个测试事件下发一次 |
| 错误/技能响应帧 | 成功控制场景没有该类响应 | 成功控制场景没有该类响应 |
| 厂家讲解技能配置 | 扫描到的 302 个组件文本中没有相关修改逻辑 | 已包含对 SOC1/SOC2 指定讲解映射的选择性处理 |

上述 16 个序列比较仅归一化 SDK 自动生成的随机 item ID；保留其余事件、消息内容和调用顺序。302 个文本的范围是外层组件内直接包含的脚本、Python、JSON、属性模板和说明，不代表检查了厂家固件或机器人的实际配置。

## 实际测试

从 Git 提交 `749af1b7a1a8267346f839261900a77ac88d3038` 读取当时的原始 `ReferenceControlChannelTest`，先锁定源码 SHA-256，再添加只打印轨迹的观察代码。原始 204 条断言全部保留，未按新版行为重写。

- V1.3.1 实际知识库 JAR：原始 204 条断言全部通过。
- r18 对同一原始测试有 24 项预期差异，全部属于八个开始导航/讲解场景：SDK 接管、取消本地确认、因而没有“SDK 完成后本地确认”的步骤。没有其他断言差异。
- r18 最终归档随包的八组相关回归全部通过，包含当前静默契约、语音文本通道、导航/讲解路由、TTS 异步确认、重复回调及故障、模型失败后恢复、历史现场语音场景回放。
