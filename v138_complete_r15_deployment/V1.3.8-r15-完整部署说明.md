# 灵犀 V1.3.8 r15 完整部署说明

产品版本保持 V1.3.8，内部运行版本为 `1.0.19-20261017-r15`。这是独立完整安装包，不需要先安装旧版本或增量包。适用厂家底层软件正常的 ARM64 SOC1、Ubuntu 22.04、ROS Humble 机器人。

包内包含 AIMDK 压缩组件、ARM64 Java/Node 运行时、导航/地图网页、Java 语音接入、普通动作和灵创接入代码、知识库组件。厂家音频、底盘、定位服务和实际动作/灵创资源由设备提供；系统 apt 依赖需要网络或已配置的本地源。

**已经编译 AIMDK 的新机直接使用同目录《V1.3.8-r15-已编译AIMDK新机完整部署说明》。不要重复编译或替换正常的 AIMDK。**

## 1. 安装准备

上传以下文件到 SOC1 的 `/home/run`，以 run 登录：

- `lingxi-v1.3.8-complete-20261017-r15-deployment.tar.gz`
- `lingxi-v1.3.8-complete-20261017-r15-deployment.tar.gz.sha256`

准备配套的灵心 APP ID、AppKey、AppSecret、豆包 Ark API Key、可用模型标识、知识库智能体 `AI_AGENT_...`、SOC2 地址及其 run 密码。确认机器时间和外网访问正常。

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

用户应为 run，架构为 aarch64/arm64，agi/run 两个厂家账号均应存在。run 无 sudo 权限时，由设备管理员提供安装权限，不能用无权限账号强行继续。

必要工具缺失时安装：

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl openssh-client python3 iproute2 util-linux nano
command -v python3 curl ssh ssh-keygen ssh-copy-id tar ss flock sudo
```

## 3. 尚未编译 AIMDK 的新机

仅在设备缺少可用 AIMDK 时执行本节。已有 `/home/agi/aimdk/install` 且必需接口检查通过的设备跳过本节，按另一份教程直接安装业务。

先以 run 准备系统编译依赖和压缩组件：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261017-r15-deployment
bash ./install_all.sh prepare
```

看到准备完成后，另开终端，以 **agi** 登录同一台 SOC1，执行：

```bash
cd /home/agi
bash ./01-replace-aimdk.sh
```

不要用 run 直接执行，也不要对整个脚本加 sudo。脚本在暂存目录编译并验证后切换 `/home/agi/aimdk`；已有旧目录时保留时间戳备份，切换或最终导入失败会尝试恢复。编译失败时保留日志并处理，不继续业务安装。出现“[通过] AIMDK 替换完成”后回到 run 终端。

检查服务实际使用的干净环境和必需接口，只导入不移动机器人：

失败时先核对缺失接口、固定路径、读取/目录遍历权限。只在交互终端 source 其他路径不能替代服务环境。可选的 `PncTaskResponse` 缺失不影响本检查，继续使用既有到达判定。

## 4. 首次完整业务安装

回到 run 终端，核对端口归属：

```bash
sudo ss -ltnp | grep -E ':(3000|8002|18080|18082|18083|18084) ' || true
cd /home/run/lingxi-v1.3.8-complete-20261017-r15-deployment
read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

其他程序占用端口时先核实归属。依次输入配套的灵心配置、豆包密钥/模型、机器人名和 SOC2 地址。默认模型 `doubao-seed-2-0-mini-260428` 必须在 Ark 账号可用；默认 SOC2 地址 `10.0.1.42` 以实际设备为准。

按提示输入 SOC2 run 密码，分别安装 SSH 公钥、受限语音重启权限。首次新机不加 `--skip-soc2-setup`。

此命令安装完整业务，不再执行 `install-navigation`、`install-addons`，也不混装旧增量包。知识库安装仅安装检索服务，不用旧知识库 JAR 覆盖新版 Java 接入。成功应输出“灵犀 V1.3.8 完整产品已安装”。安装器不发送走路、动作或重定位指令。

## 5. 启动与服务验收

```bash
bash ./install_all.sh preflight
hostname -I
```

同局域网访问 `http://机器人IP:3000/console/`，点击“一键启动全部服务”，等待最终检查。也可使用命令：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal status
bash ./scripts/03-verify-after-web-start.sh
bash ./install_all.sh doctor
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
sudo systemctl show lingxi-java-agent-robot.service \
  -p User -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
sudo ss -ltnp | grep -E ':(3000|8002|18080|18082|18083|18084) ' || true
```

current 应指向 `/opt/sparkrobot/lingxi-nav/releases/1.0.19-20261017-r15`。Java 应为 `running=true`、`lingxi_connected=true`、`robot_online=true`，NRestarts 不持续增加。systemd active、端口监听或脚本退出 0 均不能单独证明语音链路已连通。

| 端口 | 用途 |
| --- | --- |
| 3000 | 网页控制台 |
| 8002 | 地图与点位/任务存储 |
| 18080 | 本机语音桥 |
| 18082 | 导航与讲解桥 |
| 18083 | 兼容网关 |
| 18084 | 本机知识库检索 |

## 6. 现场产品验收

1. 选择实际地图并现场重定位，确认定位持续更新，再执行导航。
2. 新建讲解任务，编辑步骤、讲解文字、动作、开始命令词和等待秒数，保存并刷新，逐项核对。等待范围 0–300 秒，0 秒为不等待，正值为无人交流后继续的时间。
3. 唤醒后测试普通问答、知识库问答；确认针对提问回答，不无限复读。输入由灵心 ASR 转成文本后传给模型。
4. 说“带我去已保存点名”，核对目标；测试停止、连续带路、开始/暂停/继续/结束讲解。
5. 稳定站立时说“能不能跟我握一下手”“给我比个心”，确认动作只发送一次、接受回执不误报拒绝；说“不要握手”不执行。
6. 测试讲解被打断、交流结束 5 秒后的恢复、点位等待按无人交流计时，以及灵创保护结束后语音恢复。
7. 重复一键启动时确认健康组件不被无故重启；服务异常应显示真实失败，处理后能重试。

动作“已接受”只代表接口接收。确认超时会提示“暂未收到动作确认，请先观察机器人状态”，不要立即反复重发。真正拒绝仍报告失败，不强制伪装为成功。

模型正常时负责灵活意图识别。模型暂不可用时，仅对明确动作和精确匹配已保存点名的带路命令提供有限本地补偿；问答仍依赖模型恢复。不引入 V1.3.9 循环次数或其导航策略。

## 8. 旧版更新、备份与回滚

首次新机安装使用第 1–6 节，不需要本节。已有 V1.3.8 r11/r12/r13/r14、知识库服务正常，可保留平台配置快速更新，**不需要再次编译 AIMDK**：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261017-r15-deployment
bash ./install_all.sh upgrade
```

更新前建议保存客户配置。以下备份包含密钥，只保留在受控位置：

```bash
LINGXI_BACKUP="/home/run/lingxi-before-r15-$(date +%Y%m%d-%H%M%S).tar.gz"
sudo tar -czf "$LINGXI_BACKUP" -C / \
  etc/sparkrobot/lingxi-nav \
  var/lib/sparkrobot/lingxi-nav \
  etc/sparkrobot/lingxi-kb
sudo chown run:run "$LINGXI_BACKUP"
chmod 0600 "$LINGXI_BACKUP"
unset LINGXI_BACKUP
```

r10 或更早版使用第 4 节完整 install，重新填写配置，安装器保留地图和任务；不要混装不兼容增量。非 V1.3.8 产品不使用此快捷更新命令。

从 r14 更新后回滚，需旧运行目录仍在：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261017-r15-deployment
sudo sparkrobot-lingxi-internal stop
sudo sparkrobot-lingxi-internal rollback 1.0.19-20261017-r14
sudo install -m 0755 ./scripts/control-r14.sh /usr/local/sbin/sparkrobot-lingxi-complete
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal status
```

从 r11/r12/r13 更新则将回滚版本及 `control-rXX.sh` 同时改为对应来源版本。新机首次安装没有旧版本可回滚。保留完整包、校验文件和备份，验收前不删除旧运行目录。
