# 灵犀 V1.3.8 r17 完整部署教程

交付日期：2026-10-19。产品仍为 V1.3.8，运行目录版本为 `1.0.19-20261019-r17`。

本包是独立完整安装包，包含 r16 完整产品和后续有效累计修复，不需要先装旧包或逐个叠加增量。适用厂家系统正常的 ARM64 SOC1、Ubuntu 22.04、ROS Humble 机器人。已编译好 AIMDK 的新机器使用同目录《已编译AIMDK新机部署教程》，跳过本文第 3 节。

运行文件采用已交付 1.0.8 的准确字节，包含 1.0.6 路由、1.0.7 到点与 TTS 确认、1.0.8 导航/开始讲解控制结果静音。安装流程集成 1.0.10 的 SOC1/SOC2 原生讲解映射事务；排除现场失败的 1.0.9 运行改动。

包内有 AIMDK 压缩组件、ARM64 Node/Java 运行时、网页、导航地图服务、Java 语音接入、知识库和灵创接入代码。厂家底盘、定位、麦克风音频服务、实际动作和灵创资源需由设备提供。系统 apt 依赖仍需要可用的软件源。

## 1. 准备

把完整包和同名 `.sha256` 一起上传到 SOC1 的 `/home/run`。以 run 登录，准备灵心 APP ID、AppKey、AppSecret、豆包 Ark API Key、可用模型、知识库 `AI_AGENT_...`、实际 SOC2 地址及其登录/sudo 密码。不要直接使用旧机器的密钥配置。

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

必须为 ARM64，run/agi 存在，时间正确，run 具备 sudo 权限。必要工具缺失时：

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl openssh-client python3 iproute2 util-linux nano
command -v python3 curl ssh ssh-keygen ssh-copy-id tar ss flock sudo
```

安装前结束讲解、导航和自动返航，确认机器人停稳。双板原生配置有改动时会短暂重启 SOC2 厂家语音服务。使用普通交互 SSH 终端运行安装；不要把安装命令包在 heredoc 中，以免阻断密码输入。

已有可用 `/home/agi/aimdk/install` 的机器跳过本节，不重复编译。

另开终端以 **agi** 登录同一台 SOC1：

## 4. 安装完整业务

以 run 执行，不对 `install_all.sh` 整体加 sudo；脚本会自行提升必要步骤：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

依提示填写灵心配套配置、豆包密钥与模型、机器人显示名、实际 SOC2 地址。默认模型必须在 Ark 账号中可用；默认 SOC2 地址仅为输入建议，以实际设备为准。

首次新机不加 `--skip-soc2-setup`。按提示输入 SOC2 登录密码以安装公钥和受限重启权限；原生技能辅助操作可能另外提示 SOC2 sudo 密码。此密码不会保存到包或配置中。

完整安装依次安装导航主包、知识库，检查两块板历史 `skills.json` 并按需禁用 `start_fixed_line_intro / exhibit_commentary` 对应条目。只修改这些目标条目的 `enabled`，普通动作、唱歌、跳舞及其他配置值保持原值。不要只解压 `components` 内部主包安装，否则会跳过完整流程。

原生阶段结果：

- 有启用映射：备份、修改、验证和重载，并打印事务记录/回滚命令。
- 映射已禁用：校验后不重复重启。
- 两板均无历史映射：明确提示“不适用”，不修改原生配置；业务安装可完成，但不能据此认定错误声音已经消失。
- SSH、权限、配置格式或恢复失败：安装返回失败，不打印完整产品安装成功。

若主包已经装好但原生阶段失败，处理具体报错后在本目录重试该阶段：

```bash
bash ./install_all.sh native-tour-quiet
bash ./install_all.sh preflight
```

这不会重新编译 AIMDK 或重新填写平台配置。

## 5. 启动与检查

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
bash ./install_all.sh preflight
hostname -I
```

同局域网访问 `http://机器人IP:3000/console/`，点击“一键启动全部服务”。也可以使用：

```bash
sudo sparkrobot-lingxi-complete start
sudo sparkrobot-lingxi-internal status
bash ./scripts/03-verify-after-web-start.sh
bash ./install_all.sh doctor
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
sudo systemctl show lingxi-java-agent-robot.service \
  -p User -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
sudo ss -ltnp | grep -E ':(3000|8002|18080|18082|18083|18084) ' || true
```

current 应为 `/opt/sparkrobot/lingxi-nav/releases/1.0.19-20261019-r17`。Java 要同时确认 `running=true`、`lingxi_connected=true`、`robot_online=true`，不能只看 active 或监听端口。

3000 为网页、8002 为地图/任务存储、18080 为语音桥、18082 为导航讲解、18083 为兼容网关、18084 为知识库。安装器不自动下发导航、讲解或动作。

## 6. 产品验收

1. 选择实际地图、完成重定位，确认定位持续更新。
2. 新建讲解任务，编辑点位、文案、等待秒数、动作和开始命令词，保存并刷新核对。
3. 唤醒后问普通问题和知识库问题，确认正确回答、不复读。
4. 说“带我去【已保存点名】”，确认正确目标且只执行一次；不额外播报底层成功/失败。“收到”允许。
5. 说“开始讲解”及自定义开始词，确认任务实际启动且不额外说“抱歉，任务执行失败……”；到点文案正常。
6. 检查连续导航、停止、讲解暂停/继续/结束、无人交流等待及交流结束后 5 秒恢复。
7. 稳定站立时测试握手、比心、打招呼；测试“不要握手”不执行。核对普通唱歌/跳舞及灵创结束后语音恢复。
8. 重复一键启动，确认健康组件不反复重启；真实失败有状态和日志。

近目标收尾要求距离不超过 0.45m、朝向满足配置且不超过 0.25rad、线速度不超过 0.05m/s、转速不超过 0.08rad/s、漂移不超过 0.04m，连续新鲜定位稳定 5 秒后才完成；仍先停止并等停稳。不修改底盘避障距离或导航速度。TTS 对明确优先级拒绝做有界处理，未知确认不重发；底层接受不等于声音已经播放完成。

## 8. 已有 V1.3.8 更新与回滚

已有 r11～r16 且知识库正常，可保留密钥、地图、点位、任务、AIMDK 配置更新。包括这些主包已装过历史增量的场景。先在网页结束全部任务并确认停稳，再备份：

```bash
LINGXI_BACKUP="/home/run/lingxi-before-r17-$(date +%Y%m%d-%H%M%S).tar.gz"
sudo tar -czf "$LINGXI_BACKUP" -C / \
  etc/sparkrobot/lingxi-nav var/lib/sparkrobot/lingxi-nav etc/sparkrobot/lingxi-kb
sudo chown run:run "$LINGXI_BACKUP"
chmod 0600 "$LINGXI_BACKUP"
unset LINGXI_BACKUP
```

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
bash ./install_all.sh upgrade
sudo sparkrobot-lingxi-complete start
bash ./install_all.sh doctor
```

r10 或更早使用第 4 节完整 install，重新输入配置；地图和任务按现有迁移逻辑保留。不要跨用 V1.3.9 包。

回退分两部分。若本次原生阶段打印了事务回滚命令，先在 current 仍为 r17 时原样执行：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
sudo python3 ./scripts/native-tour-quiet/install.py \
  --rollback /var/lib/sparkrobot/lingxi-native-tour-quiet/transactions/实际事务编号.json
```

然后恢复原运行版本。以下仅以**从 r16 更新**为例，旧目录必须仍在：

```bash
sudo sparkrobot-lingxi-internal stop
sudo sparkrobot-lingxi-internal rollback 1.0.19-20261019-r16
sudo install -m 0755 ./scripts/control-r16.sh /usr/local/sbin/sparkrobot-lingxi-complete
sudo sparkrobot-lingxi-complete start
sudo sparkrobot-lingxi-internal status
```

来源 r11～r15 同时替换为对应旧运行版本和 `control-rXX.sh`。已禁用/不适用且未产生新事务时，不需要本次原生回滚。原生回滚会校验后续改动，拒绝覆盖其他人的新配置。新机首次安装没有旧版本可回退。安装失败不会自动回退整个完整产品；原生阶段有独立联合恢复，保留其记录以便重试。
