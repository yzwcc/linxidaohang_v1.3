# V1.3.8 r17 已编译 AIMDK 新机部署教程

适用于从未部署灵犀业务、但厂家 AIMDK 已编译至 `/home/agi/aimdk/install` 的 ARM64 新机器。无需先安装 r15/r16 或任何增量包，也无需替换/再次编译 AIMDK。

本包累计合并到点判定、TTS 异步确认、导航/讲解控制静音及双板原生讲解技能配置处理。产品 V1.3.8，内部版本 `1.0.19-20261019-r17`。全流程在 SOC1 完成；原生配置阶段通过实际 SOC2 SSH 配置检查第二块板。

## 1. 准备

将以下两个文件上传 SOC1 的 `/home/run`：

- `lingxi-v1.3.8-complete-20261019-r17-deployment.tar.gz`
- `lingxi-v1.3.8-complete-20261019-r17-deployment.tar.gz.sha256`

以 run 登录，确认 Ubuntu 22.04、ROS Humble、厂家定位/音频/底盘服务正常，run/agi 存在。准备灵心 APP ID、AppKey、AppSecret、豆包密钥/可用模型、知识库 `AI_AGENT_...`、实际 SOC2 地址和登录/sudo 密码。

```bash
cd /home/run
whoami
uname -m
id run
id agi
sudo -v
timedatectl status
sudo test -r /opt/ros/humble/setup.bash
sudo test -r /home/agi/aimdk/install/setup.bash
sudo test -d /agibot/data/var/MapManagerModule
```

工具缺失时：

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl openssh-client python3 iproute2 util-linux nano
command -v python3 curl ssh ssh-keygen ssh-copy-id tar ss flock sudo
```

## 2. 校验并解压

```bash
cd /home/run &&
sha256sum -c lingxi-v1.3.8-complete-20261019-r17-deployment.tar.gz.sha256 &&
tar -xzf lingxi-v1.3.8-complete-20261019-r17-deployment.tar.gz &&
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment &&
sha256sum -c SHA256SUMS.txt
```

所有检查必须为 OK。不要执行 `prepare`、`01-replace-aimdk.sh`；那些用于缺少 AIMDK 的机器。

使用实际服务用户和路径检查，只导入不运动：

```bash

  PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin \
  LANG=C.UTF-8 bash --noprofile --norc <<'BASH'
```

失败先检查路径、接口和读取权限。`PncTaskResponse` 可选，缺失不阻止安装；本包仍用改进后的里程计回验。确实缺少必需接口时参见另一份完整部署教程，不通过忽略错误继续。

## 4. 安装业务

确认停稳、结束其他任务。在交互 SSH 终端以 run 执行：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
read -r -p "知识库智能体 Code（AI_AGENT_...）: " LINGXI_AGENT_CODE
bash ./install_all.sh install --agent-code "$LINGXI_AGENT_CODE"
unset LINGXI_AGENT_CODE
```

依提示填写灵心配置、豆包密钥/模型、机器人名称和实际 SOC2 地址。新机不使用 `--skip-soc2-setup`。输入 SOC2 登录密码建立公钥和运维权限；原生技能配置可能另外要求 sudo 密码。不要把安装命令包在 heredoc 中。

脚本包含导航主包、知识库与双板原生技能配置处理，不需要安装独立增量。不要只安装 `components` 内主包。

原生阶段只禁用历史 `start_fixed_line_intro / exhibit_commentary` 映射，保留其他技能。若两板都不存在该历史配置，会明确显示“不适用”；这不等于证明所有错误声音已消除。配置改动前会保存原文件/权限/指纹，按需短暂重启 SOC2 厂家语音服务。安装器不会执行走路、动作或开始讲解。

若仅原生阶段失败，解决具体 SSH/密码/配置报错后：

```bash
cd /home/run/lingxi-v1.3.8-complete-20261019-r17-deployment
bash ./install_all.sh native-tour-quiet
bash ./install_all.sh preflight
```

## 5. 启动

```bash
bash ./install_all.sh preflight
hostname -I
```

同局域网打开 `http://机器人IP:3000/console/`，点击“一键启动全部服务”。命令行方式：

```bash
sudo sparkrobot-lingxi-complete start
sudo sparkrobot-lingxi-internal status
bash ./scripts/03-verify-after-web-start.sh
bash ./install_all.sh doctor
sudo readlink -f /opt/sparkrobot/lingxi-nav/current
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
sudo systemctl show lingxi-java-agent-robot.service \
  -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
```

current 为 `1.0.19-20261019-r17`；Java 同时检查 `running=true`、`lingxi_connected=true`、`robot_online=true`，重启次数不持续上涨。preflight/doctor 会重新读取双板映射；仍启用会报错，不能只凭旧的安装结果判定。

## 6. 验收与日常维护

1. 地图/定位持续更新，保存点位和讲解任务后刷新仍保留。
2. 普通问答、知识库问答正常。灵心把音频转为文本后进入模型。
3. 说“带我去【保存点名】”，正确执行一次，不播报底层成功/失败。
4. 说“开始讲解”和自定义命令词，任务正常启动，不播报“抱歉，任务执行失败……”；到点文案正常，“收到”允许。
5. 等待按无人交流时间继续，打断后交流结束 5 秒恢复，暂停/继续/结束任务正常。
6. 握手/比心/打招呼、唱歌/跳舞及灵创保护正常；否定动作指令不执行。
7. 重复网页一键启动不反复重启健康语音链路。

检查原生配置阶段记录：

```bash
sudo cat /var/lib/sparkrobot/lingxi-native-tour-quiet/full-r17-status.json
```

此记录是安装结果，真实状态以 preflight 和实际声音为准。

改错填的配置：

```bash
sudo cp -a /etc/sparkrobot/lingxi-nav/lingxi-nav.properties \
  /etc/sparkrobot/lingxi-nav/lingxi-nav.properties.bak.$(date +%Y%m%d-%H%M%S)
sudo nano /etc/sparkrobot/lingxi-nav/lingxi-nav.properties
sudo systemctl restart lingxi-java-agent-robot.service
sudo bash /opt/sparkrobot/lingxi-nav/current/scripts/java_agent_control.sh status
```

修改配套 `lingxi.appId`、`lingxi.appKey`、`lingxi.appSecret`、`doubao.apiKey`、`doubao.model`，保留有效 `lingxi.callbacks`。

```bash
sudo tail -n 100 -F \
  /var/log/sparkrobot/lingxi-nav/java-agent.log \
  /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log \
  /var/log/sparkrobot/lingxi-nav/map_label_server_v3.log \
  /var/log/sparkrobot/lingxi-nav/robot_lingxi_bridge.log
```

Ctrl+C 退出。权限修复使用 `bash ./install_all.sh repair-permissions`。原生配置有独立事务回滚，按安装时打印的命令执行；全新安装没有旧业务版本可回退。已有机器升级/联合回滚详见另一份完整部署教程第 8 节。

本次离线验证不替代客户机器的认证、运动和声音验收。没有新增硬件 DOA、AEC/RNNoise，不调整底盘避障距离或速度，也不加入 V1.3.9 循环功能。
