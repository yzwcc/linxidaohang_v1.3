# V1.3.8 到达判定与语音确认累计增量包

包名：`sparkrobot-lingxi-v1.3.8-arrival-tts-fix-1.0.7-20261019.tar.gz`。

适用：V1.3.8 完整包 r15、r16，以及在它们上安装过 control-reply-fix 1.0.0～1.0.6 的机器。日志中的 `1.0.19-20261019-r16` 在支持范围内。其他版本会在写入前拒绝，防止覆盖不同逻辑。

本包已包含 1.0.6 及其之前的累计语音控制修复，无需再依次安装旧增量包。无需重新编译或安装 AIMDK。

## 安装

先把压缩包及同名 `.sha256` 文件上传至机器人 `/home/run`。仅在电脑上下载文件不会自动传到机器人；如果报 `No such file or directory`，请先确认上传位置。

安装前在网页结束讲解、导航和自动返航任务，确认机器人停稳。安装过程中不要点击启动服务或下发任务。安装器会重启原本运行的导航服务组和 Java Agent；原本停止的服务仍保持停止。

```bash
cd /home/run
sha256sum -c sparkrobot-lingxi-v1.3.8-arrival-tts-fix-1.0.7-20261019.tar.gz.sha256
tar -xzf sparkrobot-lingxi-v1.3.8-arrival-tts-fix-1.0.7-20261019.tar.gz
cd sparkrobot-lingxi-v1.3.8-arrival-tts-fix-1.0.7-20261019
sudo bash ./install.sh --check
sudo bash ./install.sh
```

`--check` 只检查版本、文件、运行清单、权限、实际 Java 启动路径和任务空闲状态，不启停服务，不发导航或动作。若检查失败，请不要跳过校验强行覆盖。

本包不修改地图、点位、讲解任务、密钥、知识库、回调配置、机器人语音栈或网页文件。导航控制使用实际存在的 `scripts/navigation_control.sh`，以原来的 `agi` 用户执行。校验文件和脚本均为 LF 换行。

## 安装后检查

```bash
sudo sparkrobot-lingxi-internal verify
sudo sparkrobot-lingxi-internal doctor
curl -fsS http://127.0.0.1:18082/nav/status | python3 -m json.tool
sudo systemctl show lingxi-java-agent-robot.service \
  -p ActiveState -p SubState -p ExecMainStatus -p NRestarts
```

如果安装前所有业务服务就已停止，本包会保留该状态。需要使用时，可从网页启动，或运行：

```bash
sudo sparkrobot-lingxi-internal start
sudo sparkrobot-lingxi-internal doctor
```

确认补丁标记：

```bash
sudo python3 - <<'PY'
import json
from pathlib import Path
release = Path("/opt/sparkrobot/lingxi-nav/current").resolve(strict=True)
manifest = json.loads((release / "payload-manifest.json").read_text())
print("release =", release)
print("arrival_tts_fix =", manifest.get("arrival_tts_fix"))
print("control_reply_fix =", manifest.get("control_reply_fix"))
PY
```

应显示 `arrival_tts_fix = 1.0.7-20261019`。

## 现场验证

另开一个 SSH 窗口监听：

```bash
sudo tail -n 80 -F \
  /var/log/sparkrobot/lingxi-nav/lingxi_nav_bridge.log \
  /var/log/sparkrobot/lingxi-nav/java-agent.log
```

依次测试：

1. 没有其他任务时，说“带我去取号点”，确认目标识别正确、只启动一次导航。
2. 观察接近目标后的收尾。保持原来的严格到达逻辑；额外允许 0.45 米内，朝向误差满足配置且不超过约 14.3 度，线速度不超过 0.05 米/秒、转速不超过 0.08 弧度/秒、位置漂移不超过 0.04 米，连续稳定 5 秒后完成。必须是连续、新鲜且时间戳推进的定位。日志标记为 `Navigation stable near-goal accepted`。
3. 稳定完成后应先走原有 STOP/停稳等待，再进入点位播报和下一步。不会仅因为“距离近”就立即开始讲解。`stop_policy.mode=never` 或无有效朝向证据时不启用该收尾路径。
4. 在空闲状态说“开始讲解”，确认任务正常启动。讲解已经运行时再次启动，以及讲解保护期间要求另行导航，仍沿用原来的忙碌和保护规则，不强行抢占任务。
5. 语音日志中查看 `TTS acknowledgement`：`accepted` 是底层接收；`rejected` 是明确拒绝；`ack_pending/ack_unknown` 是未获得确切确认。接收确认不等于声音已经播放完毕。

本包仅对明确的 `priority_rejected` 做最多两次短延迟重试，保持原来的 L7 优先级。任务阶段变化、后续语音请求到来或超出短重试窗口时取消重试。确认超时不会自动重发同一段话，也不会再切回 SDK 播放相同文本。

若仍听到“抱歉，暂时没有学会这个动作”，请保留对应时间日志。这句话未出现在此前提供的本机日志中，其原生来源尚未证实；本包没有宣称拦截所有系统原生播报，也没有更改底盘避障距离或安全提醒。

## 回滚

安装成功会输出本次唯一的备份路径，形如：
`/var/lib/sparkrobot/lingxi-arrival-tts-fix/backups/20261019T……-……`。

在同一个包目录执行以下命令，将末尾路径替换为安装器实际输出的路径：

```bash
sudo bash ./install.sh --rollback /var/lib/sparkrobot/lingxi-arrival-tts-fix/backups/本次实际备份目录
```

回滚会恢复 JAR、Python 文件、运行清单及原权限，并删除本补丁新增的两个模块。服务保持回滚前的运行或停止状态。安装失败会自动恢复本次事务；若安装后文件已有其他补丁修改，会拒绝覆盖，避免丢失新变更。
